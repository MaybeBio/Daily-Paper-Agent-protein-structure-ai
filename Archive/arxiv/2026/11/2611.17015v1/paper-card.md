## 03 研究问题

- **具体问题**：生物学研究者在使用 foundation models（如蛋白质语言模型、结构预测模型）时，如何识别和理解模型的知识边界？Agentic systems（自主决策的 AI 系统）能否扩展这些边界？
- **为什么重要**：随着 AI 在生物学中的广泛应用，研究者容易过度信任模型输出，尤其在蛋白质结构预测、功能注释、设计等关键任务中，错误判断可能导致实验资源浪费或错误结论。
- **现有方法为何不足**：现有文献多聚焦于模型性能提升，缺乏对知识边界的系统性讨论；生物学研究者缺乏判断模型何时可靠、何时不可靠的框架。
- **精确研究问题**：Can biologists reliably identify the knowledge boundaries of foundation models in biological applications, and do agentic systems meaningfully extend these boundaries beyond what static models achieve?

## 06 核心思想

**1) 表面方法**：本文是一篇观点性综述，不提出新算法或新模型，而是构建一个分析框架，用于理解 foundation models 在生物学中的知识边界，并讨论 agentic systems 的潜在作用与局限。

**2) 核心洞察**：Foundation models 的知识边界由训练数据分布决定，而非模型容量或架构。Agentic systems 通过迭代查询、外部工具调用、实验反馈等方式可以**扩展**这些边界，但无法**消除**——因为 agent 的底层推理仍依赖 foundation models 的表征能力。作者强调，生物学研究者需要建立「边界意识」，将模型输出视为假设而非结论。

**3) 可能的普适教训 [Analysis]**：对于蛋白质结构计算研究，这一框架意味着：AlphaFold 等结构预测模型的可靠性高度依赖训练集覆盖的序列-结构空间；在全新折叠、工程改造蛋白、非标准残基等场景中，预测结果应被视为候选而非确定答案。Agentic 工作流（如自主设计-验证循环）可以提升效率，但必须内置不确定性量化和人工验证节点。

## 14 学到什么

**Agent 提炼的知识候选**：

1. **边界意识框架**：在蛋白质结构预测/设计任务中，应明确区分「训练分布内」与「分布外」场景。例如，AlphaFold 对天然蛋白结构预测可靠，但对 de novo 设计蛋白或非天然氨基酸修饰的预测应视为假设。可迁移：在结构预测项目中建立「边界检查清单」，标注每个预测的可靠性等级。

2. **不确定性量化优先**：模型置信度不等于准确性。在蛋白质结构预测中，pLDDT 分数应结合多序列比对深度、模板覆盖度等外部信号综合判断。可迁移：开发结合多源不确定性信号的评估工具。

3. **Agent 工作流需内置验证节点**：自主设计-预测-验证循环中，应在关键决策点插入人工或实验验证，防止错误累积。可迁移：在蛋白质设计 agent 中设计「验证门控」机制。

4. **多尺度整合是开放问题**：单一模型难以同时处理序列-结构-功能-表型多个层次。可迁移：在蛋白质计算研究中采用「模型组合」策略，不同层次使用不同模型，并明确各模型的边界。

5. **因果推理缺失**：结构预测模型输出相关性而非因果机制。在蛋白质工程中，不能仅依赖模型预测的突变效应，需结合分子动力学模拟等物理方法验证机制。可迁移：建立「预测-模拟-实验」三级验证流程。

## 16 研究想法

**Agent 生成的研究候选**：

**候选 1：蛋白质结构预测模型的边界校准评估框架**
- **名称**：Structure Prediction Boundary Calibration (SPBC)
- **来源局限/观察**：本文指出 foundation models 存在知识边界，但未提供定量评估方法；AlphaFold 等模型的 pLDDT 在分布外场景中校准不良。
- **核心假设**：通过系统评估模型在序列相似性、结构新颖性、共进化信号强度等维度上的置信度-准确性关系，可以建立可操作的边界预测器。
- **相对本文的增量**：将本文的定性框架转化为可计算的评估工具。
- **初步方法**：收集多样化的蛋白结构数据集，按序列相似性、结构拓扑新颖性分层；计算 AlphaFold/ESMFold 的置信度指标与预测准确性（TM-score）的校准曲线；训练边界预测器（如 logistic regression 或小模型）整合多源特征。
- **验证方式**：在独立测试集（如新解析的蛋白结构、设计蛋白）上评估边界预测器的 AUC 和校准误差。
- **可能的失败模式**：边界特征可能高度任务特异，难以泛化到所有蛋白类型；置信度指标可能已包含足够信息，额外特征增益有限。
- **创新状态**：unverified

**候选 2：蛋白质设计 agent 的验证门控机制**
- **名称**：DesignAgent with Verification Gates (DAVG)
- **来源局限/观察**：本文指出 agentic systems 存在错误累积风险，但未给出缓解方案；蛋白质设计 agent 中预测错误可能沿设计-验证循环传播。
- **核心假设**：在 agent 决策链中插入基于多源验证的「门控」节点（如结构预测一致性检查、MD 模拟稳定性验证、实验可行性过滤），可显著降低最终设计失败率。
- **相对本文的增量**：将本文的 agent 风险讨论转化为具体工程方案。
- **初步方法**：构建蛋白质设计 agent（如基于 LLM 的序列生成 + AlphaFold 结构验证 + MD 模拟）；在关键决策点设计门控函数，综合 pLDDT、MD 稳定性指标、合成可行性评分；对比有/无门控的 agent 在 benchmark 设计任务上的成功率。
- **验证方式**：在标准蛋白设计 benchmark（如从头设计结合蛋白）上比较成功率、计算成本、错误传播路径。
- **可能的失败模式**：门控可能过度保守，降低设计多样性；多源验证的计算成本可能抵消 agent 的效率优势。
- **创新状态**：unverified

**候选 3：蛋白质语言模型的知识边界图谱**
- **名称**：Protein Language Model Boundary Atlas (PLM-BA)
- **来源局限/观察**：本文强调训练数据分布决定模型边界，但未提供具体数据分布分析方法；蛋白质语言模型的进化尺度预测在特定序列空间（如设计蛋白、病毒蛋白）中可靠性未知。
- **核心假设**：通过对比模型训练数据分布与目标序列空间的差异，可以预测模型在特定任务上的可靠性。
- **相对本文的增量**：将「数据分布决定边界」的抽象观点转化为可操作的数据分析工具。
- **初步方法**：收集 ESM/ProtTrans 等模型的训练数据分布信息（如序列聚类、物种覆盖）；对目标序列空间（如设计蛋白、未培养微生物蛋白）进行嵌入空间分析；建立「分布距离-预测可靠性」的映射关系。
- **验证方式**：在多个下游任务（功能注释、稳定性预测、结构预测）上评估映射关系的预测能力。
- **可能的失败模式**：训练数据分布信息可能不完整或不可得；嵌入空间距离与任务可靠性之间的相关性可能较弱。
- **创新状态**：unverified
