## 02 一句话总结

BiHC 提出一种基于全重原子 Voronoi 接触面积、经残基亲水性和片段尺寸归一化的成对自包含分数 F 及全局分割质量分数 G，通过独立的 top-down 递归分裂和 bottom-up 递归合并两条层次搜索轨迹生成候选域分割，在 CATH–ECOD 共识基准上达到与深度学习方法 Chainsaw 相当、优于其他准则型方法的域分割性能。

## 03 研究问题

- **具体问题**：如何仅凭显式的物理/几何准则（而非学习到的表征）自动识别蛋白质结构域边界？
- **为什么重要**：蛋白质结构域是结构、进化、功能的基本单元，域分割是结构分类、进化分析、基于结构的设计的必要前置步骤。随着实验和预测结构数量激增，自动化、可解释的域分割工具需求日益增长。
- **现有方法为何不足**：
  - 深度学习方法（Chainsaw、Merizo、DPAM-AI）性能强，但边界决策依赖学习到的表征，难以追溯每个决策的结构依据；
  - 传统准则型方法（PUU、DomainParser、PDP、SWORD、DDOMAIN、UniDoc）多使用距离截断或距离函数表示接触，未直接度量界面的几何范围；且候选生成与候选评估常使用不同准则，需要额外校准，增加过拟合风险。
- **精确的「Can ... ?」研究问题**：Can a single Voronoi-based physical criterion, normalized for fragment size and internal packing and supplemented by hydropathy, be used consistently for both candidate domain-boundary discovery and partition quality assessment, achieving performance competitive with deep learning methods?

## 06 核心思想

### 1) 表面方法

BiHC 是一个纯准则型（criterion-based）域分割器，包含三个核心组件：
- **结构表示**：以 SSE（二级结构元件）为基本单元，用全重原子 Voronoi 镶嵌（Voronota v1.29，1.4 Å 探针）计算残基间接触面积；
- **成对自包含分数 F**：将残基间 Voronoi 接触面积按残基亲水性（Kyte-Doolittle 标度归一化到 [0,1]）加权，再除以片段尺寸相关的归一化项（约化尺寸项 µ_AB 的 β 次方，β = 0.86）；
- **全局分割质量分数 G**：由 F 导出的全局分数，同时要求域间接触弱（低 F）且域内最弱可允许切割也弱（高 F），以调和平均组合。

搜索策略为**双向层次聚类**：top-down 从完整结构开始递归施加最弱可允许切割（单切或双切），bottom-up 从 SSE 开始递归合并 F 最高的接触对，两条轨迹的所有中间分割均作为候选，最后用 G 排序选择。

### 2) 核心洞察

- **Voronoi 接触面积直接度量界面几何范围**，比距离截断更物理；
- **亲水性加权**：域间界面平均而言比域内接触更亲水（极性），因为疏水残基更倾向于埋在域内部；
- **归一化是关键**：原始接触面积随片段尺寸增长，必须用约化尺寸项归一化才能跨候选比较；
- **F 同时用于生成与评估**：同一准则贯穿候选发现与候选排序，避免生成-评估准则分离带来的校准问题；
- **双向搜索互补**：top-down 和 bottom-up 各自覆盖不同的分割空间，保留所有中间分割可避免早期停止的局部最优问题。

### 3) 可能的普适教训 [Analysis]

- **物理准则的「可解释性红利」**：当深度学习模型在基准上占优时，显式物理准则仍可提供可追溯的决策依据，且可作为集成、蒸馏或异常检测的补充信号；
- **「生成-评估同源」原则**：若生成候选与评估候选使用同一准则，可减少超参数校准负担，降低过拟合风险——这一原则可迁移到其他结构分割/聚类任务；
- **双向搜索 + 全轨迹保留**：不依赖单一方向的贪心停止，而是保留所有中间状态再全局排序，是一种通用的搜索策略，适用于构象采样、聚类等存在层次结构的问题；
- **归一化设计需匹配任务几何**：尺寸归一化的指数（β）需与接触面积的标度行为匹配（本文通过 PDP 的 α 推导 β = 2α = 0.86），这种「从已有方法推导标度指数」的思路可迁移。

## 07 方法总览

- **输入**：蛋白质链的 3D 结构（PDB 格式），需 ≥60 残基
- **输出**：域分割（每个残基的域分配），以及每个候选分割的全局质量分数 G
- **模块**：
  1. **结构表示模块**：SSE 分配（STRIDE）→ 全重原子 Voronoi 镶嵌（Voronota v1.29）→ 残基-残基接触面积矩阵
  2. **打分模块**：计算成对自包含分数 F（亲水性加权 + 尺寸归一化）
  3. **搜索模块**：top-down 递归分裂 + bottom-up 递归合并，保留所有中间分割
  4. **排序模块**：用全局分数 G 对所有候选分割排序，选择最优
  5. **后处理模块**：合并短片段（<40 残基或 <2 个规则 SSE）到相邻片段
- **训练**：无监督，无需训练数据；唯一需选择的超参数为阈值 t（在 tuning set 上选取）
- **工具**：STRIDE（SSE 分配）、Voronota v1.29（Voronoi 镶嵌）、自研 Python 实现
- **文字流程**：
  1. 输入结构 → STRIDE 分配 SSE → Voronota 计算全重原子 Voronoi 镶嵌 → 汇总为残基-残基接触面积
  2. 对任意两个片段 A、B，计算亲水性加权的 Voronoi 界面面积 W_AB 和约化尺寸项 µ_AB，得 F_AB = W_AB / (µ_AB)^β
  3. Top-down：从完整结构开始，找到 F 最低的可允许切割（单切或双切，每侧 ≥40 残基），递归分裂直到无合法切割；记录所有中间分割
  4. Bottom-up：从 SSE 开始，反复合并 F 最高的接触对，直到整个结构合并为一个片段；记录所有中间分割
  5. 对每个候选分割 P，计算全局分数 G_P,t（域间 F 与域内最弱切割 F 的调和平均，相对于阈值 t）
  6. 选择 G 最高的分割作为最终预测；后处理合并短片段

## 09 关键公式符号

> 注：原文公式以文字描述为主，具体符号形式未完整给出。以下基于 Methods 描述重构，标注 [Analysis] 表示推断。

**1. 亲水性加权界面面积**

W_AB = Σ_(r∈A, s∈B) a_rs · h_rs

- W_AB：片段 A、B 之间的亲水性加权 Voronoi 接触面积
- a_rs：残基 r 和 s 之间的 Voronoi 接触面积（由 Voronota 计算）
- h_rs：残基 r、s 的归一化亲水性值的均值（Kyte-Doolittle 标度归一化到 [0,1]）
- 用途：衡量域间界面的物理接触强度，亲水残基贡献更大
- 直觉：域间界面应相对亲水（疏水残基埋在域内），因此高 W 表示强接触

**2. 约化尺寸项**

µ_AB = (N_A · N_B) / (N_A + N_B)  [Analysis：基于「harmonic mean」描述推断]

- N_A、N_B：片段 A、B 的残基数
- 用途：归一化界面面积，消除片段尺寸影响
- 直觉：与两片段尺寸的调和平均成正比，大片段自然有更大接触面积

**3. 成对自包含分数**

F_AB = W_AB / (µ_AB)^β

- β = 0.86（= 2α，α = 0.43 来自 PDP）
- 用途：衡量 A、B 是否应合并为同一域
- 直觉：F 低 → 界面弱（相对尺寸而言）→ 应分割；F 高 → 界面强 → 应合并
- 标度推导：当 N_A ≈ N_B ≈ N 时，µ_AB ≈ N/2，F 的尺寸标度为 N^(1-β) = N^0.14，与 PDP 的 N^(2α) = N^0.86 标度一致（在 comparable-size limit）

**4. 几何 Voronoi 接触密度**（用于定义 F 的分母）

ρ_A = (内部接触面积之和) / (N_A 相关归一化项)  [Analysis：原文描述为 "geometric Voronoi contact density"，具体公式未给出]

- 用途：衡量片段 A 的内部堆积紧密程度
- 直觉：高密度 → 结构紧凑 → 更可能是一个独立域

**5. 全局分割质量分数**

G_P,t = H( 域间分数, 域内分数 )  [Analysis：原文描述为 "harmonic mean of the inter-domain and intra-domain scores"，具体形式未给出]

- 域间分数：所有接触域对的 F 相对于阈值 t 的满足程度（要求 F < t）
- 域内分数：每个域的最弱可允许内部切割的 F 相对于阈值 t 的满足程度（要求 F > t）
- 用途：对候选分割 P 的整体质量打分
- 直觉：好的分割应使域间界面弱（F < t）且域内无弱切割（所有内部切割 F > t）

## 10 实验设计与证据链

### 数据集

| 数据集 | 来源 | 规模 | 用途 |
|--------|------|------|------|
| CONSENSUS-43 | CATH v4.3 S40 + ECOD v295.2 共识 | 3,231 结构（3,031 单域 + 200 多域） | 主基准 |
| Tuning set | CATH v4.3 S40 流程，排除 CONSENSUS-43 | 3,918 结构（1,959 单域 + 1,959 多域，平衡采样） | 选择阈值 t |
| CONSENSUS-44 | CATH v4.4 S40 新增域 + ECOD v295.2 共识 | 1,060 结构（933 单域 + 127 多域） | 跨版本稳定性验证 |

### 过滤流程（四阶段）

1. 长度过滤：≥60 残基（35,581 / 17,278 候选）
2. 序列相似性过滤：MMseqs2 40% 同一性、80% 覆盖度聚类，排除与训练集/先前集合聚类的簇（4,350 / 16,332 / 1,755）
3. 结构相似性过滤：Foldseek，TM-score ≥ 0.90（长链归一化）或序列同一性 ≥ 0.90 且 TM-score ≥ 0.80 排除（4,051 / 15,555 / 1,487）
4. CATH–ECOD 共识过滤：域数一致且 partition IoU ≥ 0.90（3,231 / 11,241 / 1,060）

### 评估指标

- **域数准确率**：exact-K accuracy（预测域数 = 目标域数的比例）
- **域数误差**：K-score（基于 Bray-Curtis 相异度，反映域数误差幅度）
- **分割质量**：IoU、NDO（归一化域重叠）、CSD（链段距离）、DBD（域边界距离）

### 对比方法

- 准则型：UniDoc、SWORD2、STRIDE-R（重构的 STRUDL）
- 深度学习方法：Chainsaw、Merizo

### 统计检验

- 配对 bootstrap（3,000 次重采样），Benjamini-Hochberg 校正，q < 0.05 显著
- 敏感性分析：exact-K 用 McNemar 检验，连续指标用 Wilcoxon 符号秩检验

## 11 结论正确解读

- **任务范围**：本文仅评估了**域分割**（domain segmentation），即给定一条链，预测域的数量和边界。未涉及域分类、域功能注释或域间相互作用预测。
- **基准范围**：CONSENSUS-43/44 基于 CATH 与 ECOD 的共识注释，排除了两者不一致的结构。这意味着基准偏向于「注释一致」的较清晰案例，真实世界中的模糊案例可能更多。
- **真值/oracle 输入**：BiHC 的输入仅为 3D 结构（PDB），无任何域注释或同源信息。对比的深度学习方法（Chainsaw、Merizo）使用训练集学习域组织模式，其训练数据可能包含与基准重叠的结构。
- **端到端状态**：BiHC 是**完全无监督**的，无需训练；但阈值 t 在 tuning set 上选择，tuning set 与 CONSENSUS-43 同源于 CATH v4.3，存在一定程度的「调参泄漏」——虽然 tuning set 排除了 CONSENSUS-43 本身，但两者来自同一分布。
- **算力成本**：Voronoi 镶嵌（Voronota）为多项式时间算法，层次搜索为 O(N²) 量级（基于 SSE 数），远低于深度学习方法的前向推理成本（需 GPU）。但本文未报告具体运行时间。
- **历史数据依赖**：无。BiHC 不依赖任何训练数据或历史注释。
- **模型依赖**：无。BiHC 不依赖预训练模型。
- **最难情形**：多域结构（≥3 域）、紧密堆积的域间界面、无规则 SSE 的卷曲区域。BiHC 在多域结构上准确率显著低于深度学习方法。
- **有边界的复述**：在 CATH-ECOD 共识基准上，BiHC 作为无监督物理准则方法，其域数预测准确率与深度学习方法 Chainsaw 相当，且显著优于其他准则型方法；但其多域分割能力仍弱于深度学习方法，且其性能边界受限于物理去耦假设（即注释域边界不一定对应物理弱界面）。

## 14 学到什么

> 标题：Agent 提炼的知识候选

1. **物理准则的「生成-评估同源」设计**：BiHC 的核心设计原则是让同一个物理分数 F 同时驱动候选生成（top-down 切割和 bottom-up 合并）和候选评估（全局分数 G）。这种「同源准则」避免了 STRUDL 中生成与接受准则分离导致的额外校准问题。**可迁移到**：构象采样中的打分函数设计、聚类算法中的距离度量选择。

2. **双向层次搜索 + 全轨迹保留**：BiHC 不依赖单一方向的贪心决策，而是同时运行 top-down 和 bottom-up 两条轨迹，保留所有中间分割，再用全局分数排序。这避免了早期停止的局部最优问题。**可迁移到**：蛋白质构象空间的层次划分、MD 模拟中的状态聚类、序列设计中的层次搜索。

3. **Voronoi 接触面积作为「几何界面」度量**：相比距离截断，Voronoi 面片面积直接度量原子间的几何接触范围，且可通过镶嵌一次计算、反复查询。**可迁移到**：蛋白-蛋白相互作用界面预测、蛋白-配体结合位点识别、MD 轨迹中的接触分析。

4. **亲水性加权的物理直觉**：域间界面平均更亲水（疏水残基埋在域内），这一物理先验可以增强边界信号。**可迁移到**：蛋白-蛋白 docking 的界面打分、膜蛋白的跨膜区域预测、蛋白设计中的表面残基选择。

5. **尺寸归一化的标度推导**：从已有方法（PDP 的 α = 0.43）推导自己的归一化指数（β = 2α = 0.86），而不是自由拟合。这种「从先验方法推导标度」的思路可避免过拟合。**可迁移到**：任何需要尺寸归一化的几何/物理打分函数设计。

6. **基准构建的严谨性**：CATH-ECOD 共识过滤（域数一致 + IoU ≥ 0.90）、序列和结构双重去冗余、对训练集泄漏的控制（排除 Chainsaw/Merizo 训练集相关簇）——这些基准构建原则对评估任何结构预测/分割方法都适用。

7. **物理准则与深度学习的互补定位**：BiHC 在单域结构上最优、在多域结构上弱于深度学习方法，说明物理准则擅长「识别独立单元」而弱于「解析复杂组织」。**可迁移到**：将物理准则作为深度学习模型的先验/正则化，或用于生成训练标签。

## 15 与已有知识连接

- **Wodak & Janin (1981)**：最早提出用界面面积极小值识别域边界。BiHC 继承「弱界面 = 域边界」的物理直觉，但用 Voronoi 面片面积替代了溶剂可及表面积（SASA）计算。
- **STRUDL (Wernisch, Hunting, and Wodak 1999)**：首次将 Voronoi 接触面积用于域分割，使用 radical plane 加权 Voronoi 和 Kernighan-Lin 图分割。BiHC 的 F 分数可视为 STRUDL 思想的推广，但统一了生成与评估准则，并增加了亲水性加权。
- **PDP (Alexandrov & Shindyalov 2003)**：使用距离相关的接触数和尺寸归一化（α = 0.43）。BiHC 的 β = 2α = 0.86 直接源自 PDP 的标度行为。
- **PUU (Holm & Sander 1994)**：基于接触数的 top-down 递归分割。BiHC 的 top-down 搜索与之类似，但使用 Voronoi 面积而非接触数。
- **SWORD / SWORD2 (Postic et al. 2017; Cretin et al. 2022)**：bottom-up 合并策略的先例。BiHC 的 bottom-up 搜索与之类似，但使用 F 而非接触密度。
- **UniDoc (Zhu et al. 2023)**：结合 top-down 和 bottom-up 的准则方法。BiHC 与之最接近，但 UniDoc 使用距离/接触准则，BiHC 使用 Voronoi 面积 + 亲水性。
- **Chainsaw (Wells et al. 2024)**：深度学习方法，预测残基对同域概率。BiHC 的对比基准，也是 CATH v4.4 注释流程的组成部分。
- **Merizo (Lau, Kandathil, & Jones 2023)**：深度学习方法，预测域掩码。BiHC 的对比基准。
- **Voronota (Olechnovič & Venclauskas 2014)**：Voronoi 镶嵌计算工具，BiHC 的几何计算基础。
- **STRIDE (Frishman & Argus 1995)**：二级结构分配工具，BiHC 的 SSE 定义来源。
- **Kyte-Doolittle 疏水性标度 (1982)**：亲水性加权的物理基础。
- **CATH (Sillitoe et al. 2020) / ECOD (Schaeffer et al. 2026)**：域注释数据库，BiHC 的基准来源。
- **MMseqs2 (Steinegger & Söding 2017)**：序列聚类工具，用于去冗余。
- **Foldseek (van Kempen et al. 2024)**：结构相似性搜索工具，用于结构去冗余。

## 16 研究想法

> 标题：Agent 生成的研究候选

### 候选 1：物理-学习混合域分割器
- **来源局限/观察**：BiHC 在单域结构上最优但在多域结构上弱于深度学习方法；深度学习方法性能强但决策不可解释。
- **核心假设**：将 BiHC 的 F/G 物理分数作为特征或正则化项注入深度学习模型（如 Chainsaw 的架构），可以兼得物理可解释性和学习表征的表达力。
- **增量**：在 Chainsaw/Merizo 的架构中加入 F 分数作为辅助输入或辅助损失；或在 BiHC 的候选排序阶段用学习到的排序器替代固定阈值 t。
- **初步方法**：在 CONSENSUS-43 上训练一个轻量排序器，输入为 BiHC 各候选分割的 F/G 特征 + 结构几何特征，输出为候选排序；与纯 BiHC 和纯 Chainsaw 对比。
- **验证方式**：CONSENSUS-43/44 基准，报告 exact-K、K-score、IoU、NDO、CSD、DBD；重点分析多域子集。
- **失败模式**：物理特征与学习表征冗余，混合后无增益；或排序器过拟合 tuning set。
- **创新状态**：unverified

### 候选 2：Voronoi 接触面积作为 MD 轨迹的域动态描述符
- **来源局限/观察**：BiHC 的 F 分数是静态结构上的快照；但域边界在 MD 模拟中可能动态变化。
- **核心假设**：沿 MD 轨迹计算 F/G 分数的时间序列可以揭示域的动态稳定性、域间界面的开合事件，以及域边界随构象变化的移动。
- **增量**：将静态域分割扩展到动态域分割（dynamic domain segmentation），为构象采样和 MD 分析提供新工具。
- **初步方法**：选取若干已知域结构的蛋白，运行 μs 级 MD；每帧计算 F/G；聚类 F/G 时间序列，识别域边界移动或域合并/分裂事件。
- **验证方式**：与实验已知的域运动（如 domain swapping、open-closed 构象）对比；检查 F/G 变化是否与构象转变同步。
- **失败模式**：F/G 对热波动过于敏感，时间序列噪声大；或域边界在 MD 中过于稳定，无动态事件可捕捉。
- **创新状态**：unverified

### 候选 3：F 分数作为 AlphaFold 预测结构的域质量评估器
- **来源局限/观察**：AlphaFold 预测结构的域边界可能与实验结构不一致；pLDDT 是残基级置信度，缺乏域级质量度量。
- **核心假设**：BiHC 的 F/G 分数可以评估预测结构的域内自包含性和域间去耦性，从而作为域级置信度指标，辅助识别预测结构中不可靠的域边界。
- **增量**：为 AlphaFold 预测结果提供域级质量评估，补充 pLDDT 的残基级信息。
- **初步方法**：在 CONSENSUS-43 上，对每个结构的 AlphaFold 预测版本计算 F/G；比较预测结构与实验结构的 F/G 差异；训练一个分类器，用 F/G 特征预测域边界是否正确。
- **验证方式**：在独立测试集上评估域边界预测准确率；与 pLDDT 基线对比。
- **失败模式**：F/G 对结构误差不敏感，无法区分正确与错误的域边界；或 pLDDT 已包含足够信息，F/G 无增量。
- **创新状态**：unverified

### 候选 4：基于 F 分数的蛋白设计域边界约束
- **来源局限/观察**：蛋白设计（如 de novo design）中，域边界的合理放置影响折叠和功能；现有设计工具缺乏显式的域边界约束。
- **核心假设**：将 F/G 分数作为设计目标的正则化项，可以引导设计出域间界面弱、域内自包含性强的多域蛋白。
- **增量**：为蛋白设计提供物理可解释的域级目标函数。
- **初步方法**：在现有设计流程（如 RFdiffusion + ProteinMPNN）中，加入 F/G 分数作为可微损失项；设计若干多域蛋白，验证其是否折叠为预期域结构。
- **验证方式**：实验表达和结构验证（或 AlphaFold 预测验证）；与无 F/G 约束的设计对比。
- **失败模式**：F/G 不可微或梯度噪声大，难以优化；或设计出的域边界与天然蛋白差异大，折叠失败。
- **创新状态**：unverified

### 候选 5：双向层次搜索策略迁移到构象聚类
- **来源局限/观察**：BiHC 的双向搜索（top-down 分裂 + bottom-up 合并）避免了单一方向的局部最优；构象聚类（如 MD 轨迹聚类）同样面临层次结构未知的问题。
- **核心假设**：将 BiHC 的双向搜索策略迁移到构象空间聚类，可以比单一方向的层次聚类（如 agglomerative 或 divisive）更鲁棒地识别构象状态层次。
- **增量**：为构象聚类提供新的搜索策略，可能改善对稀有构象和中间态的识别。
- **初步方法**：将 F 分数替换为构象间的距离/相似度度量（如 RMSD、接触图相似度），实现双向层次聚类；在标准 MD 轨迹集上评估。
- **验证方式**：与常见聚类方法（如 GROMOS、DBSCAN、层次聚类）对比，使用 VRC、silhouette 等内部指标和已知构象状态的恢复率。
- **失败模式**：双向搜索的计算成本过高；或构象空间缺乏清晰的层次结构，双向搜索无优势。
- **创新状态**：unverified
