## 02 一句话总结
为解决 PPI 预测中负样本稀缺且质量低、以及评估泄漏导致泛化性虚高的问题，作者构建了包含 26,934 正对与 377,643 负对的 Flock 数据集，并用严格序列/界面相似性与日期截断控制的 Leakage-Free Set 评测，发现 ESMFold2 性能下降而 ESMC 泛化更强。

## 03 研究问题
- **具体问题**：如何构建大规模、高质量、无泄漏的 PPI 负样本数据集，并据此建立严格的基准来评估 PPI 预测模型的真实泛化能力？
- **为什么重要**：PPI 是治疗发现的核心，但计算预测受限于负样本（非互作对）的缺乏与错误；现有模型在正样本上过拟合，泛化性被高估。
- **现有方法不足**：现有模型多基于正样本或随机配对作为负样本；legacy 负样本数据集规模小且含正确性错误；结构建模领域存在评估泄漏（训练/测试序列或界面相似、日期截断未控制）。
- **精确研究问题**：Can a negative-enriched, leakage-controlled PPI dataset reveal significant performance degradation in co-folding models (e.g., ESMFold2) while exposing stronger generalization in protein language models (e.g., ESMC)?

## 04 背景与发展脉络
*标注：此脉络为「仅本文框架」，基于摘要推断，未经外部核验。*
- **阶段 1：早期 PPI 预测**——基于序列/结构特征的传统机器学习，负样本多为随机配对，规模小、噪声高。
- **阶段 2：深度学习 PPI 模型**——GNN、Transformer 等，仍依赖正样本或简单负采样，泛化性差。
- **阶段 3：共折叠结构模型（如 AlphaFold-Multimer、ESMFold2）**——直接预测复合物结构，但训练数据存在泄漏（同源序列/界面重复），评估虚高。
- **阶段 4：蛋白质语言模型（如 ESM 系列）**——从序列进化信息中学习，可能对 PPI 有隐式泛化。
- **本文位置**：在阶段 3→4 之间插入**数据层创新**——提供大规模负样本与泄漏控制基准，作为评测标准。

## 06 核心思想
1. **表面方法**：构建大规模负样本数据集（Flock），整合 PDB 生物组装体与文献挖掘的负样本（用 agentic LLM 工作流），并设计 Leakage-Free Set 基准。
2. **核心洞察**：PPI 预测的瓶颈不在模型架构，而在**数据质量与评估协议**——负样本的可靠性与泄漏控制决定了模型泛化性的可信度；不同模型家族（共折叠 vs 语言模型）对数据泄漏的敏感度不同。
3. **[Analysis] 可能的普适教训**：任何结构预测/生成任务（如构象采样、对接）都应建立「负样本/难例 + 泄漏控制」的评测协议，否则模型对比结论不可靠；LLM 可用于自动化高质量数据标注，但需验证其正确性。

## 07 方法总览
- **输入**：PDB 生物组装体（正样本来源）、科学文献（负样本来源）
- **输出**：Flock 数据集（正/负 PPI 对）、Leakage-Free Set 基准
- **模块**：
  1. 正样本构建：从 PDB 生物组装体提取互作对
  2. 负样本挖掘：用 agentic LLM 工作流从文献中提取高置信非互作对
  3. 泄漏控制：序列相似性、界面相似性、日期截断过滤
- **训练**：不涉及模型训练，仅构建数据集与基准
- **工具**：agentic LLM（具体模型未提供）、PDB 数据库、序列/结构比对工具（推断）
- **反馈回路**：无（静态数据集）
- **假设**：文献中明确标注的非互作对是可靠的负样本；PDB 组装体中的互作对是真实正样本
- **流程**：PDB 组装体 → 正样本提取 → 文献挖掘（LLM 辅助）→ 负样本提取 → 相似性与日期过滤 → Flock 数据集 → 划分 Leakage-Free Set → 评测 ESMFold2 与 ESMC

## 11 结论正确解读
- **任务范围**：仅限 PPI 二分类/结构预测的泛化性评测，不涉及新模型提出。
- **oracle/真值输入**：正样本来自 PDB 实验结构，负样本来自文献挖掘（LLM 辅助），真值可靠性依赖文献标注质量。
- **端到端状态**：数据集构建完成，但未提供下游任务端到端训练结果。
- **算力成本**：未提供。
- **历史数据依赖**：日期截断用于模拟训练时点，但具体日期未提供。
- **模型依赖**：评测仅覆盖 ESMFold2 与 ESMC，不代表所有共折叠/语言模型。
- **最难情形**：Leakage-Free Set 中序列/界面相似性极低的 PPI 对，模型表现未知。
- **不确定性**：负样本的 LLM 挖掘可能存在系统性错误，未提供人工验证率。
- **有边界复述**：在 Flock 数据集与 Leakage-Free Set 协议下，ESMFold2 的泛化性显著低于其在 legacy 基准上的表现，而 ESMC 表现更稳定；该结论仅适用于所测模型与数据划分，不推广至所有 PPI 预测方法。

## 14 学到什么
**Agent 提炼的知识候选**：
1. **负样本工程**：PPI 预测中，负样本的规模与质量比模型架构更关键；可用 LLM 自动化挖掘文献负样本，但需置信度筛选。
2. **泄漏控制协议**：结构预测任务应严格过滤序列/界面相似性与日期截断，否则评估结果虚高；此协议可迁移至构象采样、分子对接等任务。
3. **模型家族差异**：共折叠模型（如 ESMFold2）对数据泄漏敏感，而蛋白质语言模型（如 ESMC）泛化更稳；提示在结构预测中可考虑语言模型作为替代或补充。
4. **基准设计**：数据集论文应提供「难例子集」（如 Leakage-Free Set）作为标准评测协议，增强模型对比的可信度。
5. **LLM 用于数据标注**：agentic LLM 工作流可扩展到其他生物数据（如突变效应、结合亲和力）的自动化标注，但需人工验证。
