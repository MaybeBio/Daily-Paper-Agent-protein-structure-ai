## 02 一句话总结
Genolator 通过将 DNA 序列（Evo2）、氨基酸序列（ESM2）和蛋白质结构（PST）的嵌入投影为虚拟 token 并与 Llama-3 8B 联合微调，在 365,000+ QA 对训练后，能够以自然语言问答形式准确确认或否认蛋白质的 GO 功能关联（F1≈0.98, MCC=0.959），优于 GPT-4.1 和 XGBoost 基线。

## 03 研究问题
- **具体问题**: 如何让非技术用户通过自然语言交互，对给定基因/蛋白质序列进行功能解读（亚细胞定位、分子功能、生物学过程）？
- **为什么重要**: 基因组数据量激增，但功能注释仍依赖专家和耗时实验；现有计算方法多为黑箱预测，缺乏可解释性和交互性，且难以整合多源信息（DNA、序列、结构）。
- **现有方法不足**:
  - 通用 LLM（如 GPT-4.1）无法直接处理原始 DNA/蛋白质序列，且会产生幻觉（如虚假记忆、氨基酸乱码）。
  - 专用预测模型（如 XGBoost）缺乏生成能力和自然语言交互。
  - 现有基因组 LLM 仅处理单一模态（DNA 或蛋白质），未融合结构信息。
- **精确研究问题**: Can a multimodal LLM that fuses DNA, amino acid sequence, and protein structure embeddings with natural language queries accurately confirm/deny and generate GO-based functional annotations for unseen proteins?

## 06 核心思想
1. **表面方法**: 将三种生物模态（DNA 序列、氨基酸序列、蛋白质结构）分别通过预训练编码器（Evo2、ESM2、PST）提取嵌入，经可学习的线性投影器映射为 LLM 的虚拟 token，与自然语言问题拼接后输入 Llama-3 8B 进行指令微调。

2. **核心洞察**: 
   - **结构信息 > 序列信息**：PST（结构增强）嵌入比 ESM2（纯序列）嵌入带来更大的性能提升（消融损失 3.31% vs 0.51%），说明蛋白质三维结构对功能解读的贡献远超一级序列。
   - **冻结编码器 + 可训练投影器**：保持 Evo2/ESM2/PST 权重冻结，仅训练投影器和 LLM，既保留预训练知识又降低计算成本。
   - **虚拟 token 作为跨模态桥梁**：将高维生物嵌入压缩为 LLM 可理解的 token 序列，实现生物信息与自然语言的统一表示空间。
   - **自然语言作为交互界面**：将功能预测重构为问答任务，使非技术用户可直接查询，同时通过确认/否认问题设计实现可验证的二元判断。

3. **可能的普适教训** [Analysis]: 
   - 多模态融合中，**模态的信息密度差异**决定了其贡献权重——结构 > 序列 > 文本，这提示在设计融合策略时应优先考虑信息量最大的模态。
   - **冻结基础模型 + 轻量适配器**是高效的多模态集成范式，可避免灾难性遗忘和巨额训练成本。
   - 将预测任务重构为问答格式，不仅提升可用性，还能利用 LLM 的生成能力输出解释性内容，而不仅是标签。

## 07 方法总览
- **输入**: 
  - DNA 序列（基因的 cDNA 序列，含 UTR）
  - 氨基酸序列（对应蛋白质）
  - 蛋白质结构（AlphaFold 数据库 PDB 文件）
  - 自然语言问题（如 "Is this protein involved in DNA repair?"）
- **输出**: 自然语言回答（确认/否认 + 解释），或开放问答的生成文本
- **模块**:
  1. **Evo2 (7B)**：DNA 序列编码器，提取 4096 维嵌入
  2. **ESM2 (3B)**：氨基酸序列编码器，提取 2560 维嵌入
  3. **PST (Protein Structure Transformer)**：结构增强序列编码器，提取 1280 维嵌入
  4. **虚拟 token 投影器**：3 个线性层，将各模态嵌入映射到 Llama 隐藏维度 (4096)
  5. **Llama-3 8B (Bio-Medical-Llama-3)**：基座 LLM，处理拼接后的 token 序列
- **训练**:
  - 数据: 365,000+ QA 对（确认/否认 + 开放问答），基于 MANE Select v1.4 的 ~18,000 个基因
  - 策略: 冻结 Evo2/ESM2/PST，微调投影器 + Llama（LoRA, rank 未提供）
  - 优化: 学习率 5×10⁻⁵，batch size 8，最多 10 epochs，early stopping (patience=2)
  - 数据划分: 相似性感知 KMeans 聚类（k=3），80/10/10 训练/验证/测试
- **评估**:
  - 二元分类: 确认/否认任务，指标 Accuracy, Precision, Recall, F1, MCC
  - 开放问答: LLM-as-judge（GPT-4.1）将生成答案映射到 GO Slim terms，计算重叠率
- **流程**: 用户输入问题 + 序列 → 编码器提取嵌入 → 投影为虚拟 token → 与问题 token 拼接 → Llama 生成回答

## 09 关键公式符号
*（本文为深度学习应用型论文，核心公式较少，以下为理解所需的关键数学描述）*

1. **虚拟 token 投影**:
   - 对每个模态 m ∈ {DNA, protein, structure}，嵌入 E_m 经线性变换:
   - **T_m = W_m · E_m + b_m**
   - 其中 T_m ∈ R^(8×4096) 为虚拟 token 序列，W_m 为可学习权重矩阵，b_m 为偏置
   - 用途: 将不同维度的生物嵌入统一映射到 LLM 的 token 空间
   - 直觉: 类似多模态 LLM 中的 "adapter" 或 "projector" 层

2. **嵌入归一化**:
   - 各模态嵌入在拼接前进行 L2 归一化，确保尺度一致
   - 用途: 防止某一模态因数值范围大而主导训练

3. **交叉熵损失**（训练目标）:
   - **L = -Σ log P(y_t | y_<t, T_DNA, T_prot, T_struct, T_prompt)**
   - 标准自回归语言建模损失，条件于虚拟 token 和问题 token
   - 用途: 微调 Llama 生成准确回答

4. **MCC（Matthews 相关系数）**:
   - **MCC = (TP·TN - FP·FN) / √[(TP+FP)(TP+FN)(TN+FP)(TN+FN)]**
   - 用途: 评估二元确认/否认分类性能，对类别不平衡更稳健

5. **余弦相似度**（表示分析）:
   - **cos(A,B) = (A·B) / (||A|| · ||B||)**
   - 用途: 量化 GO term 嵌入之间的语义/功能相似性

## 11 结论正确解读
- **任务范围**: 本文仅针对人类蛋白质编码基因的 GO 功能注释（三个 aspect: BP/MF/CC），不涉及非编码元件、其他物种或更细粒度的功能预测。
- **输入要求**: 需要 DNA 序列、氨基酸序列和蛋白质结构（AlphaFold 预测）三模态输入，实际应用中需先获得这些数据。
- **性能边界**: 在确认/否认任务上表现优异（MCC=0.959），但开放问答的完全匹配率仅 2.51-5.83%，说明生成精确功能注释的能力有限。
- **基线比较**: 与 GPT-4.1 的比较中，GPT-4.1 仅使用文本序列输入，未经过微调，可能低估了其在更优提示工程下的表现。
- **数据依赖**: 训练数据由 GPT-4.1 生成，存在潜在的标签噪声和偏差；KMeans 划分虽减少泄露，但聚类边界可能影响泛化评估。
- **计算成本**: 需要 Evo2 (7B) + ESM2 (3B) + PST 三个编码器进行推理，实际部署成本较高。
- **因果性**: 本文展示的是关联性功能注释，不涉及因果机制解释；"功能"指 GO 注释关联，非实验验证的功能。

## 14 学到什么
**Agent 提炼的知识候选**:

1. **多模态融合策略**: 将不同生物模态（DNA、序列、结构）通过预训练编码器提取嵌入，再经轻量投影器映射为 LLM 虚拟 token，是高效的多模态集成范式。可迁移至蛋白质设计任务，如将结构约束（来自 AlphaFold 或 MD 模拟）与序列信息融合用于生成式设计。

2. **冻结编码器 + 微调 LLM**: 保持 Evo2/ESM2/PST 冻结，仅训练投影器和 LLM，既保留预训练知识又降低计算成本。此策略可迁移至其他蛋白质相关任务，如将 MD 模拟轨迹编码为 token 输入 LLM 进行动态性质问答。

3. **结构信息 > 序列信息**: 消融实验表明 PST（结构增强）嵌入贡献远大于 ESM2（序列）嵌入（3.31% vs 0.51% 损失）。这提示在蛋白质功能预测中，结构信息是更关键的特征，可指导未来模型设计优先考虑结构模态。

4. **问答格式重构预测任务**: 将功能预测重构为确认/否认 + 开放问答，不仅提升可用性，还能利用 LLM 生成解释性内容。可迁移至蛋白质设计中的约束满足检查，如 "Does this mutation preserve the active site?"。

5. **相似性感知数据划分**: 使用 KMeans 在嵌入空间聚类后划分数据，比随机划分更严格地评估泛化能力。此方法可迁移至任何蛋白质 ML 任务，避免同源蛋白跨集泄露。

6. **注意力分析 + 消融结合**: 同时使用注意力权重分析和 token 消融实验评估模态重要性，避免单一方法的偏差。可迁移至多模态蛋白质模型的可解释性分析。

7. **LLM-as-judge 评估生成任务**: 使用 GPT-4.1 将生成文本映射到 GO terms 进行评估，解决开放问答的自动评估难题。可迁移至蛋白质设计生成序列的功能评估。

## 15 与已有知识连接
- **Evo2 (Brixi et al., 2025)**：基因组基础模型，本文使用其提取 DNA 嵌入。Evo2 的 7B 版本支持长达 1M token 的 DNA 上下文，本文利用其编码完整 cDNA 区域。
- **ESM2 (Lin et al., 2023)**：蛋白质语言模型，本文使用其提取氨基酸序列嵌入。ESM2 已在结构预测、功能预测等任务中广泛验证。
- **PST (Hartout et al.)**：蛋白质结构 transformer，本文使用其生成结构增强的序列嵌入。PST 将 AlphaFold 结构信息注入 ESM 嵌入。
- **ChatNT (Chatterjee et al.)**：本文明确对比的模型，基于 Nucleotide Transformer 的对话代理。差异在于 ChatNT 不支持蛋白质结构信息，且未训练 GO 功能预测。
- **AlphaFold (Jumper et al., 2021; Varadi et al., 2024)**：本文使用 AlphaFold 数据库的结构作为 PST 输入，体现结构预测与功能解读的衔接。
- **GO 功能预测传统方法 (DeepGO, ProteinBERT)**：本文的 XGBoost 基线代表传统方法，Genolator 的生成能力是核心差异。
- **多模态 LLM 架构 (LLaVA, LLaMA-Adapter)**：本文的虚拟 token 投影策略与视觉-语言模型中的 adapter 方法类似，但应用于生物序列模态。
- **LoRA (Hu et al., 2022)**：参数高效微调方法，本文用于微调 Llama-3 8B。

## 16 研究想法
**Agent 生成的研究候选**:

1. **候选名称**: MD-Genolator: 融合分子动力学模拟轨迹的蛋白质构象功能问答
   - **来源局限/观察**: Genolator 使用静态 AlphaFold 结构，但蛋白质功能常依赖构象动态；MD 模拟可提供构象 ensemble 信息。
   - **核心假设**: 将 MD 轨迹编码为时序 token 输入 LLM，可回答关于构象变化、变构效应、动力学稳定性等功能问题。
   - **初步方法**: 使用 MD 模拟生成构象轨迹 → 降维/聚类提取代表性构象 → 用结构编码器（如 PST）编码 → 时序拼接为虚拟 token → 微调 LLM 进行功能问答。
   - **验证方式**: 在已知变构蛋白（如 GPCR、激酶）上测试，对比静态结构输入的 Genolator。
   - **创新状态**: unverified

2. **候选名称**: Struct2Seq-Gen: 基于结构约束的蛋白质序列生成与功能验证
   - **来源局限/观察**: Genolator 是判别式功能解读，未涉及生成；蛋白质设计需要从结构/功能约束生成序列。
   - **核心假设**: 将结构嵌入（PST）与 LLM 生成能力结合，可生成满足特定功能约束的蛋白质序列。
   - **初步方法**: 将目标结构嵌入作为条件 token，微调 LLM 进行序列生成；使用 GO term 作为功能约束；结合 Rosetta/AlphaFold 验证生成序列的结构可行性。
   - **验证方式**: 在已知酶家族上测试，评估生成序列的活性保留率、结构稳定性。
   - **创新状态**: unverified

3. **候选名称**: MutantChat: 突变效应的多模态自然语言解释
   - **来源局限/观察**: Genolator 处理野生型序列，未涉及突变效应；临床遗传学需要变异功能解读。
   - **核心假设**: 将突变前后序列/结构嵌入对比输入 LLM，可生成变异致病性的自然语言解释。
   - **初步方法**: 对同一蛋白的野生型和突变型分别编码 → 计算嵌入差异 → 作为额外 token 输入 LLM → 微调生成变异解释。
   - **验证方式**: 在 ClinVar 数据集上测试，对比 Pathogenic/Benign 分类准确率和解释质量。
   - **创新状态**: unverified

4. **候选名称**: CrossSpecies-Func: 跨物种蛋白质功能迁移学习
   - **来源局限/观察**: Genolator 仅训练人类基因，跨物种泛化未知。
   - **核心假设**: 多模态嵌入（DNA+序列+结构）具有跨物种可迁移性，可零样本预测非人类蛋白质功能。
   - **初步方法**: 在人类数据上训练，在模式生物（小鼠、斑马鱼、酵母）上零样本测试；分析嵌入空间中的物种聚类结构。
   - **验证方式**: 使用模式生物 GO 注释数据库评估零样本性能。
   - **创新状态**: unverified

5. **候选名称**: StructAware-FuncPretrain: 结构感知的蛋白质功能基础模型预训练
   - **来源局限/观察**: Genolator 依赖预训练编码器（Evo2/ESM2/PST），未针对功能任务联合预训练。
   - **核心假设**: 在更大规模数据上联合预训练多模态编码器 + LLM，可提升功能预测的泛化性和鲁棒性。
   - **初步方法**: 使用 UniProt/Swiss-Prot 注释数据构建预训练语料；设计结构-序列-DNA 对齐的预训练任务；对比 Genolator 的微调策略。
   - **验证方式**: 在多个功能预测 benchmark（CAFA、GOA）上评估。
   - **创新状态**: unverified
