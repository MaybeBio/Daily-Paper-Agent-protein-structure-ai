## 02 一句话总结
本文构建了 ThermoMutDB 2.0，通过将大语言模型与规则实体识别结合、辅以专家验证的半自动化文献筛选流程，从 5,934 篇候选文献中筛选出 254 篇供专家评审，最终纳入 102 篇文献和 1,763 条新的蛋白质突变热稳定性数据，并为每条突变生成突变体结构模型以实现三维结构上下文可视化。

## 03 研究问题
- **具体问题**：如何从海量生物医学文献中高效、准确地提取蛋白质突变的热稳定性实验数据，并将其与结构信息关联，以支持蛋白质稳定性研究与预测模型开发？
- **为什么重要**：蛋白质热稳定性数据是理解蛋白质结构-功能关系、突变分子后果及疾病机制的基础。然而，这类数据分散在数十年的大量文献中，人工提取耗时费力，且数据质量直接影响下游预测模型的训练与评估。
- **现有方法不足**：传统文献挖掘依赖纯人工筛选，效率低、可扩展性差；已有的自动化方法（如基于规则或简单文本匹配）在识别相关文献时精度有限，难以处理复杂的生物医学文本表述。此外，现有数据库（如 ThermoMutDB 1.0）缺乏系统性的结构信息整合，无法提供突变的三维结构上下文。
- **精确研究问题**：Can a human-in-the-loop pipeline combining large language models with rule-based entity recognition achieve scalable and accurate literature triage for protein thermostability data, while systematically enriching curated mutations with structural models?

## 06 核心思想
1. **表面方法**：构建一个三阶段流水线——(1) LLM 结合规则 NER 对文献进行初筛与优先级排序；(2) 专家对高优先级文献进行人工审阅与数据提取；(3) 对提取的突变数据自动生成突变体结构模型，实现结构富集。
2. **核心洞察**：文献挖掘的瓶颈不在于「能否找到相关论文」，而在于「如何在可接受的精度下高效缩小候选范围」。LLM 的语义理解能力可以大幅压缩人工审阅的文献量（从 5,934 篇压缩到 254 篇，压缩率约 95.7%），而规则 NER 提供可解释的实体锚点，专家验证保证最终数据质量。结构富集则使数据从「序列+数值」升级为「结构+数值」，直接对接结构预测与稳定性预测的交叉需求。
3. **可能的普适教训** [Analysis]：在生物医学数据挖掘中，「人机协同」比「全自动」更现实——LLM 负责缩小搜索空间，规则方法提供确定性锚点，人类负责最终判断。这种「漏斗式」架构可迁移到其他数据密集型任务（如突变致病性注释、蛋白质-配体相互作用数据提取等）。

## 07 方法总览
- **输入**：PubMed 检索到的候选文献（时间跨度 1976 年 1 月至 2026 年最近一次检索），共 5,934 篇。
- **输出**：1,763 条新的蛋白质突变热稳定性数据条目，每条包含突变信息、热力学参数（如 ΔΔG、Tm 变化等）及对应的突变体结构模型。
- **模块**：
  1. **文献检索模块**：从 PubMed 获取候选文献。
  2. **LLM 初筛模块**：使用大语言模型对文献标题/摘要进行分类，判断是否涉及蛋白质突变热稳定性实验测量。
  3. **规则 NER 模块**：基于规则识别文献中的蛋白质名称、突变位点、热力学参数等实体，辅助 LLM 判断。
  4. **优先级排序模块**：综合 LLM 与 NER 结果，对文献进行优先级打分。
  5. **专家审阅模块**：高优先级文献由专家人工审阅，提取数据并验证。
  6. **结构富集模块**：对纳入的突变，使用结构预测工具（如 AlphaFold 或同源建模）生成突变体结构模型。
- **训练**：未提及 LLM 的微调，推测使用预训练模型（如 GPT 系列）进行零样本或少样本分类。
- **工具**：LLM（具体型号未提供）、规则 NER 系统、结构预测工具（具体未提供）。
- **反馈回路**：专家审阅结果可反馈至 LLM 提示词或 NER 规则，优化后续筛选（作者未明确说明，[Analysis] 推测存在此机制）。
- **假设**：LLM 能有效识别相关文献；规则 NER 能提供可靠的实体锚点；结构预测模型能生成合理的突变体结构。

## 14 学到什么
**Agent 提炼的知识候选**：

1. **人机协同的文献筛选漏斗架构**：LLM 初筛 → 规则 NER 锚定 → 专家终审的三级漏斗，可迁移到蛋白质结构相关计算研究中的任何文献挖掘任务（如突变致病性注释、蛋白质-配体相互作用数据提取、MD 模拟参数收集）。本课题可借鉴此架构构建「蛋白质构象变化文献数据库」或「突变-功能关系知识库」。

2. **结构富集作为数据增值策略**：将突变数据与预测结构关联，使数据从「序列+数值」升级为「结构+数值」。本课题可迁移此思路——在构建稳定性预测训练集时，不仅存储 ΔΔG 值，还存储突变体的三维结构，使下游模型能同时利用序列与结构特征。

3. **LLM 用于生物医学文本分类的可行性**：LLM 能有效压缩候选文献量（压缩率 95.7%），说明其在生物医学文献筛选中具有实用价值。本课题可探索用 LLM 自动提取 MD 模拟论文中的力场参数、模拟时长、温度等元数据，构建模拟参数数据库。

4. **专家验证作为质量保障的必要性**：即使 LLM 表现良好，最终仍需专家验证。本课题在设计自动化数据提取流程时，应保留人工审核环节，确保数据质量。

5. **数据库可持续更新的设计原则**：半自动化流程使数据库更新更可持续。本课题若构建类似资源（如蛋白质构象数据库），应采用可扩展的自动化流程，而非一次性人工整理。

- **ProTherm**：经典的蛋白质热力学稳定性数据库，ThermoMutDB 系列与其存在数据重叠与互补。本课题可对比两者数据覆盖与质量。
- **AlphaFold 及相关结构预测工具**：本文的结构富集模块依赖结构预测工具，与蛋白质结构预测方向直接相关。本课题可借鉴其「预测结构用于数据注释」的思路。
- **LLM 在生物医学文本挖掘中的应用**：近年来 LLM 被广泛用于文献分类、信息提取（如 BioBERT、GPT 系列）。本文是这一趋势在蛋白质稳定性数据领域的应用实例。
- **ΔΔG 预测模型**：如 DDGun、FoldX、Rosetta 等稳定性预测工具，其训练数据部分来源于 ThermoMutDB 类数据库。本文新增的数据条目可直接用于改进这类预测模型。
- **候选方向** [Analysis]：本文未提及与 MD 模拟数据的整合。本课题可探索将 ThermoMutDB 2.0 的突变数据与 MD 模拟结果（如突变体的构象 ensemble）关联，构建「实验热力学数据 + 模拟构象」的多模态数据集。

## 16 研究想法
**Agent 生成的研究候选**：

1. **候选名称**：LLM 驱动的蛋白质-配体相互作用文献自动提取系统
   - **来源局限/观察**：本文展示了 LLM 在蛋白质突变热稳定性文献筛选中的有效性，但未涉及蛋白质-配体相互作用数据。本课题（分子对接方向）同样面临文献数据分散的问题。
   - **核心假设**：LLM 能有效从文献中提取蛋白质-配体结合亲和力数据及对接构象信息。
   - **初步方法**：借鉴本文的三级漏斗架构，用 LLM 筛选候选文献，规则 NER 提取蛋白质/配体/亲和力实体，专家验证，并关联对接构象。
   - **验证方式**：与 PDBbind、BindingDB 等现有数据库对比覆盖率和精度。
   - **创新状态**：unverified

2. **候选名称**：突变热稳定性数据与 MD 模拟构象的多模态关联数据库
   - **来源局限/观察**：ThermoMutDB 2.0 提供突变体的静态结构模型，但未包含构象动态信息。MD 模拟可提供突变对蛋白质构象 ensemble 的影响，两者结合可更全面理解稳定性机制。
   - **核心假设**：将实验 ΔΔG 数据与 MD 模拟的构象特征（如 RMSF、氢键网络变化）关联，可提升稳定性预测模型的准确性和可解释性。
   - **初步方法**：对 ThermoMutDB 2.0 中的突变体进行 MD 模拟，提取构象特征，训练多模态预测模型（序列+结构+动态特征）。
   - **验证方式**：在独立测试集上比较多模态模型与仅序列/结构模型的预测精度。
   - **创新状态**：unverified

3. **候选名称**：基于 LLM 的 MD 模拟参数文献挖掘与标准化
   - **来源局限/观察**：MD 模拟论文中的力场参数、模拟条件（温度、盐浓度、模拟时长）等元数据分散且格式不统一，难以系统化利用。
   - **核心假设**：LLM 能从 MD 模拟论文中自动提取并标准化模拟参数，构建可查询的模拟参数数据库。
   - **初步方法**：用 LLM 从 MD 论文中提取参数，规则 NER 锚定关键实体，专家验证，建立标准化 schema。
   - **验证方式**：人工抽样评估提取准确率，与现有模拟数据库（如 MDDB）对比。
   - **创新状态**：unverified

4. **候选名称**：AlphaFold 预测结构在热稳定性数据注释中的不确定性传播分析
   - **来源局限/观察**：ThermoMutDB 2.0 使用预测结构进行结构富集，但预测结构本身有不确定性，可能影响下游分析。
   - **核心假设**：AlphaFold 预测结构的局部不确定性（pLDDT）与突变热稳定性数据的可靠性存在相关性。
   - **初步方法**：分析 ThermoMutDB 2.0 中突变位点的 pLDDT 值与 ΔΔG 数据的一致性，评估低置信度区域的突变数据是否更易出错。
   - **验证方式**：与实验解析结构中的突变数据对比，统计低 pLDDT 区域的 ΔΔG 异常率。
   - **创新状态**：unverified

5. **候选名称**：面向蛋白质稳定性预测的主动学习文献筛选框架
   - **来源局限/观察**：本文的流水线依赖专家终审，但未利用已标注数据来优化 LLM 筛选策略。
   - **核心假设**：主动学习策略（根据专家反馈迭代优化 LLM 提示）能进一步提升筛选精度，减少专家工作量。
   - **初步方法**：将专家审阅结果作为反馈信号，迭代调整 LLM 提示词或微调小模型，形成闭环优化。
   - **验证方式**：对比固定提示与主动学习策略的精度-成本曲线。
   - **创新状态**：unverified
