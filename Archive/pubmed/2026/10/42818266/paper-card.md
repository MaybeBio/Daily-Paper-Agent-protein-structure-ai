## 02 一句话总结
T-REX 通过 LLM 智能体在多个蛋白质生成模型与结构评估器之间进行自适应决策（rescue/explore/exploit），在有限算力预算下实现跨七个靶点的最高结构新颖 hit 吞吐量。

## 03 研究问题
- **具体问题**：面对日益增多的蛋白质设计工具（生成模型 + 结构评估器），如何在有限算力预算下自动、高效地编排这些工具以最大化设计产出（尤其是结构新颖的 hit）？
- **为什么重要**：单一模型各有优劣，但手动组合多个工具需要大量专家经验和试错；算力有限时，如何分配资源成为实际瓶颈。
- **现有方法不足**：现有工作多聚焦于改进单一生成模型或评估器，缺乏系统性的多工具编排策略；固定流水线（pipeline）无法根据中间结果动态调整资源分配。
- **精确研究问题**：Can an LLM-driven agentic controller adaptively allocate compute across diverse generative models and evaluators to achieve higher throughput of structurally distinct hits than any fixed orchestration baseline?

## 04 背景与发展脉络
*（标注：以下脉络为「仅本文框架」，基于摘要推断，未经外部核验）*
- **阶段一：单模型设计**——早期 de novo binder 设计依赖单一生成模型（如 RFdiffusion 类方法），优点：简单直接；局限：模型能力有限，hit 率低。
- **阶段二：生成 + 评估流水线**——引入结构评估器（如 AlphaFold 或能量函数）对生成候选进行筛选，优点：提高 hit 精度；局限：流水线固定，无法根据中间结果调整。
- **阶段三：多模型集成**——组合多个生成模型与评估器，优点：覆盖更广序列/结构空间；局限：资源分配静态，缺乏目标适应性。
- **本文位置**：提出 T-REX，将 LLM 智能体作为「编排层」，在生成-评估循环中动态决策，实现目标自适应的算力分配，代表从「静态流水线」向「agentic campaign control」的转变。

## 06 核心思想
1. **表面方法**：构建一个 agentic 框架 T-REX，包含 LLM 智能体（负责决策）和确定性控制器（负责验证与调度），在生成-评估循环中执行 rescue/explore/exploit 三种动作。
2. **核心洞察**：设计工作流不应是静态的，而应像「科学实验」一样根据累积结果动态调整策略；LLM 的推理能力可以充当「策略制定者」，而确定性控制器保证动作的可行性与安全性。
3. **可能的普适教训** [Analysis]：在计算生物学中，模型性能的提升不仅来自更好的单一模型，也可能来自更聪明的「模型使用策略」；LLM 作为编排层可以低成本地桥接多个专用工具，这一思路可迁移到其他多步骤计算任务（如 MD 模拟 + 对接 + 结构预测的组合）。

## 07 方法总览
- **输入**：目标蛋白结构（靶点）、算力预算、可用工具集（多个生成模型 + 结构评估器）
- **输出**：结构新颖的 binder 候选集合（hits）
- **模块**：
  1. LLM 智能体（决策模块）：根据历史结果推理，选择 rescue/explore/exploit
  2. 确定性控制器（执行模块）：验证智能体提议的动作，调度具体工具
  3. 生成模型池：多个 SOTA 蛋白质生成模型
  4. 结构评估器池：多个结构评估工具
- **训练**：未提及显式训练；LLM 可能为预训练模型，控制器为规则驱动
- **工具**：LLM（具体型号未提供）、生成模型与评估器（具体名称未提供）
- **反馈回路**：生成候选 → 评估 → 结果反馈给 LLM 智能体 → 智能体调整下一步动作
- **假设**：LLM 能基于累积结果做出优于固定策略的决策；确定性控制器能保证动作合法性
- **流程**：初始化 → LLM 根据当前状态选择动作（rescue 失败但接近的候选 / explore 新设置 / exploit 成功路线）→ 控制器验证并调度工具 → 生成与评估 → 更新状态 → 循环直至算力耗尽

## 14 学到什么
**Agent 提炼的知识候选**：
1. **LLM 作为编排层**：将 LLM 智能体用于多工具调度，而非直接生成结构，可低成本桥接多个专用模型——可迁移至「AlphaFold + MD 模拟 + 对接」的复合工作流，用 LLM 决定何时运行哪个工具。
2. **Rescue/Explore/Exploit 动作空间**：将设计过程显式建模为三类动作，结构清晰且可解释，可迁移至其他蛋白质设计任务（如序列设计中的局部优化）。
3. **目标自适应算力分配**：不同靶点可能需要不同方法组合，这一思想可迁移至「结构预测中的多模型集成」，根据输入序列特征动态选择预测器。
4. **确定性控制器 + 智能体决策分离**：用规则层保证安全性、用 LLM 层保证灵活性，这一架构可迁移至任何需要「AI 决策 + 物理约束」结合的场景（如 MD 模拟中的自适应步长控制）。
5. **吞吐量作为核心指标**：在算力受限时，以「单位算力的结构新颖 hit 数」为优化目标，而非单纯追求 hit 率，这一指标设计可迁移至高通量筛选任务。

## 15 与已有知识连接

- **组合关系**：可与 RFdiffusion、AlphaFold 等具体工具组合使用，T-REX 作为上层调度器；与主动学习（active learning）互补，T-REX 的 explore 动作可视为主动采样的变体。
- **冲突观点**：若固定流水线经过精心调优，可能在某些靶点上优于 T-REX；本文未提供此类对比。
- **可迁移领域**：分子对接中的多打分函数融合、MD 模拟中的多力场选择、蛋白质结构预测中的多模型集成，均可借鉴「agentic orchestration」思路。
- **候选方向** [Analysis]：将 T-REX 的编排思想应用于「AlphaFold 预测 + MD 精修」的循环，用 LLM 决定何时停止预测、何时启动模拟，可能提升结构预测精度。

## 16 研究想法
**Agent 生成的研究候选**：

1. **候选名称**：LLM 驱动的 MD 模拟自适应协议选择
   - **来源局限/观察**：MD 模拟中力场、步长、溶剂模型的选择依赖经验，且不同体系最优设置不同。
   - **核心假设**：LLM 能基于体系特征与中间模拟结果，动态选择/调整 MD 协议，优于固定协议。
   - **相对本文增量**：将 T-REX 的 orchestration 思想从「生成模型」迁移至「物理模拟参数空间」。
   - **初步方法**：构建 LLM 智能体，输入体系信息+模拟轨迹摘要，输出力场/步长调整建议；确定性控制器验证参数合法性。
   - **验证方式**：在多个蛋白-配体体系上对比固定协议与自适应协议的采样效率与结构精度。
   - **可能的失败模式**：LLM 建议可能过于保守或激进，导致模拟不稳定；参数空间过大时决策质量下降。
   - **创新状态**：unverified

2. **候选名称**：多结构预测器集成中的目标自适应选择
   - **来源局限/观察**：AlphaFold 等预测器在不同靶点类型上表现各异，固定集成策略未充分利用各自优势。
   - **核心假设**：基于输入序列特征与中间预测置信度，LLM 可动态选择最优预测器或组合方式。
   - **相对本文增量**：将 T-REX 的 target-adaptive 思想应用于结构预测而非 binder 设计。
   - **初步方法**：训练/使用 LLM 分类器，输入序列特征+各预测器置信度，输出预测器选择或加权方案。
   - **验证方式**：在 CAMEO 或 CASP 基准上对比自适应集成与固定集成的预测精度。
   - **可能的失败模式**：特征与预测器性能的关联性弱，LLM 决策无实质增益。
   - **创新状态**：unverified

3. **候选名称**：Rescue-Explore-Exploit 框架用于构象采样
   - **来源局限/观察**：构象采样中，局部优化（rescue）、新构象探索（explore）与已知通路利用（exploit）的平衡难以手动调优。
   - **核心假设**：将采样过程显式建模为三类动作，由 LLM 根据累积能量/多样性指标决策，可提升采样效率。
   - **相对本文增量**：将 T-REX 的动作空间直接映射至构象采样任务。
   - **初步方法**：在 MD 或蒙特卡洛采样中嵌入 LLM 决策层，周期性选择 rescue/explore/exploit 动作。
   - **验证方式**：在标准构象采样基准（如迪拉克肽）上对比自适应采样与固定策略的构象覆盖度。
   - **可能的失败模式**：LLM 决策延迟过高，无法实时响应；动作空间定义不匹配采样动力学。
   - **创新状态**：unverified

4. **候选名称**：算力预算感知的蛋白质设计工作流优化
   - **来源局限/观察**：T-REX 强调有限算力下的分配，但未提供预算-收益的定量模型。
   - **核心假设**：可建立预算-收益函数，指导 LLM 智能体在给定预算下做出更优的资源配置决策。
   - **相对本文增量**：为 T-REX 类框架增加理论化的预算优化层。
   - **初步方法**：收集不同靶点/方法组合的算力-收益数据，拟合预算-收益曲线，嵌入 LLM 决策提示。
   - **验证方式**：在固定预算下对比有/无预算模型的 hit 产出。
   - **可能的失败模式**：收益函数难以泛化，过拟合特定靶点。
   - **创新状态**：unverified
