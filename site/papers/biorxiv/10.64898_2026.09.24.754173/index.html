RNASeek: A Cross-Phyla Generative Foundation Model for Multipurpose RNA Modeling and Reinforcement Learning-Based Design

Shiyuan Chen; Neil R. Fernandes; Wei Vivian Li; Lili Wang; Zhenyu Jia; Joy S. Xiang
bioRxiv 预印本 · 2026-09-28 · 仅摘要 · 原文

该文提出RNA生成式基础模型RNASeek，用于RNA序列建模与功能设计，虽对象为RNA而非蛋白质，但其预训练-预测-强化学习优化框架可迁移至蛋白质结构/序列设计，对课题有借鉴价值。

摘要

RNA plays central roles in regulating information flow and provides a versatile substrate for engineering biological functions. While large language models (LLMs) have transformed natural language processing and protein design, a general framework connecting RNA foundation models to functional sequence design remains limited. Here, we present RNASeek, a 1.6-billion-parameter generative foundation model built on a DeepSeek architecture and trained on a cross-phyla transcriptomic corpus for RNA sequence representation and generation. Natural-language tokens enable flexible conditional prediction and sequence design using a unified backbone. RNASeek captures species-specific transcript features and intron–exon boundaries in a zero-shot setting. We then fine-tune RNASeek to predict ribozyme self-cleavage activity and viral mRNA stability, revealing interpretable sequence features associated with function, including ribozyme loop flexibility and stem stability, as well as AU-rich motifs associated with mRNA stability. We use these functional predictors as reward models and apply Group Relative Policy Optimization (GRPO) to update RNASeek’s generation policy toward sequences with desired properties. GRPO-guided generation produces faster-cleaving ribozymes and stability-enhancing 3′ UTRs while satisfying user-specified IUPAC constraints. Experimentally validated RNASeek-generated ribozymes achieve wild-type levels of activity, while RNASeek-generated 3′ UTR sequences exceed the performance of the training data and benchmarked AI-generated 3′ UTRs. Together, RNASeek establishes a unified pretrain–predict–optimize framework that connects learned RNA function to controllable de novo sequence design and provides a general strategy for engineering regulatory RNAs with desired properties.

摘要翻译

RNA在调控信息流动中发挥核心作用，并为工程化生物功能提供了多功能底物。尽管大型语言模型（LLMs）已变革自然语言处理和蛋白质设计，但将RNA基础模型与功能性序列设计相连接的一般框架仍较为有限。在此，我们提出RNASeek，一个基于DeepSeek架构构建的16亿参数生成式基础模型，并在跨门类转录组语料库上训练，用于RNA序列表示和生成。自然语言标记使得通过统一骨干网络实现灵活的条件预测和序列设计成为可能。RNASeek在零样本设置下捕获物种特异性转录特征和内含子-外显子边界。随后，我们对RNASeek进行微调，以预测核酶自切割活性和病毒mRNA稳定性，揭示与功能相关的可解释序列特征，包括核酶环灵活性和茎稳定性，以及与mRNA稳定性相关的AU富集基序。我们使用这些功能预测器作为奖励模型，并应用组相对策略优化（GRPO）更新RNASeek的生成策略，以朝向具有所需特性的序列。GRPO引导的生成产生更快切割的核酶和增强稳定性的3′ UTR，同时满足用户指定的IUPAC约束。实验验证的RNASeek生成核酶达到野生型水平的活性，而RNASeek生成的3′ UTR序列超过训练数据和基准测试的AI生成3′ UTR的性能。综上，RNASeek建立了一个统一的预训练-预测-优化框架，将学习的RNA功能与可控的从头序列设计相连接，并为工程化具有所需特性的调控RNA提供了一般策略。

02 一句话总结

本文构建了一个 1.6B 参数的 RNA 生成式基础模型 RNASeek，通过跨门转录组预训练学习 RNA 序列表示，微调为核酶自切割活性和 mRNA 稳定性预测器后，用 GRPO 强化学习引导序列生成，实验验证生成的核酶达到野生型活性水平、生成的 3′ UTR 稳定性超过训练数据和已有 AI 方法。

03 研究问题

  • 具体问题：能否建立一个统一的 RNA 基础模型框架，将序列表示学习、功能预测和可控的 de novo 序列设计连接起来？
  • 为什么重要：RNA 在基因调控中发挥核心作用，也是工程生物学的重要底物；但现有 RNA 设计方法缺乏一个通用的「表示 → 功能 → 设计」闭环框架，与蛋白质设计领域的 LLM 进展相比明显滞后。
  • 现有方法为何不足：已有 RNA 语言模型多聚焦于表示学习或单一任务预测，缺乏将功能预测与序列生成统一起来的框架；生成方法（如随机突变或简单 motif 拼接）难以同时满足多约束（如 IUPAC 约束）和多目标（如活性 + 稳定性）。
  • 精确研究问题：Can a single generative foundation model, fine-tuned as functional predictors and optimized via reinforcement learning, produce functional RNA sequences (ribozymes and 3′ UTRs) that meet or exceed experimental benchmarks?

06 核心思想

1) 表面方法： - 构建 1.6B 参数 decoder-only 生成模型（DeepSeek 架构），在跨门转录组语料上预训练； - 引入自然语言 token 实现条件预测和序列设计的统一； - 微调为核酶自切割活性和 mRNA 稳定性预测器； - 用 GRPO 将预测器作为 reward model，更新生成策略； - 实验验证生成的核酶和 3′ UTR。

2) 核心洞察： - 将「自然语言 token」与 RNA 序列 token 统一在一个生成框架中，使得条件控制（如物种、功能描述）可以通过文本指令实现，无需任务特定的架构改动； - 功能预测器可以作为 reward model 直接驱动生成策略优化，形成「预测即评估、评估即引导」的闭环； - 跨门预训练提供了足够的序列多样性，使模型在 zero-shot 下捕获物种特异特征和剪接边界。

3) 可能的普适教训 [Analysis]： - 生成模型 + 功能预测器 + RL 的三段式框架不限于 RNA，可迁移至蛋白质设计：结构预测器（如 AlphaFold 的 pLDDT 或 Rosetta 能量函数）可作为 reward，引导序列生成； - 自然语言 token 与生物序列 token 的统一是一种灵活的「多模态条件控制」策略，可降低任务切换成本； - GRPO 作为一种无需 critic 模型的策略优化方法，在序列生成这类高维离散空间中可能比 PPO 更稳定、更省显存。

11 结论正确解读

  • 任务范围：本文结论仅适用于 RNA 序列的表示学习、功能预测和序列生成，不涉及 RNA 结构预测或结构-功能关系建模。
  • Orcale/真值输入：功能预测器的训练依赖实验测定的核酶活性和 mRNA 稳定性数据；这些数据的质量和覆盖范围直接影响 reward 的可靠性。
  • 端到端状态：框架是端到端的（预训练 → 微调 → RL → 生成），但湿实验验证仅覆盖核酶和 3′ UTR 两个任务，不能推广至所有 RNA 功能类型。
  • 算力成本：1.6B 参数模型的预训练和 RL 训练成本未披露，可能对资源有限的研究组构成门槛。
  • 历史数据依赖：预训练语料为跨门转录组，但具体物种组成、序列冗余度、数据清洗流程未披露，影响可复现性。
  • 模型依赖：架构基于 DeepSeek，但未说明为何选择该架构而非其他 decoder-only 模型；GRPO 的超参数和收敛标准未披露。
  • 最难情形：核酶自切割活性和 mRNA 稳定性是相对「简单」的功能标签；对于更复杂的 RNA 功能（如翻译调控、RNA-蛋白互作），预测器的可靠性未知。
  • 不确定性：湿实验验证的样本量、重复次数、统计显著性未披露，无法评估结论的稳健性。
  • 有边界的复述：RNASeek 在跨门 RNA 序列上预训练后，通过微调功能预测器和 GRPO 优化，能够生成在体外达到野生型活性水平的核酶序列，以及稳定性超过训练数据和已有 AI 方法的 3′ UTR 序列；该结论仅限于这两个功能任务和所测试的实验条件。

14 学到什么

Agent 提炼的知识候选：

  1. 「预训练 → 功能微调 → RL 优化」三段式框架：这是本文最核心的可迁移资产。在蛋白质设计中，可类比为「蛋白质语言模型预训练 → 结构/功能预测器微调（如 AlphaFold pLDDT、Rosetta energy、binding affinity predictor）→ RL 引导序列生成」。该框架将「评估」与「生成」闭环，避免了两阶段方法中评估器与生成器不匹配的问题。

  2. 自然语言 token 作为统一条件接口：将文本指令与生物序列 token 放在同一生成框架中，可实现「零成本」任务切换。在蛋白质设计中，可用自然语言描述目标（如「thermostable」「bind to PD-L1」「membrane protein」）作为条件，无需为每个任务训练新的条件编码器。

  3. GRPO 用于序列生成策略优化：GRPO 无需 critic 模型，相比 PPO 更省显存、更稳定，适合在序列生成这类高维离散空间中做策略优化。蛋白质设计中的序列生成（尤其是长序列、多约束场景）可借鉴此方法。

  4. 功能预测器作为 reward model 的可解释性：本文通过分析预测器关注的特征（loop flexibility、stem stability、AU-rich motifs），验证了 reward model 的生物学合理性。在蛋白质设计中，可类似地分析预测器关注的残基/结构特征，确保 reward 不是「捷径」或伪相关。

  5. 跨门预训练提升 zero-shot 泛化：在蛋白质领域，跨物种/跨家族预训练（如所有 UniProt 序列）已被证明有效；本文进一步展示了跨门（cross-phyla）语料在 RNA 上的价值，提示蛋白质预训练语料的多样性比总量更重要。

  6. IUPAC 约束与 RL 的融合：在 RL 生成过程中直接施加序列模式约束（而非后处理过滤），可提高生成序列的可用性。蛋白质设计中常见的 motif 约束（如活性位点残基、二硫键模式）可类似地嵌入生成策略。

15 与已有知识连接

  • 相似工作：与 Evo（DNA/RNA 基础模型）、RNA-FM、RNABERT 等 RNA 语言模型同属「核酸序列基础模型」方向；本文的差异化在于生成能力 + RL 优化闭环。在蛋白质领域，与 ProGen、ESM-based generative models、RGN2 等生成式蛋白质语言模型在架构思路上相似。
  • 组合方向：本文的「功能预测器 + RL」策略与蛋白质设计中的「AlphaFold-based reward + MCMC/RL」思路高度一致（如 RFdiffusion + AlphaFold 打分、ProteinMPNN + Rosetta 能量最小化）。可组合的方向：将 AlphaFold 的 pLDDT/pAE 作为 reward，用 GRPO 优化蛋白质序列生成。
  • 冲突/差异：本文未使用结构信息（无 3D 结构预测或 MSA 共进化特征），与 AlphaFold/Rosetta 系列的结构中心方法形成对比；其纯序列 + 功能标签的路线在数据充足时可能更高效，但在结构敏感任务上可能受限。
  • 可迁移领域：RNA 适配体设计、CRISPR gRNA 设计、mRNA 疫苗序列优化（密码子优化 + 稳定性）、蛋白质稳定性工程、抗体 CDR 设计等，均可套用「预训练 → 预测 → RL 生成」框架。
  • 候选方向（未验证）：将 RNASeek 的 cross-phyla 预训练策略迁移至蛋白质，构建「cross-proteome」预训练语料（涵盖细菌、古菌、真核、病毒），可能提升 zero-shot 泛化；将 GRPO 与 AlphaFold 结合用于抗体设计，可能比现有 MCMC 方法更高效。

16 研究想法

Agent 生成的研究候选：

  1. 名称：ProteinSeek-RL：基于 GRPO 的蛋白质序列生成框架，以 AlphaFold pLDDT 为 reward - 来源局限/观察：RNASeek 展示了「功能预测器 + GRPO」的闭环有效性；蛋白质设计领域尚无类似统一框架 - 核心假设：以 AlphaFold 预测的结构置信度（pLDDT）和功能位点保守性作为 reward，GRPO 能引导生成高表达、高稳定性的蛋白质序列 - 初步方法：在 ESM/ProGen 预训练模型上微调 pLDDT 预测头，用 GRPO 优化生成策略，在生成过程中施加 motif 约束 - 验证方式：与 ProteinMPNN + Rosetta 基线对比，湿实验验证表达量和热稳定性 - 创新状态：unverified

  2. 名称：Cross-Proteome 预训练策略：跨门蛋白质语料对 zero-shot 泛化的影响 - 来源局限/观察：RNASeek 的 cross-phyla 预训练在 RNA 上有效；蛋白质预训练语料多为 UniProt 全库，未系统比较跨门多样性 vs 总量 - 核心假设：跨门均衡采样的蛋白质预训练语料比总量更大但门内冗余高的语料带来更好的 zero-shot 泛化 - 初步方法：构建不同门类均衡比例的预训练语料，在相同模型规模下对比下游任务表现 - 验证方式：在酶功能预测、稳定性预测、亚细胞定位等任务上对比 zero-shot 和微调性能 - 创新状态：unverified

  3. 名称：自然语言条件蛋白质生成：用文本描述驱动 de novo 蛋白设计 - 来源局限/观察：RNASeek 用自然语言 token 实现条件控制；蛋白质设计中的条件控制多依赖结构或序列特征，缺乏语义级控制 - 核心假设：自然语言描述（如「thermostable enzyme with high catalytic activity」）能有效引导蛋白质生成模型产生符合描述的序列 - 初步方法：在蛋白质语言模型中加入文本编码器，训练文本-序列对齐，用 RL 进一步优化 - 验证方式：生成序列的功能预测 + 湿实验验证 - 创新状态：prior-art checked（已有部分工作如 ProtGPT2 支持文本条件，但 RL 闭环未见）

  4. 名称：RNA 结构感知的生成模型：将 RNA 二级结构预测器纳入 RNASeek 的 reward 体系 - 来源局限/观察：RNASeek 仅用序列和功能标签，未利用 RNA 二级结构信息；RNA 功能高度依赖结构 - 核心假设：将 RNA 二级结构预测器（如 RNAfold、UFold）的预测置信度作为额外 reward，可提升生成 RNA 的功能性 - 初步方法：在 RNASeek 的 GRPO 训练中，将二级结构预测置信度与功能预测分数加权组合为 reward - 验证方式：与仅用功能 reward 的版本对比，湿实验验证核酶活性和适配体结合能力 - 创新状态：unverified

  5. 名称：多目标 RL 生成：同时优化蛋白质稳定性、表达量和结合亲和力 - 来源局限/观察：RNASeek 的 GRPO 可处理多约束（IUPAC + 功能）；蛋白质设计常需同时满足多个目标 - 核心假设：多目标 reward 加权（稳定性 + 表达量 + 亲和力）能生成在多个维度上均衡优化的蛋白质序列 - 初步方法：在 ProteinSeek-RL 框架中，将多个预测器的输出加权组合为 reward，用 GRPO 优化 - 验证方式：与单目标优化对比，湿实验验证多维度表现 - 创新状态：unverified
