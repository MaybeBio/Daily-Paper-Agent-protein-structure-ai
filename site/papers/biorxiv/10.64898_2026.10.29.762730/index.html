8

LPT: Orchestrating bounded agentic loops for automated protein binder design

Michael Uckelmann
bioRxiv 预印本 · 2026-10-30 · 全文(europepmc) · 原文

该文提出LPT框架，用LLM编排有界智能体循环，从自然语言提示自动完成蛋白质结合剂设计，涉及结构选择、热点残基识别和候选设计，属于蛋白质结构设计计算研究，方法上结合LLM与文献数据库，虽非传统AI结构预测，但核心是蛋白设计且方法有创新。

摘要

Current large language models (LLMs) can reason over scientific information and use code-based tools, but their training knowledge is broad rather than specialized, can be out of date and is hard to attribute to sources. Furthermore, unconstrained agentic workflows and unlimited tool use can consume large amounts of tokens. Here we present LPT (little protein tiger), a framework for fixed orchestration of LLM stages, each running a bounded agentic loop with custom system prompts and tool access, to enable de novo protein binder design from a single natural language prompt. The LLM stages can query a curated literature database, containing ~14000 papers digested into key findings, enabling recall of specialized information. An LLM with database access answered 41/48 test questions drawn from database key findings correctly, while a model without access answered none. In three end-to-end design campaigns, initiated from a single prompt, LPT autonomously identified the design intent, selected targets, structures and hotspot residues and designed candidate binders to disrupt CALCRL/RAMP1, PD-1/PD-L1 and PVR-TIGIT interactions. Cross-validation with multiple folding models confirms a high in silico success rate at minimal token consumption and low computational costs.

摘要翻译

当前大型语言模型（LLMs）能够对科学信息进行推理并使用基于代码的工具，但其训练知识广泛而非专门化，可能过时且难以溯源。此外，不受约束的智能体工作流程和无限制的工具使用会消耗大量令牌。在此，我们提出LPT（little protein tiger），一种用于LLM阶段固定编排的框架，每个阶段运行一个受限的智能体循环，配备自定义系统提示和工具访问权限，以实现从单一自然语言提示出发的从头蛋白质结合物设计。LLM阶段可查询一个精选文献数据库，其中包含约14000篇论文，提炼为关键发现，从而能够回忆专门信息。具备数据库访问权限的LLM正确回答了从数据库关键发现中抽取的48个测试问题中的41个，而无访问权限的模型则一个未答对。在三项端到端设计活动中，从单一提示启动，LPT自主识别设计意图，选择靶标、结构和热点残基，并设计候选结合物以破坏CALCRL/RAMP1、PD-1/PD-L1和PVR-TIGIT相互作用。与多个折叠模型的交叉验证确认，在最小令牌消耗和低计算成本下，具有较高的计算机模拟成功率。

03 研究问题

  • 具体问题：如何让 LLM 智能体在无需人工干预、token 消耗可控的前提下，完成从自然语言提示到蛋白 binder 设计的全流程？
  • 为什么重要：现有 LLM 智能体在科学任务中常因无界工具使用导致 token 爆炸、结果不可控；同时 LLM 训练知识泛而不专、易过时、难以溯源。蛋白 binder 设计需要多步骤决策（靶点选择、结构获取、热点残基识别、序列设计、验证），是检验智能体科学推理能力的理想场景。
  • 现有方法为何不足：
  • 无约束 agentic 工作流 token 消耗大、易发散；
  • LLM 缺乏领域专精知识，且无法引用来源；
  • 现有自动化设计工具缺乏端到端编排，需人工干预各步骤。
  • 精确研究问题：Can a fixed-orchestration, bounded agentic LLM framework with curated literature database access perform de novo protein binder design from a single natural language prompt with high in silico success rate and minimal token consumption?

06 核心思想

1) 表面方法： LPT 将蛋白 binder 设计流程分解为多个固定顺序的 LLM 阶段（stages），每个阶段运行一个 bounded agentic loop——即 LLM 在受限的工具集和有限的迭代次数内完成任务。各阶段有定制 system prompt 和专属工具访问权限。整个流程从单一自然语言提示开始，自动完成设计意图识别、靶点选择、结构获取、热点残基识别、binder 设计、交叉验证。

2) 核心洞察： - 有界性（boundedness）是关键：不是让 LLM 自由探索，而是将复杂任务分解为固定阶段，每阶段限制工具和迭代次数，既保证可控性又降低 token 消耗。 - 文献数据库弥补 LLM 知识短板：~14,000 篇论文摘要的 curated 数据库使 LLM 能检索专精知识并溯源，解决了 LLM 知识泛而不专的问题。 - 编排优于自由发挥：固定编排（orchestration）比无约束 agentic 工作流更适合科学任务，因为科学流程本身有固定逻辑顺序。

3) 可能的普适教训 [Analysis]： - 在科学任务中，「约束智能体」可能比「自由智能体」更有效——科学流程的固定逻辑顺序可以被显式编码为编排结构，而非依赖 LLM 自主发现。 - 外部知识库（curated database）是弥补 LLM 知识短板的有效手段，尤其当任务需要专精、可溯源知识时。 - 对蛋白设计任务而言，LLM 智能体的价值不在于替代专用工具（如 RFdiffusion），而在于编排这些工具、做决策和解释结果。

  • 历史数据依赖：文献数据库为 curated 数据，其覆盖范围、更新频率、选择标准未说明。
  • 模型依赖：未说明使用的具体 LLM 型号、版本、温度等超参数，可复现性受限。
  • 最难情形：仅测试 3 个靶点，均为蛋白-蛋白相互作用 disruptor，未测试更复杂场景（如构象变化、变构设计）。

14 学到什么

Agent 提炼的知识候选：

  1. 有界智能体循环（Bounded Agentic Loop）设计模式：将复杂科学任务分解为固定阶段，每阶段限制工具访问和迭代次数，可同时保证可控性和效率。可迁移到本课题的构象采样、分子对接等任务中，将每个计算步骤封装为有界 agent 阶段。

  2. Curated 文献数据库作为 LLM 知识外挂：~14,000 篇论文的 curated 数据库使 LLM 从「泛而不专」变为「专精可溯源」。可迁移到本课题：构建蛋白结构预测/设计领域的 curated 文献库（如 AlphaFold 相关论文、MD 模拟方法论文），作为 LLM 智能体的知识检索源。

  3. 固定编排优于自由探索：科学流程有固定逻辑顺序（如：靶点选择 → 结构获取 → 热点识别 → 设计 → 验证），显式编码为编排结构比让 LLM 自主规划更可靠。可迁移到本课题：将 MD 模拟、对接、结构预测等步骤编排为固定流水线，而非依赖 LLM 自主决定顺序。

  4. 多模型交叉验证作为 oracle：用多个折叠模型交叉验证设计结果，降低单一模型偏差。可迁移到本课题：在构象生成或 binder 设计中，用 AlphaFold + ESMFold + MD 模拟等多方法交叉验证候选结构。

  5. 自然语言提示作为任务接口：从单一自然语言提示出发完成全流程，降低使用门槛。可迁移到本课题：开发面向蛋白设计的自然语言接口，用户描述设计目标，系统自动完成结构预测、采样、验证。

  6. Token 消耗作为设计指标：将 token 消耗作为框架评估指标之一，推动高效智能体设计。可迁移到本课题：在开发 AI 辅助蛋白设计工具时，将计算成本（token、GPU 时间）作为显式优化目标。

15 与已有知识连接

  • 相似工作：ChemCrow（LLM 化学智能体）、AutoGPT（通用 agent 框架）、Coscientist（科学发现智能体）——均探索 LLM 智能体在科学任务中的应用，但 LPT 的差异在于 固定编排 + 有界循环，而非自由 agent 行为。
  • 蛋白设计工具：RFdiffusion、ProteinMPNN 为 LPT 可能调用的底层生成工具（原文未明确列出，[Analysis] 推断）；AlphaFold2/3、ESMFold 为可能的验证工具。LPT 的贡献在于编排层，而非新的生成模型。
  • 知识增强 LLM：RAG（Retrieval-Augmented Generation）相关工作是 LPT 文献数据库设计的理论基础，但 LPT 使用 curated 数据库而非通用语料。
  • 可迁移领域：MD 模拟工作流自动化（如用 LLM 智能体编排 MD 采样、自由能计算步骤）、分子对接虚拟筛选自动化、构象生成与评估闭环。
  • 候选方向（未验证）：LPT 的 bounded loop 模式可迁移到「结构预测 → MD 模拟 → 结合自由能计算」的自动化流程中，但需验证 LLM 在物理模拟参数选择上的可靠性。

16 研究想法

Agent 生成的研究候选：

  1. 候选名称：Bounded Agentic MD Simulation Orchestrator - 来源局限/观察：LPT 展示了有界 agent 循环在蛋白设计中的有效性，但未涉及 MD 模拟的参数选择与轨迹分析 - 核心假设：固定编排的 LLM 智能体能自动选择 MD 模拟参数（力场、溶剂模型、模拟时长）并分析轨迹，达到专家水平 - 相对本文的增量：将 LPT 模式从 binder 设计扩展到 MD 模拟自动化 - 初步方法：构建 MD 模拟知识库（力场选择指南、常见陷阱），设计固定阶段（体系准备 → 参数选择 → 模拟运行 → 轨迹分析），每阶段 bounded loop - 验证方式：在标准蛋白体系上对比 LLM 选择的参数与专家选择，用 RMSD/自由能计算评估结果质量 - 可能的失败模式：LLM 对物理模拟的数值稳定性判断不足，参数选择可能合理但运行失败 - 创新状态：unverified

  2. 候选名称：Cross-Validation Agent for Conformational Sampling - 来源局限/观察：LPT 用多折叠模型交叉验证 binder 设计，但未涉及构象采样的验证 - 核心假设：LLM 智能体能协调多种构象采样方法（MD、MCMC、生成模型）并交叉验证采样充分性 - 相对本文的增量：将交叉验证思想从 binder 设计迁移到构象采样 - 初步方法：设计 agent 阶段：采样方法选择 → 并行采样 → 收敛性评估 → 构象多样性验证 - 验证方式：在已知多构象蛋白（如激酶）上测试采样覆盖率 - 可能的失败模式：LLM 对采样收敛性的判断可能过于乐观，需结合统计检验工具 - 创新状态：unverified

  3. 候选名称：Literature-Grounded Docking Parameter Selection - 来源局限/观察：LPT 的文献数据库显著提升知识 recall，但未应用于分子对接 - 核心假设：curated 文献数据库能帮助 LLM 选择正确的对接工具和参数（如搜索空间、打分函数） - 相对本文的增量：将文献增强思想从 binder 设计迁移到分子对接 - 初步方法：构建对接方法文献库，设计 agent 阶段：靶点分析 → 工具选择 → 参数设置 → 结果评估 - 验证方式：在基准集（如 DUD-E）上对比 LLM 选择的对接流程与默认流程 - 可能的失败模式：文献库覆盖不足，LLM 可能推荐过时或不适用的方法 - 创新状态：unverified

  4. 候选名称：Natural Language Interface for Protein Design Pipelines - 来源局限/观察：LPT 从单一提示出发完成全流程，但仅覆盖 binder 设计 - 核心假设：统一的自然语言接口能编排更广泛的蛋白设计任务（结构预测、序列设计、构象分析） - 相对本文的增量：扩展 LPT 的接口设计到多任务场景 - 初步方法：设计任务路由层，将用户提示映射到不同设计流水线 - 验证方式：用多种类型的蛋白设计任务测试接口的鲁棒性 - 可能的失败模式：任务歧义导致路由错误，需设计澄清机制 - 创新状态：unverified

  5. 候选名称：Token-Efficient Agent Design for Protein Tasks - 来源局限/观察：LPT 声称 minimal token 消耗但未提供量化分析 - 核心假设：有界循环的 token 效率可通过系统化设计进一步优化 - 相对本文的增量：建立 token 效率的量化评估框架 - 初步方法：对比不同 bounded loop 设计（迭代次数、工具粒度、prompt 长度）的 token 消耗与任务成功率 - 验证方式：在标准蛋白设计任务集上建立 token-质量 Pareto 曲线 - 可能的失败模式：token 效率与任务质量可能存在不可调和的权衡 - 创新状态：unverified

Review setup

  • Input scope Abstract only
  • Assessment boundary Claims and evidence as presented in the abstract
  • Shared manuscript claim summary The authors present LPT (little protein tiger), a framework that orchestrates fixed LLM stages, each running a bounded agentic loop with custom system prompts and tool access, to enable de novo protein binder design from a single natural language prompt. The framework includes a curated literature database of approximately 14,000 papers. The authors report that an LLM with database access answered 41/48 test questions correctly, while a model without access answered none. In three end-to-end design campaigns, LPT autonomously identified design intent, selected targets, structures and hotspot residues, and designed candidate binders to disrupt CALCRL/RAMP1, PD-1/PD-L1 and PVR-TIGIT interactions. Cross-validation with multiple folding models reportedly confirms a high in silico success rate at minimal token consumption and low computational costs.
  • Visible evidence base Abstract text only. No figures, tables, methods, or supplementary materials were provided for review.
  • Missing materials affecting confidence Full manuscript text, methods section, all figures and tables, supplementary materials, benchmark details, database construction details, design campaign outputs, folding model validation results, and token consumption data.

Reviewer

  • Overall assessment The abstract describes a potentially useful framework for structured LLM orchestration in protein design, with a plausible motivation around bounded agentic loops and token efficiency. However, the evidence presented is insufficient to evaluate the core claims. The benchmark result (41/48 versus 0/48) is striking but lacks methodological detail. The three design campaigns are described only at the level of interaction targets, with no quantitative outcomes reported. The claim of high in silico success rate is not supported by any data in the abstract. The framework's novelty relative to existing LLM orchestration and protein design methods is not established from the supplied material.
  • Who would be interested in the results, and why Researchers in computational protein design, LLM applications in biology, and automated scientific discovery would be interested if the full manuscript substantiates the claims. The bounded agentic loop concept and the curated literature database could appeal to those working on token-efficient AI workflows for scientific tasks. The specific design campaigns targeting immune checkpoint interactions (PD-1/PD-L1, PVR-TIGIT) and GPCR-related complexes (CALCRL/RAMP1) may interest structural biologists and drug discovery groups.
  • Major strengths The motivation for bounded agentic loops to control token consumption is timely and practically relevant. The curated literature database approach addresses a real limitation of LLM training knowledge. The benchmark design (with versus without database access) provides a clear comparative framing. The choice of three distinct protein-protein interaction targets suggests some breadth of application.
