Mitigating Class Imbalance in Graph-Structured Data via Hierarchical Learning: Insights from Protein Binding Site Prediction

Vinícius Paiva; Leandro Marcolino; Sandro Izidoro; Sabrina Silveira
bioRxiv 预印本 · 2026-10-04 · 仅摘要 · 原文

该文提出层级学习框架CLARA缓解图数据类别不平衡，并应用于蛋白质-配体结合位点预测，虽以图分类方法为核心，但直接涉及蛋白质结构相关计算问题，方法可迁移至蛋白结构预测任务。

摘要

Learning from imbalanced data remains a major challenge for graph neural networks (GNNs), as minority nodes are not only rare but also structurally marginalized within the graph. We address this issue with CLARA, a hierarchical learning framework that decomposes node classification into two stages: a coarse subgraph-level classifier that selects regions likely to contain minority instances, followed by a fine-grained node-level predictor within these regions. This design improves sensitivity while maintaining scalability, filtering out irrelevant areas and focusing learning on topologically meaningful neighborhoods. Experiments on benchmark graph datasets demonstrate substantial gains over established imbalance-handling methods, with CLARA reaching an F1-score of 88.3%. The same strategy achieves significant improvements in protein–ligand binding site prediction, underscoring its broad and consistent effectiveness across both biological and general graph learning tasks.

摘要翻译

从不平衡数据中学习仍然是图神经网络（GNNs）面临的主要挑战，因为少数类节点不仅稀少，而且在图中结构上被边缘化。我们通过CLARA解决这一问题，这是一种分层学习框架，将节点分类分解为两个阶段：首先是一个粗粒度的子图级分类器，用于选择可能包含少数类实例的区域，随后在这些区域内进行细粒度的节点级预测。这种设计在保持可扩展性的同时提高了敏感性，过滤掉不相关区域，并将学习聚焦于拓扑上有意义的邻域。在基准图数据集上的实验表明，相较于已建立的不平衡处理方法，CLARA取得了显著提升，其F1分数达到88.3%。同样的策略在蛋白质-配体结合位点预测中也实现了显著改进，突显了其在生物学和通用图学习任务中的广泛且一致的效力。

03 研究问题

  • 具体问题：图神经网络在处理类别不平衡数据时，少数类节点不仅数量稀少，而且在图结构中处于边缘化位置（即拓扑上孤立或连接稀疏），导致 GNN 难以有效学习其表示。
  • 为什么重要：蛋白质结合位点预测是药物发现和蛋白质功能注释的关键步骤，而结合位点残基在蛋白质结构中通常只占少数（少数类节点），其预测精度直接影响下游应用。
  • 现有方法为何不足：现有不平衡处理方法（如重采样、损失函数重加权、合成少数类过采样）主要针对欧氏空间数据，未考虑图结构中的拓扑边缘化问题；端到端 GNN 方法虽能利用结构信息，但缺乏对少数类节点所在局部区域的显式关注。
  • 精确研究问题：Can a hierarchical learning framework that first selects subgraph regions likely to contain minority nodes, then performs fine-grained node classification within those regions, effectively mitigate class imbalance in graph-structured data and improve protein binding site prediction?

06 核心思想

1) 表面方法： CLARA 是一个两阶段层级学习框架：第一阶段使用粗粒度子图级分类器，将图划分为若干子图区域并预测每个区域包含少数类节点的概率；第二阶段仅对高概率区域进行细粒度节点级分类，输出每个节点的标签。

2) 核心洞察： 少数类节点在图中的分布并非完全随机，而是倾向于聚集在特定的拓扑区域（如蛋白质结合口袋）。通过先识别这些区域，可以「过滤」掉大量无关区域，使细粒度分类器专注于少数类节点所在的拓扑有意义邻域，从而缓解类别不平衡。

3) 可能的普适教训 [Analysis]： 对于蛋白质结构相关任务中任何「稀疏但结构聚集」的标签（如活性位点、突变热点、构象变化关键残基），「先定位区域、再精细预测」的层级策略可能比端到端方法更有效。这一思路可迁移至构象采样中的稀有态识别、分子对接中的结合口袋预筛等场景。

07 方法总览

  • 输入：图结构数据（节点特征 + 邻接矩阵），对于蛋白质任务为残基图（残基为节点，空间/序列邻近为边）
  • 输出：节点级二分类标签（是否为少数类/结合位点残基）
  • 模块： 1. 子图划分模块：将图划分为若干子图区域 2. 粗粒度子图级分类器：预测每个子图包含少数类节点的概率 3. 细粒度节点级预测器：仅对高概率子图内的节点进行精细分类
  • 训练：两阶段训练——先训练子图级分类器，再在筛选出的子图上训练节点级预测器（具体损失函数和优化器未提供）
  • 工具：GNN 架构（具体类型未提供，推测为 GCN/GAT 类）
  • 反馈回路：子图级分类器的输出作为节点级预测器的输入筛选条件
  • 假设：少数类节点在拓扑上聚集于特定子图区域；子图级分类器能有效识别这些区域

Agent 提炼的知识候选：

  1. 层级筛选策略：对于蛋白质结构任务中稀疏但结构聚集的标签（结合位点、活性残基、构象关键残基），「先粗粒度定位区域，再细粒度预测」可作为一种通用框架，迁移至： - 分子对接中的结合口袋预筛（先预测口袋区域，再精细对接） - 构象采样中的稀有态识别（先识别可能含稀有构象的区域，再精细采样） - 蛋白质设计中的功能位点定位（先定位功能相关区域，再设计序列）

  2. 拓扑边缘化概念：少数类节点不仅数量少，而且在图结构中信息传播受限。这一概念可迁移至： - 蛋白质残基图中的功能位点预测（结合位点残基可能位于表面凸起或凹陷处，拓扑位置特殊） - MD 模拟轨迹中的稀有构象识别（稀有构象在相空间中可能处于边缘区域）

  3. 两阶段训练范式：先训练粗粒度分类器，再在筛选子集上训练细粒度模型，可减少计算开销并提高少数类关注度。可迁移至： - 大规模蛋白质结构预测中的候选区域筛选 - 分子生成中的条件区域限定

  4. 评估指标选择：在不平衡任务中优先使用 F1-score 而非 accuracy，这一实践可直接迁移至所有蛋白质结构预测任务中的稀疏标签评估。

15 与已有知识连接

  • 相似方法：与「coarse-to-fine」策略在计算机视觉中的目标检测（如 R-CNN 系列的区域提议 + 精细分类）高度相似，本文将其引入图数据领域。
  • 组合方向：与 GraphSMOTE（图数据过采样）、Focal Loss（损失函数重加权）等方法可组合使用，CLARA 作为前置筛选模块。
  • 冲突观点：与端到端 GNN 方法（如直接在图上游走预测）形成对比，本文主张显式区域筛选优于隐式学习。
  • 可迁移领域：蛋白质-配体结合位点预测与分子对接中的口袋预测高度相关；层级策略可迁移至 AlphaFold 的 pLDDT 置信度区域筛选。
  • 候选方向：将 CLARA 与等变图神经网络（如 EGNN、SE(3)-Transformer）结合，用于蛋白质构象采样中的稀有态识别。
