RNASeek: A Cross-Phyla Generative Foundation Model for Multipurpose RNA Modeling and Reinforcement Learning-Based Design.

Chen, Shiyuan; Fernandes, Neil R; Li, Wei Vivian; Wang, Lili; Jia, Zhenyu; Xiang, Joy S
bioRxiv : the preprint server for biology · 2026-10-11 · 全文(pmc) · 原文

该文提出RNA生成式基础模型RNASeek，用于RNA序列建模与功能设计，虽对象为RNA而非蛋白质，但其生成模型与强化学习设计框架可迁移至蛋白质结构/序列设计，对课题有借鉴价值。

摘要

RNA plays central roles in regulating information flow and provides a versatile substrate for engineering biological functions. While large language models (LLMs) have transformed natural language processing and protein design, a general framework connecting RNA foundation models to functional sequence design remains limited. Here, we present RNASeek, a 1.6-billion-parameter generative foundation model built on a DeepSeek architecture and trained on a cross-phyla transcriptomic corpus for RNA sequence representation and generation. Natural-language tokens enable flexible conditional prediction and sequence design using a unified backbone. RNASeek captures species-specific transcript features and intron-exon boundaries in a zero-shot setting. We then fine-tune RNASeek to predict ribozyme self-cleavage activity and viral mRNA stability, revealing interpretable sequence features associated with function, including ribozyme loop flexibility and stem stability, as well as AU-rich motifs associated with mRNA stability. We use these functional predictors as reward models and apply Group Relative Policy Optimization (GRPO) to update RNASeek's generation policy toward sequences with desired properties. GRPO-guided generation produces faster-cleaving ribozymes and stability-enhancing 3' UTRs while satisfying user-specified IUPAC constraints. Experimentally validated RNASeek-generated ribozymes achieve wild-type levels of activity, while RNASeek-generated 3' UTR sequences exceed the performance of the training data and benchmarked AI-generated 3' UTRs. Together, RNASeek establishes a unified pretrain-predict-optimize framework that connects learned RNA function to controllable de novo sequence design and provides a general strategy for engineering regulatory RNAs with desired properties.

摘要翻译

RNA在调控信息流中发挥核心作用，并为工程化生物功能提供了多功能底物。尽管大型语言模型（LLMs）已变革自然语言处理和蛋白质设计，但将RNA基础模型与功能性序列设计连接起来的通用框架仍然有限。在此，我们提出RNASeek，一个基于DeepSeek架构构建的16亿参数生成式基础模型，并在跨门类转录组语料库上训练，用于RNA序列表示和生成。自然语言标记使得能够使用统一骨干进行灵活的条件预测和序列设计。RNASeek在零样本设置中捕获物种特异性转录特征和内含子-外显子边界。然后，我们对RNASeek进行微调，以预测核酶自切割活性和病毒mRNA稳定性，揭示与功能相关的可解释序列特征，包括核酶环灵活性和茎稳定性，以及与mRNA稳定性相关的AU富集基序。我们使用这些功能预测器作为奖励模型，并应用组相对策略优化（GRPO）来更新RNASeek的生成策略，朝向具有所需属性的序列。GRPO引导的生成产生更快切割的核酶和增强稳定性的3' UTR，同时满足用户指定的IUPAC约束。实验验证的RNASeek生成的核酶达到野生型活性水平，而RNASeek生成的3' UTR序列超过训练数据和基准测试的AI生成3' UTR的性能。总之，RNASeek建立了一个统一的预训练-预测-优化框架，将学习的RNA功能与可控的从头序列设计连接起来，并为工程化具有所需属性的调控RNA提供通用策略。

02 一句话总结

RNASeek 是一个 1.6B 参数的生成式 RNA 基础模型，基于 DeepSeek 架构，通过跨物种转录组预训练、功能预测微调和 GRPO 强化学习，实现从 RNA 序列表示到可控功能序列设计的统一框架，实验验证其生成的核酶和 3' UTR 达到或超过训练数据与基准 AI 方法的性能。

03 研究问题

  • 具体问题：如何构建一个统一的 RNA 基础模型框架，既能进行序列表示与条件生成，又能通过强化学习将功能预测信号转化为可控的 de novo 序列设计？
  • 为什么重要：RNA 在基因调控、疾病机制和合成生物学中发挥核心作用，但缺乏类似蛋白质领域的通用生成模型与设计闭环。
  • 现有方法不足：现有 RNA 模型多聚焦于表示学习或单一任务预测，缺乏生成能力；蛋白质设计中的「预训练-预测-优化」范式尚未在 RNA 领域系统建立。
  • 精确研究问题：Can a single generative foundation model, fine-tuned with functional predictors and optimized via GRPO, produce RNA sequences (ribozymes and 3' UTRs) with experimentally validated functional improvements over training data and existing AI baselines?

06 核心思想

  1. 表面方法：构建 1.6B 参数生成式 LLM（DeepSeek 架构），在跨物种转录组上预训练；微调为功能预测器（核酶自切割活性、mRNA 稳定性）；用 GRPO 将预测器作为奖励模型优化生成策略。
  2. 核心洞察：将自然语言 token 与 RNA 序列 token 统一在同一生成框架中，使条件预测与序列生成共享同一 backbone，从而让「功能预测」与「序列生成」不再是两个独立模块，而是同一模型的两面。
  3. 可能的普适教训 [Analysis]：在生物序列设计中，「预测器 + 强化学习」的闭环比单纯增大模型或数据更关键——奖励模型的质量直接决定生成序列的功能上限；同时，统一 token 空间（自然语言 + 生物序列）可显著提升条件控制的灵活性。

07 方法总览

  • 输入：RNA 序列（跨物种转录组）、自然语言条件 token（如物种、功能描述）
  • 输出：RNA 序列（生成）、功能预测分数（核酶活性、mRNA 稳定性）
  • 模块： 1. 预训练：DeepSeek 架构 LLM，跨物种转录组语料 2. 微调：功能预测头（核酶自切割、mRNA 稳定性） 3. 优化：GRPO 策略优化，以预测器为奖励模型
  • 训练：预训练 → 微调 → GRPO 强化学习
  • 工具：DeepSeek 架构、GRPO 算法
  • 反馈回路：生成序列 → 预测器打分 → GRPO 更新生成策略 → 新序列
  • 假设：LLM 的生成能力可捕捉 RNA 序列的功能相关特征；GRPO 可在满足约束的同时优化功能

文字流程： 1. 在跨物种转录组上预训练 RNASeek，学习 RNA 序列的通用表示与生成分布。 2. 微调为功能预测器（核酶活性、mRNA 稳定性），提取可解释的序列特征。 3. 将预测器作为奖励模型，用 GRPO 更新生成策略，使生成序列偏向高功能分数。 4. 实验验证生成序列的体外活性（核酶）与稳定性（3' UTR）。

11 结论正确解读

  • 任务范围：RNA 序列生成与功能设计（核酶、3' UTR），非结构预测或构象采样。
  • oracle/真值输入：功能预测器为微调模型，非实验真值；实验验证仅覆盖部分生成序列。
  • 端到端状态：预训练-微调-GRPO 闭环已实现，但实验验证规模有限。
  • 算力成本：未提供。
  • 历史数据依赖：依赖跨物种转录组与功能标注数据，数据偏差可能影响泛化。
  • 模型依赖：依赖 DeepSeek 架构与 GRPO 算法，其他架构或优化器效果未知。
  • 最难情形：复杂多结构域 RNA、非编码 RNA 的远距离相互作用可能超出当前模型能力。
  • 群体/领域边界：结果基于特定核酶与 3' UTR 数据集，不能推广至所有 RNA 功能类型。
  • 不确定性：实验验证的序列数量、重复次数、统计显著性未提供。

有边界的复述：RNASeek 在跨物种 RNA 序列生成与功能设计任务上，通过 GRPO 优化实现了实验验证的功能提升，但该结论仅限于核酶自切割活性与 3' UTR 稳定性两个任务，且定量细节未完整披露。

14 学到什么

Agent 提炼的知识候选： 1. 「预训练-预测-优化」闭环范式：将功能预测器作为奖励模型，用 GRPO 更新生成策略，可迁移至蛋白质序列设计（如酶活性、结合亲和力优化）。 2. 统一 token 空间设计：自然语言与生物序列共享 token 空间，可实现灵活的条件控制——可迁移至蛋白质设计中的「文本描述 → 序列生成」。 3. 跨物种预训练策略：跨物种语料库可提升零样本泛化，适用于蛋白质结构预测中的跨家族泛化。 4. 可解释特征提取：微调后的预测器可揭示功能相关序列特征（如环灵活性、茎稳定性、AU-rich motif），可迁移至蛋白质功能位点识别。 5. GRPO 在序列设计中的适用性：相比 PPO，GRPO 无需价值网络，更适用于高维序列空间的策略优化——可迁移至蛋白质构象采样或序列生成。

15 与已有知识连接

  • 相似：与 EvoDiff、ProGen2 等蛋白质生成模型在「生成式预训练 + 条件控制」上相似；与 ProteinMPNN + RL 在「生成 + 优化」闭环上同构。
  • 组合：RNASeek 的 GRPO 优化策略可与 AlphaFold 的预测分数结合，用于蛋白质序列设计中的结构约束优化。
  • 冲突：本文强调生成式 LLM 优于判别式模型，与部分观点（如结构预测优先）存在张力，但未提供直接对比。
  • 可迁移领域：蛋白质结构预测（序列 → 结构）、构象采样（生成多样构象）、分子对接（配体序列优化）、MD 模拟（力场参数优化）。
