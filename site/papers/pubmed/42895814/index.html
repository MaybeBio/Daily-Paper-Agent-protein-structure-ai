MARDy 2.0: a platform for exploring and analysing antifungal resistance mutations.

Webber, Joe; Gifford, Hugh; Rhodes, Johanna; Farrer, Rhys A
Bioinformatics (Oxford, England) · 2026-10-19 · 仅摘要 · 原文

该文介绍抗真菌耐药突变数据库平台MARDy 2.0，整合AlphaFold预测蛋白结构并展示突变位置，虽涉及蛋白结构展示但核心是数据平台而非结构计算建模方法创新，对蛋白质结构计算课题参考价值有限。

摘要

MOTIVATION: The rising incidence of antifungal drug resistance represents a major and growing threat to global public health and food security. Therefore, understanding the genetic and molecular mechanisms that underpin antifungal resistance is essential for both clinical management and agricultural disease control. RESULTS: We present MARDy 2.0, an updated platform replacing the original Mycology Antifungal Resistance Database. MARDy 2.0 provides an interactive platform for exploring antifungal resistance data from the community resource FungAMR, and protein structures from UniProtKB or predicted structures using AlphaFold. The platform provides enhanced tools for data exploration and analysis and is freely accessible via an interactive web interface that supports search filtering and downloads, BLAST-based sequence similarity searches, an experimental natural-language query interface for exploratory analysis, a mutation plot for visualising mutations in a protein context, and structural predictions showing mutation locations. MARDy 2.0 provides a platform to facilitate research into antifungal resistance evolution, surveillance, and mitigation strategies. MARDy should be used and cited alongside the underlying resources it integrates, FungAMR. AVAILABILITY: Accessible at https://mardy.net.

摘要翻译

动机：抗真菌药物耐药性发病率的上升对全球公共卫生和粮食安全构成了重大且日益严重的威胁。因此，理解支撑抗真菌耐药性的遗传和分子机制对于临床管理和农业病害控制均至关重要。结果：我们推出了MARDy 2.0，这是一个更新后的平台，取代了原有的真菌学抗真菌耐药性数据库（Mycology Antifungal Resistance Database）。MARDy 2.0提供了一个交互式平台，用于探索来自社区资源FungAMR的抗真菌耐药性数据，以及来自UniProtKB的蛋白质结构或使用AlphaFold预测的结构。该平台提供了增强的数据探索和分析工具，并通过一个交互式网页界面免费访问，该界面支持搜索过滤和下载、基于BLAST的序列相似性搜索、用于探索性分析的实验性自然语言查询界面、用于在蛋白质背景下可视化突变的突变图，以及显示突变位置的结构预测。MARDy 2.0提供了一个平台，以促进抗真菌耐药性进化、监测和缓解策略的研究。MARDy应与其整合的底层资源FungAMR一同使用和引用。可用性：可通过https://mardy.net访问。

03 研究问题

  • 具体问题：如何为抗真菌耐药突变研究提供一个集成、交互式、可访问的数据分析平台，使用户能够同时查询突变信息、查看蛋白结构上下文并进行序列相似性搜索？
  • 为什么重要：抗真菌药物耐药性上升对全球公共卫生和粮食安全构成重大威胁，理解耐药突变的遗传和分子机制对临床管理和农业病害控制至关重要。然而，突变数据与蛋白结构信息分散在不同资源中，缺乏统一平台。
  • 现有方法为何不足：原版 MARDy 数据库功能有限，缺乏结构可视化、序列搜索和自然语言查询等高级分析工具；其他资源（如 FungAMR 本身）可能仅提供数据存储而不提供交互式分析界面。
  • 精确研究问题：Can an integrated web platform combining resistance mutation data with protein structure predictions enable more effective exploration and analysis of antifungal resistance mutations?

06 核心思想

1) 表面方法

构建一个在线交互式网络平台，整合 FungAMR 耐药突变数据、UniProtKB 实验结构和 AlphaFold 预测结构，提供搜索过滤、下载、BLAST 序列搜索、自然语言查询、突变位置可视化和结构展示等功能。

2) 核心洞察

耐药突变的生物学意义只有在蛋白结构上下文中才能被充分理解——同一突变在不同蛋白结构位置可能产生完全不同的功能后果。将突变数据与结构预测（特别是 AlphaFold 的广泛覆盖）结合，可以显著降低研究者获取结构信息的门槛，使突变分析从「列表查看」升级为「结构感知」。

3) 可能的普适教训 [Analysis]

  • 数据库/平台类工具的价值不仅在于数据积累，更在于降低分析门槛——通过自然语言查询和可视化，使非计算专家也能进行复杂分析。
  • AlphaFold 预测结构的应用场景不仅是结构生物学本身，更在于作为注释层增强其他类型生物医学数据的可解释性。
  • 社区资源整合（如 FungAMR）与平台工具（如 MARDy）的分离与协作，是可持续数据生态的可行模式。

07 方法总览

  • 输入：用户查询（关键词、序列、自然语言问题）、FungAMR 耐药突变数据、UniProtKB 蛋白结构、AlphaFold 预测结构
  • 输出：突变列表、序列比对结果、自然语言查询答案、突变-结构可视化图、可下载数据
  • 模块： 1. 数据整合层：FungAMR 突变数据 + UniProtKB/AlphaFold 结构数据 2. 搜索过滤模块：关键词/字段过滤 3. BLAST 序列搜索模块：基于序列相似性的同源突变查找 4. 自然语言查询模块：实验性 NL 接口，支持探索性分析 5. 突变可视化模块：mutation plot 展示突变在蛋白序列/结构中的位置 6. 结构展示模块：3D 结构视图标注突变位置
  • 训练：不涉及（平台工具，非机器学习模型）
  • 工具：网络框架（未指定）、BLAST、AlphaFold 预测结构、UniProtKB API
  • 反馈回路：用户使用数据可反馈至 FungAMR 社区资源（推断，未明确说明）
  • 假设：AlphaFold 预测结构可作为实验结构的合理替代用于突变位置可视化；FungAMR 数据质量可靠

文字流程：用户通过网页界面输入查询（关键词/序列/自然语言）→ 平台调用相应模块（搜索过滤/BLAST/NL 解析）→ 从整合数据库中检索 FungAMR 突变数据 → 关联 UniProtKB/AlphaFold 结构 → 生成突变列表、序列比对或结构可视化结果 → 用户可下载数据或进一步探索。

11 结论正确解读

  • 任务范围：本文仅描述平台功能与数据整合方案，未进行生物学发现或方法学验证。
  • oracle/真值输入：依赖 FungAMR 的突变注释和 UniProtKB/AlphaFold 的结构数据，这些数据的准确性直接影响平台输出质量。
  • 端到端状态：平台已上线可访问（https://mardy.net），但「实验性」自然语言查询功能表明部分模块仍处于开发阶段。
  • 算力成本：未提供（平台为在线服务，客户端无算力要求；服务器端成本未披露）。
  • 历史数据依赖：平台价值依赖 FungAMR 和结构数据库的持续更新。
  • 模型依赖：依赖 AlphaFold 预测结构，预测误差可能影响突变位置展示的准确性。
  • 最难情形：对于无实验结构且 AlphaFold 预测置信度低的蛋白，突变结构注释可能不可靠。
  • 群体/领域边界：平台面向抗真菌耐药研究社区，主要覆盖致病真菌物种；对非模式真菌或新发物种的覆盖取决于 FungAMR 数据。
  • 不确定性：自然语言查询的准确性和召回率未评估；平台对大规模数据集的性能未测试。

有边界的复述：MARDy 2.0 是一个整合了 FungAMR 耐药突变数据与 UniProtKB/AlphaFold 蛋白结构的交互式网络平台，提供了搜索、BLAST、自然语言查询和结构可视化功能。该平台可作为抗真菌耐药突变探索的入口工具，但其生物学结论的可靠性受底层数据质量和预测结构准确性的限制。

14 学到什么

Agent 提炼的知识候选

  1. 结构注释作为数据增强层：将 AlphaFold 预测结构作为现有生物医学数据库的注释层，可以显著提升突变数据的可解释性。可迁移到蛋白质结构相关计算研究：在构建任何突变/变异数据库时，考虑集成结构上下文。

  2. 多源数据整合模式：FungAMR（社区数据）+ UniProtKB（实验结构）+ AlphaFold（预测结构）的三源整合模式，可推广到其他病原体耐药数据库或蛋白质功能数据库。

  3. 自然语言查询的探索性应用：即使作为「实验性」功能，NL 接口也能显著降低非专业用户的数据访问门槛。在蛋白质结构工具中，可考虑加入 NL 查询以支持「哪些突变位于活性位点附近？」类问题。

  4. 突变可视化设计：mutation plot 将突变映射到蛋白序列/结构上下文，这种可视化策略可迁移到任何突变-结构关联分析工具中。

  5. 平台与底层数据分离架构：MARDy 2.0 作为展示层，底层数据由 FungAMR 社区维护，这种「平台-数据」分离模式有利于可持续更新，值得在类似工具中借鉴。

  6. AlphaFold 结构的应用场景扩展：本文展示了 AlphaFold 结构在非结构生物学领域的应用（耐药突变注释），提示 AlphaFold 输出可作为多种下游分析的通用输入。

  • AlphaFold (Jumper et al., 2021, Nature)：本文使用 AlphaFold 预测结构作为突变可视化的结构模板，是 AlphaFold 在应用层面的扩展。
  • CARD (Comprehensive Antibiotic Resistance Database)：细菌耐药数据库，与 MARDy 2.0 功能类似但针对细菌；可对比两者在结构整合方面的差异。
  • UniProtKB：本文实验结构的来源，是蛋白质注释的标准资源。
  • 原版 MARDy：本文的直接前身，MARDy 2.0 在其基础上增加了结构可视化、BLAST 和 NL 查询功能。
  • ResFinder：另一耐药基因检测工具，与 MARDy 2.0 的 BLAST 功能有相似之处，但侧重检测而非探索分析。

16 研究想法

Agent 生成的研究候选

候选 1：基于结构上下文的耐药突变致病性预测器 - 名称：Structure-Aware Antifungal Resistance Mutation Predictor (SAARMP) - 来源局限/观察：MARDy 2.0 仅展示突变位置，不提供突变影响的定量预测；用户需自行判断突变的功能后果 - 核心假设：结合 AlphaFold 结构特征（pLDDT、溶剂可及性、残基接触网络）与序列保守性，可以比仅用序列特征更准确地预测耐药突变的功能影响 - 相对本文的增量：从「可视化」升级为「预测」，增加计算层 - 初步方法：以 FungAMR 已知耐药突变为正样本，构建结构特征（残基深度、二级结构、接触数、pLDDT）+ 序列特征（保守性、BLOSUM 得分）的机器学习分类器 - 验证方式：交叉验证 AUC；在独立文献验证的突变集上测试；与仅序列特征模型对比 - 可能的失败模式：耐药突变数量有限导致过拟合；结构特征与耐药性无强关联；不同物种间特征分布差异大 - 创新状态：unverified

候选 2：耐药突变-结构动态模拟工作流 - 名称：Resistance Mutation Structural Dynamics Pipeline (RMSDP) - 来源局限/观察：MARDy 2.0 提供静态结构视图，但突变对蛋白功能的影响常涉及构象动态变化，静态结构无法捕捉 - 核心假设：对已知耐药突变进行 MD 模拟，可以揭示突变引起的构象变化模式（如活性位点开放度、底物通道尺寸），这些模式可作为新突变功能预测的特征 - 相对本文的增量：引入 MD 模拟维度，从静态到动态 - 初步方法：选取 10-20 个已知耐药突变及其野生型，进行 100ns 级 MD 模拟，提取构象集合特征（RMSF、PCA、活性位点距离分布），训练分类器 - 验证方式：模拟特征与实验表型（MIC 值）的相关性；留一法交叉验证 - 可能的失败模式：MD 模拟成本高、通量低；耐药突变效应可能不体现在构象动态上；力场参数对突变残基处理不准确 - 创新状态：unverified

候选 3：跨物种耐药突变结构比较模块 - 名称：Cross-Species Resistance Mutation Structural Mapper (CSRMSM) - 来源局限/观察：MARDy 2.0 支持单物种查询，但抗真菌耐药机制常跨物种保守（如 CYP51 突变在多种真菌中导致唑类耐药），缺乏跨物种结构比较工具 - 核心假设：同源蛋白中的等效位置突变在不同物种中具有相似的功能影响，通过结构比对可以识别这些等效位置 - 相对本文的增量：增加同源建模和结构比对层，支持跨物种知识迁移 - 初步方法：对 FungAMR 中所有物种的耐药蛋白进行多序列比对和结构叠加，识别保守耐药热点区域；构建跨物种突变等效映射表 - 验证方式：已知跨物种保守耐药突变的召回率；与文献报道的交叉耐药模式对比 - 可能的失败模式：同源蛋白结构差异大导致比对不可靠；物种特异性耐药机制被过度泛化 - 创新状态：unverified

候选 4：自然语言查询增强的结构-突变问答系统 - 名称：Structure-Aware Mutation QA System (SAMQA) - 来源局限/观察：MARDy 2.0 的 NL 查询为「实验性」功能，且仅支持数据检索，不支持结构相关的复杂推理问题 - 核心假设：结合 LLM 与结构化知识图谱（突变-蛋白-结构-功能关系），可以回答「哪些突变可能影响药物结合？」「这个突变在 3D 结构中靠近哪些关键残基？」等复杂问题 - 相对本文的增量：从检索式 NL 升级为推理式 QA - 初步方法：构建突变-结构知识图谱，使用 RAG 架构将用户问题检索相关结构上下文，输入 LLM 生成答案 - 验证方式：专家评估答案准确性；与纯检索式系统对比用户满意度 - 可能的失败模式：LLM 幻觉产生错误结构描述；知识图谱覆盖不全；结构推理问题超出 LLM 能力 - 创新状态：unverified

候选 5：AlphaFold 结构质量对突变注释可靠性的影响评估 - 名称：AlphaFold Confidence-Aware Mutation Annotation Framework (ACAMAF) - 来源局限/观察：MARDy 2.0 使用 AlphaFold 结构展示突变位置，但未区分高置信度与低置信度区域；低 pLDDT 区域的突变位置可能不可靠 - 核心假设：在低 pLDDT 区域展示的突变位置具有较高的空间不确定性，可能误导功能推断；通过置信度加权可视化可以改善 - 相对本文的增量：为结构注释添加置信度维度 - 初步方法：对 FungAMR 中所有蛋白的 AlphaFold pLDDT 值进行统计分析，识别低置信度区域中的突变；开发置信度感知的可视化方案（如颜色编码、误差椭圆） - 验证方式：与实验结构对比，量化低 pLDDT 区域突变位置误差；用户研究评估置信度可视化对理解的影响 - 可能的失败模式：低 pLDDT 区域突变数量少，统计功效不足；置信度可视化增加认知负担 - 创新状态：unverified

  • Overall assessment The abstract describes a potentially useful update to an existing bioinformatics resource, but the evidence provided is insufficient to evaluate the technical soundness, novelty, or practical utility of the platform. The claims are largely descriptive and lack quantitative support. The abstract does not establish a clear advance over the original MARDy or other existing antifungal resistance databases, nor does it demonstrate that the new features function as described. The case for the platform's value is currently not established from the provided material.
