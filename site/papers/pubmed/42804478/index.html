6

Attribution assignment for deep-generative sequence models enables interpretability analysis using positive-only data.

Frank, Robert; Widrich, Michael; Akbar, Rahmad; Klambauer, Gunter; Sandve, Geir Kjetil; Robert, Philippe A; Greiff, Victor
PLoS computational biology · 2026-09-28 · 仅摘要 · 原文

该文提出针对自回归生成序列模型的可解释性归因方法GAMA，虽以抗体序列为对象且不直接涉及蛋白质结构计算，但其生成模型归因框架可迁移至蛋白质序列设计中的结构相关分析。

摘要

Generative machine learning models offer a powerful framework for therapeutic design, by efficiently exploring large spaces of biological sequences enriched for desirable properties. Unlike supervised learning methods, which require both positive and negative labeled data, generative models such as LSTMs can be trained solely on positively labeled sequences, for example, high-affinity antibodies. This is particularly advantageous in biological settings where negative data are scarce, unreliable, or biologically ill-defined. However, the lack of attribution methods for generative models has hindered the ability to extract interpretable biological insights from such models. To address this gap, we developed Generative Attribution Metric Analysis (GAMA), an attribution method for autoregressive generative models based on Integrated Gradients. We assessed GAMA using synthetic datasets with known ground truths to characterize its statistical behavior and validate its ability to recover biologically relevant features. We further demonstrated the utility of GAMA by applying it to experimental antibody-antigen binding data. GAMA enables model interpretability and the validation of generative sequence design strategies without the need for negative training data.

摘要翻译

生成式机器学习模型为治疗设计提供了一个强大的框架，能够高效探索富含理想特性的广阔生物序列空间。与需要正负标记数据的监督学习方法不同，诸如LSTM之类的生成模型可以仅使用正标记序列（例如高亲和力抗体）进行训练。这在负数据稀缺、不可靠或生物学定义不清的生物环境中尤为有利。然而，生成模型缺乏归因方法，阻碍了从这些模型中提取可解释的生物学见解。为弥补这一空白，我们开发了生成归因度量分析（Generative Attribution Metric Analysis, GAMA），这是一种基于集成梯度（Integrated Gradients）的自回归生成模型归因方法。我们使用具有已知真实标签的合成数据集评估了GAMA，以刻画其统计行为并验证其恢复生物学相关特征的能力。我们进一步通过将GAMA应用于实验性抗体-抗原结合数据，展示了其实用性。GAMA使得模型可解释性及生成序列设计策略的验证成为可能，而无需负训练数据。

02 一句话总结

本文提出 GAMA（Generative Attribution Metric Analysis），一种基于 Integrated Gradients 的归因方法，用于解释自回归生成式序列模型（如 LSTM）的预测行为，使仅用正样本（如高亲和力抗体序列）训练的模型能够恢复生物学相关特征，并在合成数据与实验抗体-抗原结合数据上验证了其有效性。

03 研究问题

  • 具体问题：如何对仅用正样本训练的生成式序列模型（如 LSTM）进行归因分析，从而提取可解释的生物学特征？
  • 为什么重要：在治疗性设计（如抗体工程）中，负样本（如低亲和力或无效序列）往往稀缺、不可靠或生物学上难以定义。生成模型只需正样本即可训练，但缺乏归因方法限制了其可解释性，阻碍了从模型中提取生物学洞察。
  • 现有方法为何不足：监督学习有成熟的归因方法（如 Integrated Gradients、SHAP），但这些方法通常需要分类或回归任务中的正负标签。生成模型（特别是自回归模型）的似然函数并非直接对应分类决策，现有归因工具无法直接适用。
  • 精确研究问题：Can we design an attribution method for autoregressive generative sequence models that recovers biologically relevant features from positive-only training data?

06 核心思想

  1. 表面方法：GAMA 将 Integrated Gradients 应用于自回归生成模型的似然函数，对每个序列位置的 token 计算归因分数，从而量化每个位置对模型输出的贡献。

  2. 核心洞察：生成模型的似然函数可以视为一个可微分的打分函数，即使没有分类标签，也可以通过梯度归因来识别哪些序列位置/特征对模型的高似然贡献最大。在正样本训练的生成模型中，高归因位置往往对应生物学上重要的残基（如抗体互补决定区 CDR）。

  3. 可能的普适教训 [Analysis]：任何可微分的生成模型（包括结构生成模型）都可以通过类似方式获得可解释性，无需依赖负样本。这一思路可迁移到蛋白质结构生成、构象采样等场景。

07 方法总览

  • 输入：正样本序列集合（如高亲和力抗体序列）；训练好的自回归生成模型（LSTM）
  • 输出：每个序列每个位置的归因分数（attribution scores）
  • 模块： 1. 生成模型训练（LSTM，仅用正样本） 2. 归因计算（Integrated Gradients 应用于似然函数） 3. 归因聚合与统计检验（跨序列聚合，识别显著位置）
  • 训练：LSTM 以标准最大似然估计训练，仅使用正样本
  • 工具：深度学习框架（未指定具体库）、Integrated Gradients 实现
  • 反馈回路：归因结果可反馈用于验证生成策略或指导序列设计
  • 假设：模型似然函数可微；正样本训练足以使模型捕获生物学相关特征；归因分数能反映特征重要性
  • 流程：训练 LSTM → 对每个序列计算似然关于输入 token 的梯度 → 沿路径积分得到归因分数 → 聚合分析 → 与已知生物学特征（如 CDR 位置）对比验证

09 关键公式符号

Integrated Gradients（IG）：

[ IG_i(x) = (x_i - x_i') \int_{\alpha=0}^{1} \frac{\partial F(x' + \alpha(x - x'))}{\partial x_i} d\alpha ]

  • ( x )：输入序列（one-hot 编码）
  • ( x' )：基线输入（如全零向量或均匀分布）
  • ( F )：模型输出（此处为序列似然）
  • ( \alpha )：插值路径参数
  • ( i )：输入维度（位置 × token）

用途：计算每个输入维度对模型输出的贡献，满足公理（敏感性、实现不变性）。

直觉：从基线到实际输入的路径上累积梯度，避免梯度饱和问题。

来源：方法部分（Integrated Gradients 定义，引用 Sundararajan et al. 2017）。

11 结论正确解读

  • 任务范围：仅针对自回归生成式序列模型（LSTM 为代表），不涉及其他生成架构（如 VAE、GAN）或结构模型
  • oracle/真值输入：合成数据有已知 ground truth；抗体数据以 CDR 位置作为近似生物学真值
  • 端到端状态：方法已验证但未形成完整设计闭环（未展示归因结果直接指导序列设计并验证）
  • 算力成本：未报告
  • 历史数据依赖：依赖训练生成模型的正样本数据质量
  • 模型依赖：归因结果依赖 LSTM 模型训练质量；不同初始化或超参数可能影响归因
  • 最难情形：序列中长程相互作用、协同效应可能无法通过逐位置归因完全捕获
  • 群体/领域边界：验证限于抗体序列；其他生物序列（如酶、TCR）未测试
  • 不确定性：归因分数是统计估计，存在方差；未报告置信区间

有边界的复述：GAMA 在合成数据与抗体数据上展示了从正样本训练的 LSTM 中恢复生物学相关位置的能力，但其适用范围限于自回归序列模型，且未证明归因与功能之间的因果关系。

14 学到什么

Agent 提炼的知识候选：

  1. 归因方法迁移：Integrated Gradients 可适配生成模型的似然函数，这一思路可直接迁移到蛋白质结构生成模型（如基于自回归的序列-结构共生成模型），用于识别决定结构稳定性的关键残基。

  2. 正样本训练的可解释性：在结构预测或设计中，负样本（如错误折叠结构）同样难以定义，GAMA 的正样本归因思路可迁移到结构评分函数或生成模型的解释。

  3. 合成数据验证框架：使用已知 ground truth 的合成数据验证归因方法，这一实验设计可迁移到结构相关任务（如已知功能位点的突变扫描数据）。

  4. 逐位置归因的生物学验证：将归因位置与已知功能区域（如 CDR、活性位点）对比，是验证可解释性方法的有效策略，可迁移到酶设计、结合位点预测等任务。

  5. 统计检验的必要性：对归因分数进行显著性检验，避免将噪声当信号，这一原则适用于所有基于梯度的可解释性分析。
