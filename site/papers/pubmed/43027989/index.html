Beyond the Black Box: Physics-Based and Conservation-Informed Evidence for ACVRL1 Variant Classification in Hereditary Hemorrhagic Telangiectasia and Pulmonary Arterial Hypertension.

Brusgaard, Klaus
International journal of molecular sciences · 2026-11-14 · 仅摘要 · 原文

该研究利用蛋白质稳定性预测和保守性评分等结构信息训练随机森林分类器，对ACVRL1错义变异进行致病性分类，虽以变异分类为核心而非直接的结构计算建模，但方法可迁移至蛋白质结构相关计算任务。

摘要

Missense variants in ACVRL1 (ALK1) cause hereditary hemorrhagic telangiectasia type 2 (HHT2), heritable pulmonary arterial hypertension (PAH), or both in the same patient, and many remain variants of uncertain significance. AlphaMissense classifies them accurately but does not show which evidence drives a call. I annotated 899 ACVRL1 missense variants with protein-stability estimates (FoldX, DynaMut2), a GREMLIN-style conservation score, and structural context. I then trained random-forest classifiers on 311 variants with labels traceable to ClinVar or a publication (296 pathogenic-like, 15 benign-like). A structural/conservation-only classifier (Model 1b) reached a cross-validated ROC-AUC of 0.954 (95% CI 0.916-0.984), and a model adding sequence-based predictors (Model 1) reached 0.979, versus 0.983 for AlphaMissense on the same variants. On variants first reported in 2025-2026, Model 1b scored 0.976, Model 1 0.992, and AlphaMissense 0.992; equivalence within +/-0.05 AUC was supported for Model 1 only. Benign variants were the main weakness: Model 1b correctly classified 10/15, against 14/15 for AlphaMissense. Conservation drove most calls, with predicted destabilization contributing to a minority. An interpretable, gene-specific classifier can approach AlphaMissense for ACVRL1 while showing the structural or evolutionary evidence behind each call. Its calls are hypotheses, not functional evidence, and can prioritize VUS for functional testing.

摘要翻译

ACVRL1 (ALK1) 中的错义变异导致遗传性出血性毛细血管扩张症2型（HHT2）、遗传性肺动脉高压（PAH），或同一患者同时患有这两种疾病，且许多变异仍为意义不明确的变异。AlphaMissense 能准确分类这些变异，但未显示驱动判定的证据。我使用蛋白质稳定性估计（FoldX、DynaMut2）、GREMLIN 式保守性评分及结构背景，对 899 个 ACVRL1 错义变异进行了注释。随后，我在 311 个标签可追溯至 ClinVar 或出版物的变异（296 个致病样，15 个良性样）上训练了随机森林分类器。仅基于结构和保守性的分类器（模型 1b）达到交叉验证的 ROC-AUC 为 0.954（95% CI 0.916-0.984），而加入基于序列预测因子的模型（模型 1）达到 0.979，相比之下，AlphaMissense 在同一批变异上为 0.983。在 2025-2026 年首次报告的变异上，模型 1b 得分为 0.976，模型 1 为 0.992，AlphaMissense 为 0.992；仅模型 1 支持在 ±0.05 AUC 范围内的等价性。良性变异是主要弱点：模型 1b 正确分类 10/15，而 AlphaMissense 为 14/15。保守性驱动了大多数判定，预测的去稳定化仅贡献于少数。一个可解释的、基因特异性的分类器在 ACVRL1 上可接近 AlphaMissense 的性能，同时展示每次判定背后的结构或进化证据。其判定是假设，而非功能证据，可用于优先对 VUS 进行功能测试。

02 一句话总结

针对 ACVRL1 基因的 missense 变异，作者用 FoldX/DynaMut2 蛋白稳定性预测与 GREMLIN 保守性分数构建随机森林分类器，在 311 个有标签变异上达到与 AlphaMissense 相当的 ROC-AUC（0.979 vs 0.983），且能显式展示每个调用背后的结构或进化证据，但良性变异分类仍是主要短板。

03 研究问题

  • 具体问题: ACVRL1（ALK1）基因的 missense 变异可导致 HHT2、遗传性 PAH 或两者兼有，但许多变异仍为 VUS（意义未明变异）。AlphaMissense 能准确分类但不揭示驱动判定的证据。能否构建一个可解释的、基因特异的分类器，在保持与 AlphaMissense 相当精度的同时，显式展示每个调用背后的结构/进化证据？
  • 为什么重要: 临床遗传咨询需要可解释的变异分类依据，黑箱预测难以直接用于临床决策；可解释模型可帮助优先筛选 VUS 进行功能验证。
  • 现有方法为何不足: AlphaMissense 等深度学习方法精度高但不可解释；传统 ACMG 指南依赖人工规则，缺乏结构层面的定量证据整合。
  • 精确研究问题: "Can an interpretable, gene-specific classifier using physics-based stability estimates and conservation scores achieve classification performance comparable to AlphaMissense for ACVRL1 missense variants, while providing per-variant evidence?"

04 背景与发展脉络

（标注：以下脉络为「经外部核验」的领域常识，结合本文框架） 1. 阶段一：基于人群频率与注释的规则分类（如 ACMG/AMP 指南，2015 年至今） - 优点：临床可操作、标准化 - 局限：对罕见 VUS 缺乏统计功效，不利用结构信息 2. 阶段二：序列保守性评分（如 GERP、PhyloP、GREMLIN 的进化耦合） - 优点：捕捉纯化选择信号 - 局限：单点保守性忽略结构上下文 3. 阶段三：蛋白质结构预测与稳定性计算（AlphaFold2 2021；FoldX、DynaMut2 等） - 优点：提供物理化学层面的定量证据（ΔΔG） - 局限：单独使用精度有限，需与进化信息整合 4. 阶段四：端到端深度学习黑箱（AlphaMissense 2023） - 优点：精度高、覆盖全蛋白质组 - 局限：不可解释、不提供证据链 5. 本文位置: 在阶段三与阶段四之间架桥——用可解释的随机森林整合结构稳定性 + 保守性，逼近 AlphaMissense 精度，同时保留证据可追溯性。

06 核心思想

  1. 表面方法: 用 FoldX 和 DynaMut2 计算每个 missense 变异的蛋白稳定性变化（ΔΔG），用 GREMLIN 风格分数计算进化保守性，结合结构上下文（如二级结构位置、溶剂可及性），训练随机森林分类器。
  2. 核心洞察: 对于 ACVRL1 这类有明确结构-功能关系的蛋白，物理稳定性 + 进化保守性的组合足以逼近 AlphaMissense 的精度，且每个特征对最终调用的贡献可被显式量化（如特征重要性、SHAP 值）。保守性主导大多数调用，稳定性预测仅贡献于少数变异——说明进化信号比物理化学信号更具判别力。
  3. 可能的普适教训 [Analysis]: 对于任何有结构信息的蛋白，可解释的浅层模型 + 物理/进化特征可以作为黑箱深度模型的替代或补充，尤其在临床场景中需要证据链时。此策略可迁移至其他疾病基因的变异分类。

07 方法总览

  • 输入: ACVRL1 蛋白序列、结构（可能来自 AlphaFold2 或实验结构）、899 个 missense 变异的列表
  • 输出: 每个变异的致病性分类（致病样/良性样）及特征贡献解释
  • 模块: 1. 变异注释模块：FoldX（结构稳定性）、DynaMut2（动力学稳定性）、GREMLIN 保守性、结构上下文 2. 标签来源模块：ClinVar 或文献追溯（311 个有标签变异：296 致病样，15 良性样） 3. 分类器模块：随机森林（两种配置：Model 1b 仅结构/保守性特征；Model 1 加序列特征） 4. 评估模块：交叉验证 ROC-AUC，与 AlphaMissense 对比，时间外推验证（2025-2026 新变异）
  • 训练: 311 个有标签变异，交叉验证
  • 假设: 结构稳定性与保守性可捕获 ACVRL1 变异的致病性信号；可解释模型可达到与黑箱相当的精度
  • 流程: 变异注释 → 特征构建 → 随机森林训练/交叉验证 → 与 AlphaMissense 对比 → 时间外推测试 → 特征归因分析

11 结论正确解读

  • 任务范围: 仅针对 ACVRL1 基因的 missense 变异分类，非全基因组或全蛋白质组。
  • oracle/真值输入: 标签来自 ClinVar/文献，可能包含错误或偏倚（如 publication bias 偏向致病性）。
  • 端到端状态: 非端到端——需要预先计算结构特征与保守性分数，且依赖外部工具（FoldX, DynaMut2, GREMLIN）。
  • 算力成本: 未提供，但随机森林训练成本低；特征计算（FoldX/DynaMut2）需结构，成本中等。
  • 历史数据依赖: 训练集标签依赖历史 ClinVar/文献，可能受时间偏倚影响。
  • 模型依赖: 随机森林为浅层模型，特征工程是关键；不同特征组合可能改变结论。
  • 最难情形: 良性变异分类（仅 10/15 正确）；无明确结构/保守性信号的变异。
  • 群体/领域边界: 仅适用于 ACVRL1；其他基因需重新训练。
  • 不确定性: 95% CI 较宽（0.916-0.984），样本量小（311），良性样本极少（15）。
  • 有边界的复述: 在 ACVRL1 基因、311 个有标签变异、随机森林 + FoldX/DynaMut2/GREMLIN 特征的条件下，该可解释模型达到与 AlphaMissense 相当的交叉验证 AUC，且能提供特征归因；但良性变异分类能力有限，且结论不能外推至其他基因或更大变异集。

14 学到什么

Agent 提炼的知识候选（面向蛋白质结构相关计算研究 × AI/物理模拟）: 1. 可解释分类器设计: 用随机森林（或逻辑回归）整合物理模拟（ΔΔG）与进化保守性，替代或补充黑箱深度模型——在临床场景中证据链比单纯精度更重要。可迁移至其他疾病基因的变异分类。 2. 特征组合策略: FoldX（静态稳定性）+ DynaMut2（动力学稳定性）+ GREMLIN（进化耦合）的组合覆盖了「结构-动力学-进化」三个正交维度，这种多视角特征工程思路可迁移至蛋白设计或构象采样中的打分函数设计。 3. 时间外推验证: 用最近报道的变异作为时间外推测试集，检验模型对新数据的泛化——这是评估变异分类器实用性的关键设计，可迁移至任何预测模型的评估协议。 4. 良性变异难点: 训练集中良性样本稀缺是普遍问题，提示在构建变异分类数据集时需主动平衡标签分布，或采用异常检测框架（仅用致病样训练）。 5. 黑箱对比框架: 将可解释模型与 AlphaMissense 在同一变异集上对比，并设定等价性阈值（±0.05 AUC）——这种「可解释模型 vs 黑箱基准」的评估框架可迁移至其他结构预测任务。

  • AlphaMissense (Cheng et al., 2023, Science): 本文直接以 AlphaMissense 为黑箱基准，验证可解释模型的等价性。AlphaMissense 基于 AlphaFold 的 ESM 嵌入，覆盖全蛋白质组，但不可解释。
  • FoldX (Schymkowitz et al., 2005): 经典蛋白稳定性计算工具，广泛用于变异致病性研究；本文将其作为物理特征来源。
  • DynaMut2 (Rodrigues et al., 2021): 基于图卷积的稳定性预测器，结合动力学信息，补充 FoldX 的静态视角。
  • GREMLIN (Kamisetty et al., 2013; Balakrishnan et al., 2011): 直接耦合分析（DCA）方法，用于从序列比对推断进化耦合；本文用其保守性分数作为进化特征。
  • ACVRL1/ALK1 与 HHT2/PAH: ACVRL1 编码 TGF-β 家族受体 ALK1，其突变导致 HHT2 和/或 PAH；该基因的变异分类是临床遗传学的活跃领域。
  • 可解释 ML 在变异分类中的应用: 与 ClinGen 的 ACMG/AMP 框架互补，后者依赖规则而非定量结构证据。
  • [Analysis] 候选连接: 本文框架可类比于蛋白设计中的「物理能量项 + 进化统计势」混合打分（如 Rosetta + EVcouplings），提示变异分类与蛋白设计在特征工程上存在方法论共性。

16 研究想法

Agent 生成的研究候选:

  1. 名称: 多基因可解释变异分类框架扩展（Multi-gene Interpretable Variant Classifier, MIVC） - 来源局限/观察: 本文仅针对 ACVRL1，基因特异模型无法直接迁移至其他基因。 - 核心假设: 结构稳定性 + 保守性特征可跨基因泛化，但需基因特异校准。 - 初步方法: 在多个 HHT/PAH 相关基因（ENG, SMAD4, BMPR2, CAV1, KCNK3）上重复本文流程，训练共享特征 + 基因特异头的分层模型。 - 验证方式: 与 AlphaMissense 在各基因上对比 AUC，并检验跨基因迁移性能。 - 创新状态: unverified

  2. 名称: 良性变异增强采样策略（Benign Variant Augmentation via Decoy Generation） - 来源局限/观察: 良性样本仅 15 个，导致良性分类弱。 - 核心假设: 用同义变异或已知良性多态作为 decoy 可增强训练集。 - 初步方法: 从 gnomAD 获取 ACVRL1 的常见多态（MAF > 0.01）作为良性样，结合本文特征管道重训。 - 验证方式: 在独立良性集上评估召回率提升。 - 创新状态: unverified

  3. 名称: 结构系综感知的变异分类（Ensemble-aware Variant Classification） - 来源局限/观察: 本文用单一结构计算 ΔΔG，未考虑蛋白构象系综。 - 核心假设: 在 MD 模拟或 AlphaFold 生成的构象系综中计算 ΔΔG 分布，可提高致病性判别力。 - 初步方法: 对 ACVRL1 的 20 个代表性变异进行 MD 模拟（100 ns），提取 ΔΔG 时间序列特征（均值、方差、极值）加入随机森林。 - 验证方式: 与单结构 ΔΔG 特征对比 AUC。 - 创新状态: unverified

  4. 名称: 特征归因驱动的 VUS 功能验证优先级评分（Attribution-guided VUS Prioritization Score） - 来源局限/观察: 模型输出"hypotheses, not functional evidence"，但未提供具体优先级工具。 - 核心假设: 特征归因（如 SHAP 值）可转化为可操作的功能验证优先级。 - 初步方法: 对每个 VUS 输出 SHAP 分解，将「稳定性驱动」与「保守性驱动」的变异分组，分别推荐不同的功能实验（如热稳定性实验 vs 进化功能 assay）。 - 验证方式: 与已有功能实验数据（如 HHT 突变数据库）对比优先级排序。 - 创新状态: unverified

  5. 名称: 时间外推鲁棒性评估框架（Temporal Generalization Benchmark for Variant Classifiers） - 来源局限/观察: 本文用 2025-2026 新变异做时间外推，但未系统化此协议。 - 核心假设: 时间外推 AUC 是变异分类器实用性的关键指标，应成为标准评估协议。 - 初步方法: 在 ClinVar 全库上按报道年份切分训练/测试集，评估 AlphaMissense、本文模型及 ClinGen 规则的逐年性能变化。 - 验证方式: 比较各方法的时间外推 AUC 曲线。 - 创新状态: unverified
