7

Structural basis of serine protease inhibition by antibodies from biased Fab phage-display libraries.

Anderson, Kyle J; Lee, Melody S; Sevillano, Natalia; Chen, Gang; Hornsby, Michael J; Sidhu, Sachdev S; Craik, Charles S
Biological chemistry · 2026-10-09 · 仅摘要 · 原文

该研究结合偏置Fab噬菌体展示文库与共折叠结构预测及对接，解析抗体抑制丝氨酸蛋白酶的机制，虽以抗体-蛋白酶复合物为对象，但结构预测与能量计算框架可迁移至蛋白质结构计算研究。

摘要

Biased Fab phage-display libraries were designed to determine whether inhibitory CDR H3 motifs from potent anti-matriptase antibodies could be transferred to target homologous serine proteases. Using reverse-binding and substrate-like H3 motifs from parental clones A11 and E2 as templates, six synthetic libraries with 10(10) diversity were constructed. Selection against matriptase identified 16 inhibitors with sub-100 nM potency, representing 100,000-fold improvement over circularized H3 loops alone. Selection against TMPRSS2, a serine protease implicated in viral entry and prostate cancer with 43 % sequence identity to matriptase, yielded binders with micromolar inhibitory potency. Selection against urokinase plasminogen activator (uPA, 35 % identity) identified binders that adopted a substrate-like CDR H3 binding mode in our structural models. Across all reference structures, including the separately identified uPA inhibitor AB2 (PDB: 9PYF, deposited with this work), benchmarking of five co-folding methods and rigid-body docking showed that co-folding consistently achieved acceptable to high quality DockQ scores, outperforming traditional docking and capturing the recognition of key active site determinants. Ensemble predictions of mutational binding energy changes (DeltaDeltaG) using these models identified key paratope-epitope interactions, with predictions validated through mutagenesis. This work establishes a framework integrating biased antibody libraries with computational structure prediction and analysis for targeting conserved protease epitopes.

摘要翻译

为确定强效抗matriptase抗体中的抑制性CDR H3基序能否转移至靶向同源丝氨酸蛋白酶，设计了偏倚Fab噬菌体展示文库。以亲本克隆A11和E2的反向结合及底物样H3基序为模板，构建了六个多样性为10(10)的合成文库。针对matriptase的筛选鉴定出16个效力低于100 nM的抑制剂，较环化H3环单独使用提高了100,000倍。针对TMPRSS2（一种与病毒入侵和前列腺癌相关的丝氨酸蛋白酶，与matriptase序列同一性为43%）的筛选获得了微摩尔级抑制效力的结合物。针对尿激酶型纤溶酶原激活剂（uPA，同一性35%）的筛选鉴定出在结构模型中采用底物样CDR H3结合模式的结合物。在所有参考结构中，包括单独鉴定的uPA抑制剂AB2（PDB: 9PYF，随本研究提交），五种共折叠方法和刚性对接的基准测试表明，共折叠始终达到可接受至高质量的DockQ分数，优于传统对接，并捕获了关键活性位点决定因素的识别。使用这些模型对突变结合能变化（DeltaDeltaG）的集成预测鉴定了关键的部分位-表位相互作用，并通过突变实验验证了预测。本研究建立了一个整合偏倚抗体文库与计算结构预测和分析的框架，用于靶向保守蛋白酶表位。

03 研究问题

  • 具体问题: 能否将强效抗 matriptase 抗体的抑制性 CDR H3 基序（reverse-binding 与 substrate-like 两种模式）转移到同源丝氨酸蛋白酶（TMPRSS2、uPA），从而快速生成跨靶点抑制剂？
  • 为什么重要: 丝氨酸蛋白酶家族成员众多且结构保守，但功能各异（如 matriptase 在癌症中、TMPRSS2 在病毒入侵中、uPA 在肿瘤转移中）。若能建立可迁移的抑制基序库，将大幅加速针对新靶点的抑制剂开发。
  • 现有方法不足: 传统抗体发现需针对每个靶点独立筛选；circularized H3 loops 单独使用效力极低（本文中较全长 Fab 低 100,000 倍）；结构预测在抗体-蛋白酶复合物上的可靠性未经系统验证。
  • 精确研究问题: Can biased Fab phage-display libraries based on inhibitory CDR H3 motifs from potent anti-matriptase antibodies yield sub-micromolar inhibitors against homologous serine proteases (TMPRSS2, uPA), and can co-folding structure prediction accurately capture the binding modes and key energetic determinants of these cross-reactive antibodies?

06 核心思想

1) 表面方法: - 从强效抗 matriptase 抗体 A11（reverse-binding H3）和 E2（substrate-like H3）提取 CDR H3 基序 - 构建 6 个 biased Fab 噬菌体展示文库（总多样性 10^10） - 分别对 matriptase、TMPRSS2、uPA 进行筛选 - 对获得的抑制剂进行结构预测（5 种 co-folding 方法 + rigid-body docking 基准测试） - 用 ensemble 结构预测 DeltaDeltaG 并实验验证

2) 核心洞察: - 抑制性 CDR H3 基序具有跨同源靶点的可转移性，但需要 Fab 框架提供亲和力支撑（100,000 倍差异） - Co-folding 方法在抗体-蛋白酶复合物预测上系统性优于 rigid-body docking，能捕获活性位点关键识别 - Ensemble 突变能量预测可有效识别 paratope-epitope 关键相互作用，且与实验突变验证一致

3) 可能的普适教训 [Analysis]: - 对结构保守的酶家族，预先验证的抑制基序库可作为「模块化工具箱」跨靶点使用，大幅缩短开发周期 - 结构预测方法的选择需针对复合物类型进行基准测试，co-folding 对构象变化大的界面（如酶活性位点）更优 - 能量预测需考虑构象系综而非单一结构，尤其对柔性界面

07 方法总览

输入: - 亲本抗体 A11、E2 的 CDR H3 序列（reverse-binding 与 substrate-like 基序） - 靶蛋白序列：matriptase、TMPRSS2、uPA

输出: - 针对三个靶点的抑制性 Fab 抗体（16 个 matriptase 抑制剂 <100 nM；TMPRSS2 微摩尔级抑制剂；uPA 抑制剂含 AB2） - 抗体-蛋白酶复合物结构模型 - 关键 paratope-epitope 相互作用图谱

模块: 1. Biased 文库构建：以 A11/E2 H3 为模板，随机化周边残基，构建 6 个 Fab 文库 2. 噬菌体展示筛选：针对三个靶蛋白进行 panning 3. 效力测定：IC50 或 Ki 测定 4. 结构预测：5 种 co-folding 方法 + rigid-body docking 基准测试 5. 能量分析：ensemble DeltaDeltaG 预测 6. 实验验证：突变分析验证预测的关键相互作用

工具: 噬菌体展示技术、SPR/ELISA（推测）、AlphaFold2 及变体（co-folding）、docking 软件（具体未提供）、Rosetta 或类似能量计算工具（推测）

假设: - 同源蛋白酶（≥35% 序列同一性）共享可被同一抑制基序识别的保守表位 - Co-folding 能准确预测抗体-蛋白酶复合物结构 - Ensemble 能量预测能识别功能关键残基

文字流程: 从亲本抗体提取 H3 基序 → 构建 biased 文库 → 对三个靶点筛选 → 获得抑制剂并测效力 → 对代表性抑制剂（含 AB2）进行结构预测 → 基准测试 co-folding vs docking → 用最优模型进行 ensemble DeltaDeltaG 预测 → 突变实验验证 → 建立整合框架

11 结论正确解读

  • 任务范围: 本文结论仅适用于丝氨酸蛋白酶家族中与 matriptase 具有 ≥35% 序列同一性的成员；不适用于其他蛋白酶家族或非蛋白酶靶点。
  • oracle/真值输入: 亲本抗体 A11/E2 的已知抑制活性是 biased 文库设计的先验知识；AB2 的实验结构（PDB: 9PYF）作为结构预测的验证真值。
  • 端到端状态: 本文展示了从文库设计到抑制剂发现的完整流程，但 TMPRSS2 仅达微摩尔级，未达到治疗候选标准；uPA 抑制剂的全面表征（选择性、体内活性）未在摘要中提供。
  • 算力成本: 未提供结构预测的计算资源信息。
  • 历史数据依赖: 依赖亲本抗体的已知活性数据；无此先验则 biased 设计不适用。
  • 模型依赖: 结论依赖 co-folding 方法的准确性；基准测试仅覆盖 5 种方法，未涵盖所有可用工具。
  • 最难情形: 35% 同一性的 uPA 靶点获得抑制剂但效力未明确；更远缘靶点（<35% 同一性）的可转移性未测试。
  • 不确定性: 微摩尔级 TMPRSS2 抑制剂的实际应用价值有限；DeltaDeltaG 预测的定量准确性未提供具体误差范围。
  • 群体/领域边界: 结论适用于抗体-丝氨酸蛋白酶相互作用；对其他酶类（如半胱氨酸蛋白酶）的推广未经测试。

有边界的复述: 基于已验证的抑制性 CDR H3 基序构建 biased Fab 文库，可在丝氨酸蛋白酶家族内（≥35% 同一性）实现抑制活性的跨靶点转移，其中 co-folding 结构预测能可靠建模复合物并辅助识别关键相互作用残基，但跨靶点效力随序列同一性降低而下降。

14 学到什么

Agent 提炼的知识候选:

  1. Biased 文库设计策略: 以已验证的抑制基序为模板，通过周边残基随机化构建次级文库，可跨同源靶点转移功能。→ 可迁移至蛋白质设计：对已知功能 motif 进行「motif grafting + 周边优化」而非从头设计。

  2. Co-folding 优于 rigid-body docking 的复合物预测: 对构象变化大的酶-抗体界面，co-folding 能更好捕获 induced fit。→ 可迁移至结构预测课题：对柔性界面复合物优先选择 co-folding 而非 docking。

  3. Ensemble DeltaDeltaG 预测流程: 用多个结构模型进行能量预测取集合结果，可提高关键残基识别可靠性。→ 可迁移至突变效应预测：单结构预测不可靠时采用 ensemble 策略。

  4. 跨靶点效力梯度作为验证工具: 序列同一性梯度（100%→43%→35%）可作为检验基序可转移性的天然实验设计。→ 可迁移至同源蛋白设计：用同一性梯度系统评估设计策略的普适性。

  5. 结构预测与实验验证的闭环: 预测关键相互作用残基 → 突变验证 → 修正模型。→ 可迁移至计算驱动蛋白工程：建立「预测-验证-修正」迭代循环。

  6. Substrate-like vs reverse-binding 两种抑制模式: 不同 H3 构象模式可靶向同一酶活性位点，提供多种抑制策略选择。→ 可迁移至抑制剂设计：考虑多种结合模式而非单一构象。

15 与已有知识连接

  • AlphaFold2 及 co-folding 方法: 本文基准测试的 co-folding 方法属于 AlphaFold2 及其变体（如 AF2Complex、ColabFold）在抗体-抗原复合物预测上的应用。与已有文献一致，co-folding 对构象变化大的界面优于 docking（参考 Evans et al., 2022; Bryant et al., 2022）。
  • 噬菌体展示抗体工程: 本文的 biased 文库策略与 Sidhu 实验室此前在合成抗体文库方面的工作一脉相承（如 Fellouse et al., 2007; Persson et al., 2013）。
  • 丝氨酸蛋白酶抑制剂: 与已有小分子和蛋白抑制剂研究互补，本文提供抗体-based 抑制策略，扩展了抑制剂类型。
  • DeltaDeltaG 预测: 与 Rosetta 和 FoldX 等能量计算工具的已有应用一致，但强调 ensemble 策略，与近期关于构象系综影响能量预测的文献一致（如 Barlow et al., 2018）。
  • 候选方向 [Analysis]: 本文的框架可推广至其他酶家族（如半胱氨酸蛋白酶、金属蛋白酶），但需验证基序可转移性是否依赖特定保守表位特征。

  3. 候选名称: Ensemble DeltaDeltaG 预测的自动化流程用于抗体亲和力成熟 - 来源局限/观察: 本文展示了 ensemble DeltaDeltaG 可识别关键残基，但未将其用于亲和力成熟设计 - 核心假设: 基于 ensemble 结构的 DeltaDeltaG 预测可指导抗体亲和力成熟，优于单结构预测或随机突变 - 初步方法: 以本文获得的抑制剂为起点，用 ensemble DeltaDeltaG 预测所有 paratope 残基的单点突变效应；选择预测有利突变进行组合；实验验证亲和力变化 - 验证方式: 预测与实验 DeltaDeltaG 相关性；亲和力成熟成功率对比随机突变 - 创新状态: unverified

  4. 候选名称: 抑制基序可转移性的结构决定因素分析 - 来源局限/观察: 本文发现 substrate-like 和 reverse-binding 两种模式均可转移，但未分析何种结构特征决定转移成功 - 核心假设: 可转移性由 H3 环与靶点活性位点的形状互补性和极性匹配决定，而非简单序列同一性 - 初步方法: 对成功/失败的转移案例进行结构比较；计算 H3 环与各靶点活性位点的形状互补性（Sc 值）、静电互补性；建立结构特征-可转移性关联模型 - 验证方式: 模型预测新靶点的可转移性，实验验证 - 创新状态: unverified
