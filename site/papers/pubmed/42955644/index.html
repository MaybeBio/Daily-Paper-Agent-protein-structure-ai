Using the Function Prediction Server and Queryome for Functional Protein Design.

Punuru, Pranav; Giri, Swagarika; Kihara, Daisuke
Methods in molecular biology (Clifton, N.J.) · 2026-10-29 · 仅摘要 · 原文

该文介绍蛋白质功能预测工具（PFP、ESG等）和文献分析系统Queryome，用于辅助功能蛋白设计，但核心是功能注释而非结构预测/构象采样/对接等结构计算问题，方法上以序列搜索和文献挖掘为主，缺乏结构建模或AI/物理模拟方法，与蛋白质结构计算课题关联较弱。

摘要

Accurate computational prediction of protein function is critical for guiding the functional design of proteins in the post-genomic era. The gap between the number of protein sequences deposited in databases and those with experimentally validated functional annotations continues to widen, making automated function prediction tools indispensable for researchers. In this chapter, we describe a suite of complementary computational tools for protein function prediction and literature-based functional analysis. We cover four sequence-based Gene Ontology (GO) term prediction methods available through the Protein Function Prediction web server: PFP, ESG (Extended Similarity Group), Phylo-PFP, and Domain-PFP. Each method leverages distinct algorithmic strategies, from mining distantly related sequences with PSI-BLAST to recursive multilevel sequence searches, phylogenetic distance-based reranking, and function-aware domain embeddings. We also describe Queryome, a multi-agent deep research system that performs evidence-grounded synthesis across 28.3 million PubMed abstracts, which can be used to contextualize and validate function predictions with primary literature evidence. We provide step-by-step protocols for using these tools, interpreting results, and integrating predictions into a workflow for the functional design of proteins. The Protein function prediction server is available at www.kiharalab.org/pfp and Queryome is available as a desktop application at www.queryome.app.

摘要翻译

蛋白质功能的准确计算预测对于后基因组时代指导蛋白质的功能设计至关重要。数据库中存储的蛋白质序列数量与具有实验验证功能注释的蛋白质数量之间的差距持续扩大，使得自动化功能预测工具对研究人员而言不可或缺。在本章中，我们描述了一套用于蛋白质功能预测和基于文献的功能分析的互补计算工具。我们涵盖了通过蛋白质功能预测网络服务器提供的四种基于序列的基因本体（Gene Ontology, GO）术语预测方法：PFP、ESG（扩展相似性组，Extended Similarity Group）、Phylo-PFP和Domain-PFP。每种方法利用不同的算法策略，从使用PSI-BLAST挖掘远缘相关序列，到递归多级序列搜索、基于系统发育距离的重新排序，以及功能感知的域嵌入。我们还描述了Queryome，一个多智能体深度研究系统，该系统在2830万篇PubMed摘要中进行基于证据的综合分析，可用于结合原始文献证据来情境化和验证功能预测。我们提供了使用这些工具、解释结果以及将预测整合到蛋白质功能设计工作流程中的逐步协议。蛋白质功能预测服务器可在www.kiharalab.org/pfp访问，Queryome作为桌面应用程序可在www.queryome.app获取。
