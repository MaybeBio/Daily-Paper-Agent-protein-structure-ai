AmyloDeep: protein language model-based ensemble model for predicting amyloid propensity from the amino acid sequence.

Davtyan, Alisa; Khachatryan, Anahit; Petrosyan, Rafayel
Bioinformatics advances · 2026-11-04 · 全文(pmc) · 原文

该文利用蛋白语言模型ESM2和UniRep构建集成模型，从氨基酸序列预测淀粉样蛋白倾向，属于蛋白质序列-结构性质预测的AI方法，但未直接涉及结构预测或构象采样，方法创新性一般。

摘要

MOTIVATION: Amyloids are predominantly beta-sheet-rich, stable protein structures that can maintain their presence in the human body for multiple years. Amyloid protein aggregates contribute to the development of multiple neurodegenerative diseases, such as Alzheimer's, Parkinson's, and Huntington's, and are involved in different vital functions, such as memory formation and immune system function. RESULTS: Here, we used advanced machine learning and deep learning techniques to predict amyloid propensity from the amino acid sequence. First, we aggregated labeled amino acid sequence data from multiple sources, obtaining a roughly balanced dataset of 2365 sequences for binary classification. We leveraged that data to both fine-tune the ESM2 model and to train new models based on protein embeddings from ESM2 and UniRep. The predictions from these models were then unified into a single soft voting ensemble model, yielding highly robust and accurate results. We further made a tool where users can provide the amino acid sequence and get the amyloid formation probabilities of different segments of the input sequence. AVAILABILITY AND IMPLEMENTATION: Users can access the light version of AmyloDeep through the web server at https://amylodeep.com/, and the full model is available as a Python package at https://pypi.org/project/amylodeep/.

摘要翻译

动机：淀粉样蛋白主要是富含β-折叠的稳定蛋白质结构，能在人体内存在多年。淀粉样蛋白聚集体参与多种神经退行性疾病的发展，如阿尔茨海默病、帕金森病和亨廷顿病，并涉及不同重要功能，如记忆形成和免疫系统功能。结果：在此，我们使用先进的机器学习和深度学习技术，从氨基酸序列预测淀粉样蛋白倾向性。首先，我们汇总了来自多个来源的标记氨基酸序列数据，获得了一个大致平衡的数据集，包含2365条序列，用于二分类。我们利用这些数据对ESM2模型进行微调，并基于ESM2和UniRep的蛋白质嵌入训练新模型。这些模型的预测随后被统一到一个软投票集成模型中，产生高度稳健且准确的结果。我们进一步制作了一个工具，用户可提供氨基酸序列，并获得输入序列不同片段的淀粉样蛋白形成概率。可用性与实现：用户可通过网页服务器访问AmyloDeep的轻量版，网址为https://amylodeep.com/，完整模型作为Python包可在https://pypi.org/project/amylodeep/获取。

02 一句话总结

该文构建了一个基于 ESM2（150M/650M）和 UniRep 嵌入、由五个二分类模型（微调 ESM2-150M、FNN、SVM、XGBoost、FNN-ESM2-650M）经软投票集成的模型 AmyloDeep，在 2365 条实验验证序列上训练，用于从氨基酸序列预测淀粉样形成概率，并在 305 条测试集上优于 AMYPred-FRL 和 Cross-Beta 等现有方法。

03 研究问题

  • 具体问题: 如何从氨基酸序列准确预测哪些区域具有淀粉样形成倾向（amyloid propensity）？
  • 为什么重要: 淀粉样蛋白聚集与多种神经退行性疾病（阿尔茨海默病、帕金森病、亨廷顿病）相关，同时功能性淀粉样蛋白参与记忆形成和免疫调节。准确预测淀粉样区域是研究其致病机制和设计干预手段的第一步。
  • 现有方法为何不足: 1. 传统方法（TANGO、ZipperDB、AGGRESCAN）依赖物理模型或经验尺度，主要针对疏水性、β-sheet 倾向的序列，对 prion-like 低复杂度极性结构域等非典型淀粉样区域表现不佳。 2. 多数方法使用小规模数据集训练，泛化能力有限。 3. 未充分利用 pLM 提供的长程序列依赖信息。
  • 精确研究问题: Can a protein language model-based ensemble model, trained on aggregated experimentally validated amyloid/non-amyloid sequences, achieve higher accuracy in predicting amyloid propensity from amino acid sequence than existing physics-based and ML-based tools?

06 核心思想

  1. 表面方法: 使用 ESM2（150M 和 650M）和 UniRep 三种 pLM 生成序列嵌入，分别训练五个二分类模型（微调 ESM2-150M、FNN-ESM2-650M、SVM-ESM2-650M、XGBoost-ESM2-650M、FNN-UniRep），经校准后软投票集成，输出淀粉样形成概率。
  2. 核心洞察: - pLM 嵌入（特别是 ESM2）能捕捉序列中长程依赖和进化信息，这些信息对预测淀粉样倾向性至关重要，而传统氨基酸尺度无法编码。 - 不同 pLM（ESM2 vs UniRep）和不同分类器（神经网络 vs SVM vs 树模型）捕捉序列特征的不同方面，集成可互补。 - 概率校准（Platt/isotonic）使输出概率具有实际决策意义。
  3. 可能的普适教训 [Analysis]: 对于序列-属性预测任务（包括结构相关属性），pLM 嵌入 + 多模型集成 + 概率校准是一个通用且有效的框架。该框架不依赖特定结构假设，可迁移至其他序列-表型任务（如溶解性、稳定性、聚集倾向等）。

07 方法总览

  • 输入: 氨基酸序列（长度可变）
  • 输出: 淀粉样形成概率（0-1），以及基于滑动窗口的淀粉样区域图谱
  • 模块: 1. 数据聚合模块: 整合 CPAD 2.0、Waltz-DB 2.0、Amyloid Atlas、AmyPro、AmyLoad、AmyloBase 六个数据库，去重后得 2365 条序列 2. 嵌入生成模块: ESM2-150M（微调）、ESM2-650M（冻结嵌入）、UniRep（冻结嵌入） 3. 分类器模块: 五个模型——微调 ESM2-150M（分类头）、FNN-ESM2-650M、SVM-ESM2-650M、XGBoost-ESM2-650M、FNN-UniRep 4. 校准模块: 对每个模型应用 Platt 或 isotonic 校准 5. 集成模块: 软投票（算术平均五个校准后概率） 6. 滑动窗口模块: 用户可指定窗口大小（默认 10），生成序列的淀粉样区域图谱
  • 训练: 70% 训练 / 15% 验证 / 15% 测试；MMseqs2 以 40% 序列同一性聚类去冗余；最终模型在 A100 GPU 上训练约 30 小时
  • 假设: 淀粉样倾向性可从序列直接预测，无需结构信息；pLM 嵌入包含足够信息区分淀粉样/非淀粉样区域
  • 流程: 输入序列 → pLM 嵌入 → 五个分类器分别预测 → 概率校准 → 软投票集成 → 输出淀粉样概率 + 区域图谱

09 关键公式符号

本文为纯 ML 方法论文，无显式数学公式。核心操作可形式化如下：

  • 软投票集成: ( P_{\text{ensemble}}(x) = \frac{1}{5} \sum_{i=1}^{5} \hat{p}_i(x) )
  • ( \hat{p}_i(x) )：第 i 个模型对序列 x 的校准后淀粉样概率
  • 用途：综合五个模型预测

  • 直觉：多模型平均，降低单一模型偏差

  • 滑动窗口预测: ( P_{\text{window}}(x_{j:j+w}) = P_{\text{ensemble}}(x_{j:j+w}) )

  • ( w )：窗口大小（默认 10）
  • 用途：生成序列的淀粉样区域图谱
  • 直觉：对每个窗口独立预测，形成沿序列的概率分布

11 结论正确解读

  • 任务范围: 二分类（淀粉样/非淀粉样）和区域级预测（滑动窗口），仅基于序列，不涉及结构预测。
  • oracle/真值输入: 训练标签来自实验验证的淀粉样序列数据库，但具体实验条件（pH、浓度、温度等）未纳入模型。
  • 端到端状态: 是端到端可用的工具（Web 服务器 + Python 包），但推理需 GPU（尤其 ESM2-650M 嵌入）。
  • 算力成本: 训练约 30 小时（A100 GPU）；推理成本主要来自 pLM 嵌入生成，与序列长度线性相关。
  • 历史数据依赖: 训练数据来自 6 个数据库，时间跨度大，实验条件异质。
  • 模型依赖: 依赖 ESM2 和 UniRep 的预训练表示；ESM3 测试失败表明并非所有 pLM 都适用。
  • 最难情形: 短序列（<15 aa）无法用 Cross-Beta 比较；非典型淀粉样区域（如 prion-like 结构域）仍是挑战。
  • 群体/领域边界: 训练数据以已知淀粉样蛋白为主，对全新蛋白家族的泛化能力未验证。
  • 不确定性: 未报告置信区间或不确定性估计；概率校准后可用于阈值决策，但未提供校准曲线细节。
  • 有边界的复述: AmyloDeep 在聚合的实验验证序列数据集上训练，在独立测试集上优于 AMYPred-FRL 和 Cross-Beta，并能准确定位已知淀粉样区域；但其性能受限于训练数据规模和异质性，对短序列和非典型淀粉样区域的泛化能力仍需更多验证。

14 学到什么

Agent 提炼的知识候选:

  1. pLM 嵌入 + 多模型集成框架: 对于序列-属性预测任务，使用多种 pLM（如 ESM2 不同规模、UniProt 等）生成嵌入，配合多种分类器（神经网络、SVM、树模型）集成，可提高鲁棒性和准确性。可迁移至: 蛋白质溶解性、稳定性、聚集倾向等序列-表型预测任务。

  2. 概率校准的重要性: 对每个模型单独进行 Platt/isotonic 校准后再集成，使输出概率具有实际决策意义。可迁移至: 任何输出概率的 ML 预测任务，尤其是需要阈值决策的生物学预测。

  3. 数据聚合策略: 整合多个数据库时，使用 UniProt ID 作为标准键进行跨库匹配，并去除冗余序列。可迁移至: 其他需要整合多源生物数据的任务。

  4. 序列聚类去冗余: 使用 MMseqs2 以 40% 同一性阈值聚类，确保测试集与训练集无序列相似性泄漏。可迁移至: 任何序列-属性预测任务的训练/测试划分。

  5. pLM 选择经验: 并非所有 pLM 都适合特定任务（ESM3 不如 ESM2），需针对任务评估不同 pLM。可迁移至: 其他蛋白质序列预测任务中的 pLM 选型。

  6. 与结构预测工具的整合思路: 作者提出 AmyloDeep 可作为 AlphaFold 等结构预测工具的辅助模块，提供淀粉样概率信息。可迁移至: 将序列-属性预测与结构预测结合，如用淀粉样概率引导构象采样或结构预测。

  7. 滑动窗口区域预测: 通过滑动窗口生成区域级预测图谱，而非仅整序列分类。可迁移至: 蛋白质功能域、结合位点等区域级预测任务。

15 与已有知识连接

  • pLM 基础: ESM2 (Lin et al. 2023) 和 UniRep (Alley et al. 2019) 是蛋白质语言模型的代表，前者基于 Transformer，后者基于 LSTM。该文验证了这两种 pLM 嵌入在淀粉样预测中的有效性。
  • 与 AlphaFold 的关系: 作者明确指出 AlphaFold 2/3 在预测淀粉样结构上表现不佳（Discussion 节），原因包括训练数据中淀粉样结构稀缺、同一序列可形成多种构象等。这提示结构预测与序列-表型预测是互补而非替代关系。
  • 与经典淀粉样预测工具的关系: 该文与 TANGO、ZipperDB、AGGRESCAN、AMYLPRED2 等经典工具对比，后者基于物理模型或经验尺度，前者基于 pLM 嵌入 + ML。该文在 48 条测试集上优于 AMYLPRED2 和 Cross-Beta。
  • 与 MD 模拟的关系 [Analysis]: 该文未涉及 MD 模拟，但其预测的淀粉样区域可作为 MD 模拟的初始种子区域，或用于筛选 MD 模拟的候选序列。淀粉样概率图谱可与 MD 模拟的聚集倾向性分析相互验证。
  • 与构象采样/生成的关系 [Analysis]: 淀粉样蛋白的构象采样是难点，该文提供的序列级淀粉样概率可作为构象采样的先验约束，例如优先采样高概率区域的 β-sheet 构象。
  • 与蛋白质设计的关系 [Analysis]: 该文模型可用于负设计（避免设计出淀粉样倾向的序列），或用于筛选设计序列的淀粉样风险。

16 研究想法

Agent 生成的研究候选:

  1. 候选名称: 淀粉样区域引导的构象采样（Amyloid-Guided Conformational Sampling） - 来源局限/观察: 该文仅预测序列淀粉样倾向，未与构象采样结合；AlphaFold 对淀粉样结构预测不佳。 - 核心假设: 将 AmyloDeep 的淀粉样概率图谱作为先验约束，引导 MD 模拟或构象搜索算法优先采样高概率区域的 β-sheet 富集构象，可提高淀粉样纤维结构预测的准确性。 - 初步方法: 在 MD 模拟中加入偏置势（如 metadynamics 的 collective variable 定义为 AmyloDeep 概率），或在扩散模型（如 AlphaFold 类）的采样过程中加入淀粉样概率作为条件。 - 验证方式: 在已知淀粉样蛋白（如 PrP、Aβ）上比较加入先验前后的构象采样效率与结构准确性。 - 创新状态: unverified

  2. 候选名称: 多 pLM 嵌入融合的淀粉样预测框架扩展（Multi-pLM Fusion for Amyloid Prediction） - 来源局限/观察: 该文仅使用 ESM2 和 UniRep，未测试其他 pLM（如 ESM3、ProtTrans、Ankh）；ESM3 测试失败但仅测试一个变体。 - 核心假设: 融合更多样化的 pLM 嵌入（包括不同架构、不同训练策略）可进一步提高淀粉样预测的泛化能力。 - 初步方法: 系统评估 5-10 种 pLM 嵌入，使用注意力机制或门控网络融合多嵌入，在更大测试集上验证。 - 验证方式: 在独立测试集上比较单 pLM vs 多 pLM 融合的性能；分析不同 pLM 的互补性。 - 创新状态: unverified

  3. 候选名称: 淀粉样倾向性作为蛋白质设计中的负筛选条件（Amyloid Propensity as Negative Design Filter） - 来源局限/观察: 该文模型可预测任意序列的淀粉样概率，但未应用于蛋白质设计。 - 核心假设: 在蛋白质设计流程（如 RFdiffusion、ProteinMPNN）中加入 AmyloDeep 作为负筛选条件，可减少设计序列的淀粉样聚集风险。 - 初步方法: 在设计的候选序列中计算 AmyloDeep 概率，过滤高淀粉样概率序列；或在设计目标函数中加入淀粉样概率作为惩罚项。 - 验证方式: 设计一批蛋白质，比较加入淀粉样过滤前后的实验聚集倾向。 - 创新状态: unverified

  4. 候选名称: 淀粉样概率与 MD 模拟聚集倾向的交叉验证（Cross-Validation of Amyloid Propensity with MD Aggregation Assays） - 来源局限/观察: 该文仅用实验数据库验证，未与 MD 模拟的聚集倾向预测交叉验证。 - 核心假设: AmyloDeep 预测的高概率区域在 MD 模拟中应表现出更高的 β-sheet 形成倾向和聚集倾向。 - 初步方法: 选取若干 AmyloDeep 高/低概率序列，进行粗粒化或全原子 MD 模拟，比较聚集动力学指标（如 β-sheet 含量、聚集数）。 - 验证方式: 统计 AmyloDeep 概率与 MD 模拟聚集指标的相关性。 - 创新状态: unverified

  5. 候选名称: 环境条件感知的淀粉样预测（Environment-Aware Amyloid Prediction） - 来源局限/观察: 该文模型仅输入序列，未考虑 pH、温度、离子强度等环境因素，而作者在 Discussion 中提及 AGGRESCAN4D 已考虑 pH。 - 核心假设: 将环境条件（pH、温度等）作为额外输入特征，可提高淀粉样预测的准确性和适用性。 - 初步方法: 在 AmyloDeep 框架中加入环境条件编码器，或在训练数据中标注环境条件。 - 验证方式: 在 pH 依赖的淀粉样数据集上比较有无环境输入的模型性能。 - 创新状态: unverified

Review setup

  • Input scope Full manuscript text (abstract, introduction, methods, results, discussion, data availability)
  • Assessment boundary Scientific and technical evaluation of the presented method, its validation, and claims; no editorial or formatting considerations
  • Shared manuscript claim summary The authors present AmyloDeep, an ensemble model combining five machine learning predictors built on protein language model embeddings (ESM2, UniRep) to predict amyloid propensity from amino acid sequences. They report superior performance compared to existing tools and provide a web server and Python package.
  • Visible evidence base Main text with 4 figures and 1 table referenced; supplementary material mentioned but not provided; no quantitative performance metrics (e.g., AUC, accuracy values) are reported in the main text

Reviewer

  • Overall assessment The manuscript addresses a relevant problem in protein science, namely the prediction of amyloidogenic regions from sequence. The use of protein language model embeddings is timely and the ensemble approach is reasonable. However, the main text lacks quantitative results, which severely limits the ability to evaluate the claimed performance. The comparison with existing tools is based on a very small test set (48 sequences), and the methodology for this comparison is not fully described. Several claims, including "state-of-the-art performance," are not supported by the evidence presented in the main text. The manuscript would benefit from a more rigorous and transparent presentation of results, including all performance metrics, statistical significance testing, and a more robust comparison strategy.
  • Who would be interested in the results, and why Researchers working on protein aggregation, amyloid biology, and neurodegenerative disease would find this tool potentially useful for identifying amyloidogenic regions in proteins of interest. Computational biologists developing prediction tools for protein properties would also be interested in the methodological approach of combining pLM embeddings with ensemble learning. The web server and Python package make the tool accessible to experimental biologists without computational expertise.
  • Major strengths The problem is relevant and timely. The use of multiple pLM embeddings (ESM2 variants, UniRep) and diverse model architectures (FNN, SVM, XGBoost) is a sound methodological choice. The ensemble approach with calibration is appropriate. The authors provide both a web server and a Python package, which enhances usability. The discussion of limitations, including data scarcity and computational cost, is honest and useful.
