Domain-Aware Enzyme Classification via Multiple Instance Learning.

Xiao, Qingyang; Ye, Yuzhen; Tang, Haixu
Bioinformatics (Oxford, England) · 2026-11-02 · 仅摘要 · 原文

该文提出基于多实例学习的酶功能（EC号）预测方法，以蛋白质结构域为实例建模，虽涉及蛋白质结构相关计算，但核心是功能注释而非结构预测/采样/生成等本课题核心问题，方法可借鉴但关联度中等。

摘要

MOTIVATION: Accurate Enzyme Commission (EC) number prediction is fundamental to protein function annotation and metabolic pathway reconstruction. Recent methods based on protein language model embeddings or 3D structure have improved EC prediction, but important limitations remain. Whole-sequence embeddings can dilute local functional signals, such as catalytic residues and functional domains, whereas structure-based methods depend on accurate protein structures and are therefore difficult to apply broadly. RESULTS: We present MIL-BC, a multiple instance learning framework for EC prediction that models each protein as a bag of domains rather than a single sequence-level object. This design is motivated by the observation that enzymatic function is often determined by constituent functional domains instead of the full-length sequence alone. Domain instances are generated automatically using our DCTdomain algorithm, avoiding dependence on curated domain annotations. MIL-BC aggregates domain-level evidence into protein-level EC predictions and assigns interpretable weights to domains that contribute most strongly to each prediction. We further combine the domain embedding with global embedding in MIL-BC+. MIL-BC+ achieved F1 improvements of 0.03 - 0.17 over the sequence-based baseline on all four test sets. The largest gains were observed for proteins with multiple enzymatic functions, where domain-level modeling better separates mixed functional signals. These results show that domain-centric multiple instance learning is an accurate and interpretable strategy for enzyme classification. By improving EC prediction without requiring structural data or curated domain labels, MIL-BC provides a scalable framework for large-scale protein function annotation. AVAILABILITY: Code is available as a GitHub repository at https://github.com/omics-ai/enzyme-mil.git.

摘要翻译

动机：准确的酶学委员会（EC）编号预测是蛋白质功能注释和代谢通路重建的基础。基于蛋白质语言模型嵌入或三维结构的近期方法已改进EC预测，但仍存在重要局限性。全序列嵌入可能稀释局部功能信号，如催化残基和功能域，而基于结构的方法依赖准确的蛋白质结构，因此难以广泛应用。结果：我们提出MIL-BC，一种用于EC预测的多实例学习框架，将每个蛋白质建模为域包，而非单一序列级对象。这一设计源于酶功能通常由组成性功能域而非全长序列单独决定的观察。域实例通过我们的DCTdomain算法自动生成，避免依赖人工注释的域标注。MIL-BC将域级证据聚合为蛋白质级EC预测，并为对每个预测贡献最强的域分配可解释权重。我们进一步在MIL-BC+中将域嵌入与全局嵌入结合。MIL-BC+在所有四个测试集上相对于基于序列的基线实现了0.03至0.17的F1改进。最大增益出现在具有多种酶功能的蛋白质上，其中域级建模能更好地区分混合功能信号。这些结果表明，以域为中心的多实例学习是酶分类的一种准确且可解释的策略。通过在不需结构数据或人工域标签的情况下改进EC预测，MIL-BC为大规模蛋白质功能注释提供了可扩展框架。可用性：代码以GitHub仓库形式提供，网址为https://github.com/omics-ai/enzyme-mil.git。

03 研究问题

  • 具体问题：如何在不依赖 3D 结构或 curated domain 注释的前提下，准确预测蛋白质的 EC number，并保留局部功能信号（如催化残基、功能 domain）？
  • 为什么重要：EC number 预测是蛋白质功能注释和代谢通路重建的基础；现有方法在局部信号稀释和结构依赖方面存在瓶颈，影响大规模注释的准确性和可扩展性。
  • 现有方法不足：
  • 全序列 embedding 会稀释局部功能信号（如催化残基、domain 级功能位点）。
  • 基于 3D 结构的方法依赖准确结构预测，难以广泛适用于无结构或低质量结构的蛋白质。
  • 依赖 curated domain 注释的方法受限于注释覆盖度和更新滞后。
  • 精确研究问题：Can a multiple instance learning framework that treats proteins as bags of automatically generated domains improve EC prediction accuracy and interpretability over sequence-level baselines, without requiring structural data or curated domain labels?

04 背景与发展脉络

  • 阶段一：序列比对方法（如 BLAST、HMMER）——基于同源转移，优点是可解释、无需训练，但覆盖度低、对远源同源不敏感。
  • 阶段二：序列 embedding 方法（如 ProtBERT、ESM 系列）——利用蛋白质语言模型提取全序列表示，优点是通用性强，但局部功能信号被稀释。
  • 阶段三：结构感知方法（如 DeepFRI、ECPred 结合 AlphaFold）——利用 3D 结构或结构预测，优点是捕捉空间功能位点，但依赖结构质量，计算成本高。
  • 阶段四（本文位置）：domain-centric 多示例学习——将蛋白质分解为自动生成的 domain 实例，聚合局部证据，兼顾准确性和可扩展性，避免结构依赖和 curated 注释瓶颈。
  • 脉络标注：此脉络为「经外部核验」——基于文中引言所述方法分类及领域常识，但具体阶段划分和代表性方法选择为本文框架。

06 核心思想

  1. 表面方法：将每个蛋白质视为一个 bag，其中每个 instance 是一个自动生成的 domain 片段（由 DCTdomain 算法产生）；通过多示例学习（MIL）聚合 domain 级 embedding 进行 EC 预测；MIL-BC+ 进一步将 domain embedding 与全局序列 embedding 结合。
  2. 核心洞察：酶功能主要由功能 domain 决定，而非全序列；将蛋白质分解为 domain 实例可以分离混合功能信号，并通过 MIL 的注意力机制自动识别贡献最大的 domain，提升可解释性。
  3. 可能的普适教训 [Analysis]：在序列级表示中，局部功能信号常被稀释；将对象分解为语义子单元（如 domain、motif）并采用 MIL 聚合，是提升预测精度和可解释性的通用策略，尤其适用于多标签或多功能场景。

07 方法总览

  • 输入：蛋白质氨基酸序列（无需结构或 curated domain 注释）。
  • 输出：EC number 预测（多标签分类，每个 EC 类别一个概率）。
  • 模块： 1. DCTdomain：自动 domain 分割算法，将序列切分为 domain 实例。 2. Domain embedding：每个 domain 通过蛋白质语言模型（如 ESM）生成 embedding。 3. MIL 聚合：多示例学习层，学习 domain 权重并聚合为蛋白级表示。 4. 分类头：全连接层输出 EC 类别概率。 5. MIL-BC+：将 domain embedding 与全局序列 embedding 拼接，增强全局上下文。
  • 训练：监督学习，使用 EC 标签作为 ground truth；损失函数为多标签分类损失（如 binary cross-entropy）。
  • 工具：蛋白质语言模型（具体型号未提供）、PyTorch 等深度学习框架（推测，未明确）。
  • 假设：domain 是酶功能的基本决定单元；自动生成的 domain 能有效捕捉功能信号。
  • 流程：输入序列 → DCTdomain 分割为 domain 实例 → 每个 domain 生成 embedding → MIL 聚合（学习权重）→ 与全局 embedding 结合（MIL-BC+）→ 分类头输出 EC 预测。

Reviewer

  • Overall assessment The abstract presents a conceptually interesting application of multiple instance learning to enzyme classification, with a plausible biological rationale linking functional domains to enzymatic activity. However, the evidence provided is insufficient to evaluate the validity of the core claims. Key methodological details, baseline fairness, statistical rigor, and the actual performance of the proposed DCTdomain algorithm are not described. The reported F1 improvements are presented without confidence intervals or significance testing, and the interpretability claim is not substantiated with examples or quantitative evaluation. The work may be of interest to the computational biology community, but the case is not established from the supplied material.
  • Who would be interested in the results, and why Researchers in protein function annotation, enzyme engineering, and computational enzymology would be interested because improved EC prediction has direct applications in metabolic pathway reconstruction and genome annotation. The domain-centric interpretability angle may also appeal to those studying protein domain-function relationships. The method's claimed independence from structural data and curated annotations could attract users seeking scalable annotation tools for large sequence databases.
  • Major strengths The biological motivation is sound and clearly articulated, linking enzymatic function to constituent domains rather than full-length sequence. The proposed framework addresses a recognized limitation of whole-sequence embedding approaches. The combination of domain-level and global embeddings in MIL-BC+ is a reasonable design choice. The claim of interpretability through domain weights is potentially valuable for biological discovery.

  • Concern ID R1-M1
  • Severity Major
  • Blocking Yes
  • Axis Technical soundness
  • Claim pointer "MIL-BC+ achieved F1 improvements of 0.03 - 0.17 over the sequence-based baseline on all four test sets"
  • Evidence pointer Abstract, Results section; location not provided
  • Concern The performance claim is presented without any statistical context. No confidence intervals, standard deviations, or significance tests are reported. The range of 0.03 to 0.17 is wide, and it is unclear whether the lower bound represents a meaningful improvement. The baseline is described only as "sequence-based" without specifying which model or embedding was used, making it impossible to assess whether the comparison is fair or whether the gains are specific to the proposed method or simply reflect a stronger baseline choice.
  • Why it matters Without statistical rigor, the reported improvements could be within noise or dependent on favorable baseline selection. The central claim of the paper rests on this comparison, and the current evidence does not support a robust conclusion.
  • Resolution test Provide per-test-set F1 scores with confidence intervals or standard deviations across multiple runs, report p-values or effect sizes for the improvements, and specify the exact baseline model and embedding used. Show that the improvements are consistent and statistically significant.
  • Concern ID R1-M2
  • Severity Major
  • Blocking Yes
  • Axis Technical soundness
  • Claim pointer "Domain instances are generated automatically using our DCTdomain algorithm, avoiding dependence on curated domain annotations"
  • Evidence pointer Abstract, Methods section; location not provided
  • Concern The DCTdomain algorithm is mentioned but not described. No information is given about how domains are defined, segmented, or validated. The quality of domain generation directly affects the multiple instance learning framework, and errors in domain boundaries could propagate to prediction errors. Without any evaluation of DCTdomain's accuracy or comparison to existing domain annotation tools, the reliability of the input instances is unknown.
