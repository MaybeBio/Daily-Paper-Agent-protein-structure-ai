Reliable and Efficient Agentic Protein Design with Toolset Harnessing.

该文提出Chaperone框架，通过标准化工具接口和并行化执行，高效整合RFdiffusion3、ProteinMPNN、AlphaFold3等蛋白设计工具，显著提升智能体驱动的蛋白质结构设计工作流效率与成功率，属于蛋白质结构计算设计领域的方法创新。

摘要

Computational protein design workflows require the orchestration of multiple tools, data formats, and analysis steps that are often fragmented. Here, we introduce Chaperone, a lightweight and customizable framework that enables seamless integration of RFdiffusion3 (RFD3) [1] with downstream sequence design, structure prediction, and evaluation tools, including ProteinMPNN [2], AlphaFold3 (AF3) [3], and more than 50 other protein design tools. By combining a programmable agent-friendly interface with parallelized execution on high-performance computing systems, Chaperone as a harness enables rapid iteration and scalable exploration of complex protein design workflows. Across an evaluation of nine biomolecular design tasks, we find using Chaperone reduces total token usage relative to baseline agents by 86% and GPU costs by 64%, while increasing the overall computational design pass rate. We demonstrate Chaperone's utility for large-scale design-space exploration through a two-week end-to-end small-molecule binder design campaign, yielding low nanomolar binders to cortisol zero shot. We further demonstrate its versatility across distinct design challenges, including the design of a symmetric 12-subunit self-assembly nanoparticle and a linker that mediates interactions between C2- and D3-symmetric protein complexes to form crystalline assemblies. Together, these results demonstrate how agent harnesses built around standardized tool interfaces can substantially improve the efficiency and success of complex, long-horizon agentic design workflows in biology. We make Chaperone freely available to the community on GitHub: https://github.com/RosettaCommons/chaperone .

摘要翻译

计算蛋白质设计工作流程需要协调多种工具、数据格式和分析步骤，这些往往分散且不连贯。在此，我们介绍Chaperone，一个轻量级且可定制的框架，能够无缝集成RFdiffusion3 (RFD3) [1]与下游序列设计、结构预测和评估工具，包括ProteinMPNN [2]、AlphaFold3 (AF3) [3]以及超过50种其他蛋白质设计工具。通过将可编程的智能体友好接口与高性能计算系统上的并行执行相结合，Chaperone作为一套控制框架，能够实现复杂蛋白质设计工作流程的快速迭代和可扩展探索。在对九项生物分子设计任务的评估中，我们发现使用Chaperone相比基线智能体将总令牌使用量减少了86%，GPU成本降低了64%，同时提高了整体计算设计通过率。我们通过一个为期两周的端到端小分子结合剂设计活动，展示了Chaperone在大规模设计空间探索中的实用性，成功生成了针对皮质醇的零次射击低纳摩尔结合剂。我们进一步展示了其在多种不同设计挑战中的多功能性，包括设计一个对称的12亚基自组装纳米颗粒，以及一个介导C2-和D3-对称蛋白质复合物之间相互作用以形成晶体组装的连接子。综合这些结果，证明了围绕标准化工具接口构建的智能体控制框架能够显著提高生物学中复杂、长周期智能体设计工作流程的效率和成功率。我们将Chaperone免费提供给社区，可在GitHub上获取：https://github.com/RosettaCommons/chaperone。

03 研究问题

  • 具体问题：计算蛋白设计工作流涉及多个工具、数据格式和分析步骤，这些工具之间缺乏统一接口，导致智能体（agent）在长时程、多步骤设计任务中效率低下、token 消耗高、失败率高。
  • 为什么重要：随着 RFdiffusion3、AlphaFold3 等生成模型的出现，蛋白设计正从单步预测转向多步、迭代、探索式的 agentic 工作流。若工具间集成不畅，即使单个模型再强，端到端设计成功率仍受限于编排层的瓶颈。
  • 现有方法为何不足：现有 agent 框架（如通用 LLM agent）缺乏对蛋白设计工具语义的理解，需要大量 token 来「教」模型如何调用工具、解析输出；且多数工具为单机串行设计，无法利用 HPC 并行能力，导致长时程任务（如大规模设计空间探索）成本过高。
  • 精确研究问题：Can a standardized toolset harness with agent-friendly interfaces and parallelized HPC execution reduce token usage and GPU cost while improving the pass rate of long-horizon agentic protein design workflows?

06 核心思想

  1. 表面方法：构建 Chaperone——一个轻量级框架，为每个蛋白设计工具（RFD3、ProteinMPNN、AF3 等 50+）提供标准化的 agent-friendly 接口（统一输入/输出 schema），并集成 HPC 并行调度，使 LLM agent 能以统一方式调用任意工具，且多个独立任务可并行执行。
  2. 核心洞察：蛋白设计工作流的瓶颈不在单个模型的精度，而在工具间的「编排层」——通过将工具语义（输入/输出格式、参数含义、常见失败模式）内建到接口中，而非依赖 LLM 通过 prompt 逐步学习，可大幅减少 token 消耗并提升可靠性。同时，设计任务天然具有「探索-评估-筛选」的并行结构，HPC 并行化可显著加速。
  3. 可能的普适教训 [Analysis]：在 AI for Science 的 agentic 工作流中，「工具层标准化」与「模型层精度」同等重要——与其让 LLM 学习工具语法，不如让工具适配 LLM 的调用习惯。这一思路可迁移到 MD 模拟、分子对接等其他计算生物学工具链的 agent 化集成。

07 方法总览

  • 输入：用户以自然语言或结构化指令描述设计任务（如「设计一个结合皮质醇的蛋白」）
  • 输出：设计完成的蛋白序列/结构，以及评估报告（结合亲和力预测、结构置信度等）
  • 模块： 1. 工具注册层：将 50+ 工具（RFD3、ProteinMPNN、AF3 等）封装为统一接口，定义输入/输出 schema 2. Agent 调度层：LLM agent 通过标准化接口调用工具，规划多步设计流程 3. HPC 并行层：将可并行的独立任务（如多个候选设计的评估）分发到多节点并行执行 4. 反馈回路：工具输出自动解析并回传给 agent，支持迭代设计
  • 训练：不涉及模型训练；Chaperone 为纯框架层，工具本身（RFD3 等）为预训练模型
  • 假设：设计任务可分解为「生成-评估-筛选」的迭代循环；工具间数据格式可通过统一 schema 转换
  • 流程：用户指令 → agent 规划 → 调用工具（并行/串行）→ 解析输出 → 反馈给 agent → 迭代直至满足终止条件

11 结论正确解读

  • 任务范围：本文结论仅适用于「agentic 蛋白设计工作流」——即由 LLM agent 自主规划多步设计任务的场景，不适用于单步、非 agentic 的设计流程。
  • Oracle/真值输入：设计任务的「成功」定义未在摘要中明确——是计算预测（如 AF3 置信度）还是实验验证（如结合实验）？皮质醇结合物「低纳摩尔」是否经实验测定未说明。
  • 端到端状态：皮质醇 campaign 为「零样本」设计，但未说明是否经过湿实验验证；12 亚基纳米颗粒和晶体 linker 的「成功」同样未说明验证方式。
  • 算力成本：GPU 成本节省 64% 是相对 baseline agents 的比值，绝对值未提供；HPC 基础设施要求可能限制可复现性。
  • 历史数据依赖：Chaperone 本身不依赖训练数据，但其集成的工具（RFD3、AF3 等）依赖各自训练数据。
  • 模型依赖：Chaperone 的 agent 调度层依赖 LLM 的规划能力，LLM 的选择（如 GPT-4、Claude 等）可能影响结果。
  • 最难情形：长时程、多步骤、需多次迭代的设计任务（如皮质醇结合物设计）是 Chaperone 的目标场景；简单单步任务可能无法体现其优势。
  • 不确定性：九项任务的通过率提升幅度未量化；token 和 GPU 节省的置信区间未提供。
  • 边界化复述：Chaperone 在九项计算设计任务中，相比未使用该 harness 的 baseline agents，token 消耗降低 86%、GPU 成本降低 64%、通过率提升；并在两周内零样本设计出皮质醇低纳摩尔结合物（计算预测，实验验证状态未说明）。这些结论仅适用于 agentic 设计工作流，且依赖 HPC 基础设施。

14 学到什么

Agent 提炼的知识候选：

  1. 工具层标准化优先于模型层优化：在 agentic 蛋白设计工作流中，将工具（RFD3、ProteinMPNN、AF3）封装为统一接口、内建领域语义，比试图让 LLM 通过 prompt 学习工具语法更高效。可迁移：对 MD 模拟（如 OpenMM、GROMACS）、分子对接（如 AutoDock Vina）等工具链，可构建类似的标准化 harness，使 agent 能以统一方式调用。

  2. 并行化是长时程设计任务的关键加速器：蛋白设计天然具有「生成多个候选 → 并行评估 → 筛选」的并行结构。可迁移：在构象采样任务中，可将多个独立 MD 轨迹并行分发，由 agent 汇总分析。

  3. 反馈回路设计决定 agent 的迭代效率：Chaperone 将工具输出自动解析为结构化反馈，使 agent 无需「阅读」原始输出文件。可迁移：在结构预测工作流中，可将 AF3 的 PAE/pLDDT 输出自动解析为 agent 可理解的「设计质量摘要」，加速迭代决策。

  4. 零样本设计能力依赖工具链的完整性：皮质醇结合物零样本设计成功，说明当生成（RFD3）、序列设计（ProteinMPNN）、验证（AF3）工具链完整且接口顺畅时，agent 可自主完成长时程任务。可迁移：在构象生成任务中，确保「采样 → 打分 → 聚类 → 分析」工具链的接口标准化，可提升 agent 的端到端能力。

  5. 评估指标需区分计算预测与实验验证：本文「低纳摩尔」的验证状态不明确，提示在设计 agent 工作流时，应明确区分「计算通过」与「实验验证通过」的边界。可迁移：在设计评估协议时，明确每个环节的验证层级。

15 与已有知识连接

  • 相似工作：与 LangChain、AutoGPT 等通用 agent 框架相比，Chaperone 聚焦于蛋白设计领域，内建工具语义而非通用工具调用。与 Microsoft 的 BioChat、DeepMind 的 AlphaFold 生态相比，Chaperone 不提供新模型，而是编排现有模型。
  • 组合方向：Chaperone 的 harness 思路可与「主动学习」结合——agent 基于 AF3 评估结果自动选择下一轮 RFD3 采样参数，实现闭环优化。
  • 冲突/差异：与「端到端单模型」思路（如直接训练一个可完成全流程的模型）相比，Chaperone 主张「组合现有工具 + 编排层优化」，两者在哲学上互补而非冲突。
  • 可迁移领域：Chaperone 的「工具注册 + 并行调度 + 反馈回路」架构可迁移至 MD 模拟工作流（如将 OpenMM 的多个轨迹并行运行，由 agent 汇总 RMSD/结合自由能分析）、分子对接虚拟筛选（并行对接多个候选分子）。
  • 候选方向 [Analysis]：Chaperone 的接口标准化思路可推广至「结构预测 → MD 精修 → 结合自由能计算」的完整 pipeline，构建一个统一的「蛋白计算工作流 OS」。

16 研究想法

Agent 生成的研究候选：

  1. 名称：MD-Harness——面向 MD 模拟的 agentic 工具集成框架 - 来源局限/观察：Chaperone 聚焦于 RFD3/AF3 等结构设计工具，未覆盖 MD 模拟（如 OpenMM、GROMACS）的集成；MD 模拟同样面临工具碎片化、参数设置复杂、轨迹分析繁琐等问题。 - 核心假设：将 MD 模拟工具封装为标准化接口，使 agent 能自主完成「体系构建 → 平衡 → 生产 → 轨迹分析 → 结合自由能计算」全流程，可提升 MD 模拟的自动化程度与可复现性。 - 初步方法：借鉴 Chaperone 的架构，为 OpenMM/GROMACS 定义统一输入/输出 schema，集成并行轨迹采样，并构建自动化的轨迹分析反馈回路（RMSD、Rg、氢键、MM-PBSA 等）。 - 验证方式：在 3-5 个标准体系（如蛋白-配体结合、蛋白-蛋白互作）上对比 agent 自主 MD 与人工 MD 的效率和结果一致性。 - 创新状态：unverified（未见类似工作）

  2. 名称：Chaperone-Enhanced 构象采样主动学习 - 来源局限/观察：Chaperone 的反馈回路支持「生成-评估-迭代」，但未明确利用评估结果主动调整采样参数；构象采样任务中，agent 可基于中间结果动态调整采样策略。 - 核心假设：将 Chaperone 与主动学习结合，使 agent 基于 AF3/实验数据自动调整 RFD3 采样参数（如去噪步数、对称约束），可提升构象采样的效率与多样性。 - 初步方法：在 Chaperone 的反馈回路中增加「参数建议模块」，agent 根据上一轮评估结果（如 AF3 置信度、能量打分）自动调整下一轮采样参数。 - 验证方式：在构象生成任务中对比固定参数采样与主动调整采样的构象多样性、能量分布、计算成本。 - 创新状态：unverified

  3. 名称：Chaperone 的跨工具错误传播审计 - 来源局限/观察：Chaperone 集成 50+ 工具，但工具间的错误传播（如 RFD3 输出异常结构导致 ProteinMPNN 失败）未在摘要中讨论。 - 核心假设：在 Chaperone 中引入工具间输出质量检查（如结构合法性、能量异常值检测），可减少级联失败，提升长时程任务成功率。 - 初步方法：在工具注册层增加输出验证模块，对每个工具的输出进行自动质量检查，异常时触发重试或替代工具。 - 验证方式：在九项设计任务中对比有无质量检查的成功率与 token 消耗。 - 创新状态：unverified

  4. 名称：Chaperone 的「零样本」能力边界刻画 - 来源局限/观察：皮质醇结合物零样本设计成功，但未说明失败案例或任务难度边界。 - 核心假设：Chaperone 的零样本能力存在任务类型、复杂度、工具覆盖度的边界，刻画这些边界可指导框架改进。 - 初步方法：系统性地在 20+ 不同难度任务（简单结合、多表位、对称组装、酶设计）上测试 Chaperone，记录成功/失败模式。 - 验证方式：产出任务难度-成功率矩阵，识别 Chaperone 的强项与短板。 - 创新状态：unverified
