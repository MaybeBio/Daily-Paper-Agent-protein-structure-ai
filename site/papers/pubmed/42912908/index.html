Pose Reproduction, Cross Docking, Database Enrichment, and Reverse Docking Benchmarks for DOCK6, Vina, and AutoDock 4 with Emphasis on Approved Drugs.

Corbo, Carissa P; Laverty, Scott R; Rizzo, Robert C
Journal of chemical information and modeling · 2026-10-23 · 全文(pmc) · 原文

该文构建了大规模蛋白-配体复合物基准集SB2025/FARMA2025，并系统评估DOCK6、Vina和AutoDock 4在对接、交叉对接、富集和反向对接中的表现，虽以分子对接为核心且方法为物理模拟，但对象为蛋白-配体复合物而非纯蛋白质结构，且侧重基准测试而非方法创新。

摘要

High-quality test sets to evaluate docking software help the community understand strengths and weaknesses of different methods and programs. In this work, we introduce SB2025, a calculation-ready set of 1,244 protein-ligand complexes derived from the PDB, curated using literature-based ligand protonation states, and freely available in DOCK6, AutoDock Vina, and AutoDock 4 (AD4) formats. SB2025 includes 322 unique proteins, 17 major protein classes, and ligands with a wide range of properties and flexibilities, making it a broad and challenging test set. FARMA2025, a specific subset of SB2025, contains 165 approved drugs bound to their pharmacological targets and closely mirrors the distribution of FDA drug target classes for small molecules through 2023 (r2 = 0.72). Comprehensive benchmarking was subsequently performed to evaluate pose reproduction (PR), cross-docking (CD), database enrichment (DE), and reverse docking (RD) under standardized conditions. Averaged PR success rate across triplicate runs for DOCK6 was slightly improved compared to Vina (followed by AD4) using both the large SB2025 test set and the more drug-focused FARMA2025 test set. Conversely, CD matrix success rates for AD4 were more favorable than DOCK6 or Vina across 11 protein families. The programs all yielded substantial early DE; however, the number of active ligands in common between the programs within the top 1% of the database, with one exception, was surprisingly low. Challenging RD tests using FARMA2025, which gauge the ability to correctly rank the cognate structure best, indicate that generating the correct ligand pose is necessary but not sufficient. SB2025, FARMA2025, and example scripts and protocols for benchmarking are available at ringo.ams.stonybrook.edu (downloads) and github.com/rizzolab.

摘要翻译

用于评估对接软件的高质量测试集有助于社区理解不同方法和程序的优缺点。在本工作中，我们介绍了SB2025，一个计算就绪的1,244个蛋白质-配体复合物集合，源自PDB，基于文献中的配体质子化状态进行筛选，并以DOCK6、AutoDock Vina和AutoDock 4 (AD4)格式免费提供。SB2025包含322个独特蛋白质、17个主要蛋白质类别，以及具有广泛性质和灵活性的配体，使其成为一个广泛且具有挑战性的测试集。FARMA2025是SB2025的一个特定子集，包含165个与其药理学靶标结合的已批准药物，并紧密反映了截至2023年FDA小分子药物靶标类别的分布（r2 = 0.72）。随后进行了全面基准测试，以在标准化条件下评估姿态重现（pose reproduction, PR）、交叉对接（cross-docking, CD）、数据库富集（database enrichment, DE）和反向对接（reverse docking, RD）。在三次重复运行中，DOCK6的平均PR成功率略优于Vina（其次是AD4），使用大型SB2025测试集和更侧重药物的FARMA2025测试集时均如此。相反，在11个蛋白质家族中，AD4的CD矩阵成功率优于DOCK6或Vina。所有程序在早期DE方面均表现出显著效果；然而，在数据库前1%中，各程序之间共有的活性配体数量，除一个例外，出人意料地低。使用FARMA2025进行的具有挑战性的RD测试，旨在评估正确排名同源结构的能力，表明生成正确的配体姿态是必要的但不足够。SB2025、FARMA2025以及用于基准测试的示例脚本和协议可在ringo.ams.stonybrook.edu（下载）和github.com/rizzolab获取。

03 研究问题

  • 具体问题: 在统一、标准化、大规模且包含已批准药物的基准测试条件下，DOCK6、AutoDock Vina 和 AutoDock 4 三种主流开源对接程序在构象重现（PR）、交叉对接（CD）、数据库富集（DE）和反向对接（RD）四种任务中的表现如何？
  • 为什么重要: 分子对接是早期药物发现中最常用的计算方法之一，但不同程序使用不同的采样算法和打分函数，其性能高度依赖于测试集的选择。缺乏大规模、多样化、计算就绪且包含临床相关药物-靶标复合物的基准测试集，导致：(1) 开发者难以公平比较不同方法；(2) 用户难以根据实际需求选择最合适的工具和参数；(3) 已有基准测试结果差异大（如 PR 成功率从 23% 到 78%），部分原因是测试集偏差和协议不一致。
  • 现有方法为何不足: 已有基准测试存在以下问题：(1) 测试集规模有限（多数为 100-700 个复合物）；(2) 蛋白类别覆盖不全，特别是缺乏膜蛋白（GPCR、离子通道等）和转运体；(3) 多数测试集未包含已批准药物与其治疗靶标的复合物，无法反映真实药物发现场景；(4) 不同研究使用不同的准备协议、打分函数版本和评估标准，结果难以直接比较。
  • 精确的 "Can ... ?" 研究问题: 在标准化条件下，DOCK6、Vina 和 AD4 能否在不同蛋白类别和任务类型中保持一致的性能排名？已批准药物子集（FARMA2025）是否比通用测试集更能反映程序在真实药物发现场景中的表现差异？

06 核心思想

1) 表面方法

构建大规模、计算就绪、多任务对接基准测试集（SB2025 和 FARMA2025），在标准化条件下系统比较三种对接程序（DOCK6、Vina、AD4）在四种任务（PR、CD、DE、RD）上的表现，并分析蛋白类别、配体性质、参数设置等因素对结果的影响。

2) 核心洞察

  • 测试集构成决定评估结论：不同测试集（SB2025 vs FARMA2025 vs Astex2007）得出的程序性能排名不同，说明基准测试结果高度依赖测试集选择。FARMA2025 因更贴近真实药物发现场景，其评估结果对实际应用更具参考价值。
  • 程序性能具有任务和类别依赖性：没有单一程序在所有任务和所有蛋白类别上表现最佳。DOCK6 在 PR 上略优，AD4 在 CD 矩阵成功率上最高，Vina 在 DE 上表现突出。这种差异源于各程序采样算法和打分函数的设计哲学不同。
  • 参数设置比程序选择更重要：对于同一程序，box size 和 exhaustiveness 等参数对结果的影响可能大于程序间的差异。DOCK6 使用大 box 效果更好，而 Vina 和 AD4 使用小 box 效果更好，这与各程序的采样机制有关。
  • 结构水对 CD 至关重要：HSP90 案例表明，包含结构水可显著提高 Vina 的 CD 成功率（从 19.7% 到 90.3%），说明在真实应用中考虑结构水的重要性。

3) 可能的普适教训 [Analysis]

  • 基准测试设计应反映目标应用场景：如果目标是药物发现，测试集应包含已批准药物-靶标复合物，而非仅使用工具化合物。这一原则可迁移到其他计算方法的评估中（如 MD 模拟、AlphaFold 结构预测的评估）。
  • 多维度评估优于单一指标：PR 精度高不代表 DE 或 RD 表现好，反之亦然。评估计算方法时应同时考察多个维度的性能指标。
  • 「计算就绪」是基准测试可用的关键：提供标准化输入文件（mol2、pdbqt、grid 等）和脚本，降低用户使用门槛，是基准测试集被广泛采用的重要因素。

07 方法总览

输入： - 从 PDB 获取的蛋白质-配体复合物结构（1,244 个，分辨率 < 3.5 Å，平均 2.1 Å） - 配体三维结构及文献报道的质子化状态 - 蛋白质序列信息（UniProt 登录号）用于分类

输出： - SB2025 和 FARMA2025 测试集（含 DOCK6、Vina、AD4 三种格式的输入文件） - 四种任务（PR、CD、DE、RD）的定量评估结果 - 不同蛋白类别、配体性质、参数条件下的性能对比

模块： 1. 测试集构建模块：PDB 筛选 → 结构质量评估 → 配体质子化状态确定 → 蛋白质分类 → 文件格式转换 2. PR 评估模块：将配体从共晶结构中提取后重新对接，计算 RMSD 3. CD 评估模块：将同一蛋白家族的配体交叉对接至不同蛋白结构 4. DE 评估模块：将活性分子与诱饵分子混合对接，评估富集能力 5. RD 评估模块：将药物对接至 FARMA2025 中所有蛋白，评估靶标识别能力

工具： - DOCK6.12（含新加入的 simplex ramping 特征） - AutoDock Vina 1.1.2 - AutoDock 4.2.6（LGA 算法） - OpenBabel 2.4.1（格式转换） - AMBER（能量最小化） - AM1-BCC / Gasteiger 电荷模型

流程（文字描述）： 1. 从 PDB 收集复合物结构，按标准筛选（分辨率、配体性质、非共价结合等） 2. 对每个复合物进行结构准备：加氢、分配质子化状态、能量最小化 3. 为三种程序分别准备输入文件（DOCK6: mol2 + grid；Vina: pdbqt；AD4: pdbqt + gpf） 4. 运行 PR 实验：每种程序使用其推荐参数进行对接，计算 RMSD 5. 运行 CD 实验：对 11 个蛋白家族进行交叉对接 6. 运行 DE 实验：使用 DUD-E 的 active/decoy 集合 7. 运行 RD 实验：将 FARMA2025 中 165 个药物对接至所有蛋白 8. 统计分析：按蛋白类别、配体性质、参数设置等维度比较三种程序

假设： - 共晶配体的结合模式代表真实结合模式（PR 评估的前提） - DUD-E 的 decoy 分子与 active 分子性质匹配但无活性（DE 评估的前提） - 药物与其共晶蛋白的结合亲和力高于与其他蛋白的结合（RD 评估的前提）

09 关键公式符号

1. RMSD 计算（三种变体）： - RMSDs（标准重原子 RMSD，基于原子顺序匹配）： [ RMSD_s = \sqrt{\frac{1}{N}\sum_{i=1}^{N} | \mathbf{p}_i - \mathbf{q}_i |^2} ] 其中 ( \mathbf{p}_i ) 和 ( \mathbf{q}_i ) 分别为预测位姿和实验位姿中第 ( i ) 个重原子的坐标，( N ) 为重原子数。

  • RMSDh（对称性校正 RMSD，使用匈牙利算法进行原子匹配）： [ RMSD_h = \min_{\sigma \in S_N} \sqrt{\frac{1}{N}\sum_{i=1}^{N} | \mathbf{p}i - \mathbf{q}{\sigma(i)} |^2} ] 其中 ( S_N ) 为所有可能的原子排列，匈牙利算法用于高效求解最小权重匹配。

  • RMSDm（最小 RMSD，基于 Trott 等人的方法）： [ RMSD_m = \min_{\mathbf{R}, \mathbf{t}} \sqrt{\frac{1}{N}\sum_{i=1}^{N} | \mathbf{R}\mathbf{p}_i + \mathbf{t} - \mathbf{q}_i |^2} ] 其中 ( \mathbf{R} ) 为旋转矩阵，( \mathbf{t} ) 为平移向量，允许在最小化 RMSD 的同时进行刚体变换。

2. 过表达/欠表达比例（Over/Under-Representation）： [ \text{Over/UnderRepresentation} = 100 \times \left( \frac{\% \text{ProteinClass}{\text{Testset}}}{\% \text{ProteinClass}{\text{FDA2023}}} - 1 \right) ] 正值表示测试集中该蛋白类别相对于 FDA 2023 靶标分布过表达，负值表示欠表达。

3. 累积百分比差异（Cumulative % Difference）： [ \text{Cumulative \% Diff} = \sum_{\text{classes}} \left| \% \text{ProteinClass}{\text{Testset}} - \% \text{ProteinClass}{\text{FDA2023}} \right| ] 用于量化测试集与 FDA 2023 靶标分布的整体差异，值越小表示测试集越能代表真实药物靶标分布。

4. 富集因子（Enrichment Factor, EF）（隐含于 DE 分析中）： [ EF_{1\%} = \frac{\text{Active hits in top 1\% of database} / \text{Total actives}}{\text{1\% of database} / \text{Total database}} ] 用于评估程序在数据库前 1% 中富集活性分子的能力。

11 结论正确解读

任务范围：本文评估的是三种对接程序（DOCK6.12、Vina 1.1.2、AD4 2.6）在四种标准对接任务（PR、CD、DE、RD）上的表现。结论仅适用于这些程序的特定版本和本文使用的标准化协议。

真值/输入：所有评估基于实验确定的共晶结构（X-ray 和 EM），配体质子化状态基于文献报道。这些真值本身存在实验误差，且 EM 结构（26 个）的精度可能低于 X-ray 结构。

端到端状态：本文评估的是「对接」这一单一环节，而非完整的虚拟筛选流程。实际药物发现中，对接前的准备（如蛋白构象选择、质子化状态）和对接后的后处理（如 MD 模拟、MM-GBSA 重打分）对最终结果有重要影响，本文未涉及。

算力成本：本文未系统比较三种程序的计算时间（作者明确说明这不是本文重点）。DOCK6 需要预计算 grid，Vina 和 AD4 的采样机制不同，实际计算成本差异可能显著。

历史数据依赖：SB2025 的构建基于 PDB 中截至 2023 年的结构数据，FARMA2025 基于截至 2023 年批准的药物。随着新结构和新药物的出现，测试集需要更新。

模型依赖：三种程序使用不同的打分函数（DOCK6: 基于力场的能量函数；Vina: 经验打分函数；AD4: 半经验自由能函数），其性能差异可能源于打分函数而非采样算法。本文未单独区分采样和打分的贡献。

最难情形：CD 实验中的离对角线对接（特别是 HSP90 家族）是最具挑战性的任务，Vina 在无结构水时成功率仅 19.7%。RD 实验中的 cognate rank 任务也极具挑战性，三种程序的平均排名均在 17-31 之间（随机为 83）。

群体边界：本文的结论基于 1,244 个复合物，覆盖 17 个蛋白类别，但某些类别（如 NTPase）样本量较小。对于未覆盖的蛋白类型（如 RNA 结合蛋白、蛋白-蛋白相互作用界面），结论可能不适用。

有边界的复述：在本文构建的 SB2025 和 FARMA2025 测试集上，使用开发者推荐的标准化协议，DOCK6 在 PR 上略优于 Vina 和 AD4（74.6% vs 71.0% vs 65.8%），AD4 在 CD 矩阵成功率上最高（46.4%），DOCK6 在 DE 早期富集上表现最佳（AUC@1%FPR = 9.1），DOCK6 在 RD 靶标识别上最优（平均 cognate rank = 17.1）。三种程序在不同任务和蛋白家族上各有优劣，没有单一程序在所有任务上全面领先。

14 学到什么

Agent 提炼的知识候选：

  1. 基准测试集构建的「计算就绪」标准：SB2025/FARMA2025 提供了标准化输入文件（mol2、pdbqt、grid 等），大幅降低了用户使用门槛。这一做法可迁移到其他计算方法的基准测试中——不仅提供原始结构，还提供经过验证的、可直接运行的输入文件和脚本。

  2. 多任务评估框架：本文的 PR/CD/DE/RD 四任务框架可迁移到其他对接程序或深度学习对接方法的评估中。特别是 RD 任务（反向对接）在多数基准测试中缺失，但对药物重定位研究至关重要。

  3. 参数优化的「程序特异性」原则：本文发现不同程序的最优 box size 不同（DOCK6 偏好大 box，Vina/AD4 偏好小 box），这提示在评估或使用对接程序时，应针对每个程序进行参数优化，而非使用统一的参数设置。

  4. 结构水处理的「体系特异性」：HSP90 案例表明结构水对 CD 结果有决定性影响（Vina 成功率从 19.7% 到 90.3%），但这一结论可能不适用于所有体系。在对接研究中，应评估结构水对目标体系的重要性，而非盲目包含或排除。

  5. 「共识对接」的潜在价值：DE 实验中三种程序选中的活性分子重叠度低（作者未直接报告，但 Venn 图暗示），提示「共识对接」策略（多个程序的结果取交集）可能提高虚拟筛选的精确率。这一假设值得在后续研究中验证。

  6. FARMA2025 作为药物相关基准的价值：FARMA2025 是首个以已批准药物为核心的对接基准测试集，其靶标类别分布与 FDA 2023 年批准药物高度一致（R²=0.72）。这一设计理念可迁移到其他计算方法的评估中——基准测试集应反映目标应用场景的分布。

  7. 失败模式分析的方法论：本文将 PR 失败分为「采样失败」和「打分失败」，这一分类方法可迁移到其他对接程序的调试中，帮助开发者定位算法瓶颈。

  8. 「不兼容配对」的处理策略：CD 实验中排除 RMSD > 2 Å 的配对，这一策略虽然可能引入偏差，但避免了不公平的比较。在类似的多对多对接评估中，应明确说明排除标准并评估其影响。

Reviewer

  • Overall assessment This manuscript presents a substantial and potentially valuable contribution to the computational drug discovery field through the introduction of two new benchmark datasets and a systematic comparison of three widely used docking programs. The work addresses an important need for standardized, clinically relevant test sets and provides a comprehensive evaluation framework. However, the current manuscript has several significant issues that need to be addressed, particularly regarding the clarity of the dataset construction methodology, the statistical rigor of the comparisons, and the interpretation of the reverse docking results. The claims about FARMA2025 being the first of its kind and the generalizability of the findings require more careful support. The manuscript would benefit from clearer presentation of the benchmarking protocols and more nuanced discussion of the limitations.

  • Who would be interested in the results, and why Computational chemists and structural biologists developing or using docking software would be the primary audience. Drug discovery researchers in both academic and industrial settings would find the benchmark datasets and comparative performance data valuable for tool selection and protocol optimization. The FARMA2025 dataset, in particular, would be of interest to those working on drug repurposing and target identification. The methodological framework for benchmarking could also inform future software development efforts.

  • Major strengths 1. Introduction of two new benchmark datasets (SB2025 and FARMA2025) that address gaps in existing test sets, particularly the focus on approved drugs and the alignment with FDA drug target class distributions 2. Comprehensive benchmarking across four distinct tasks (PR, CD, DE, RD) under standardized conditions 3. Systematic exploration of key parameters affecting docking outcomes (sampling space, exhaustiveness, charge models, RMSD calculation methods) 4. The FARMA2025 dataset's design to mirror FDA drug target class distributions is a thoughtful approach to creating a clinically relevant benchmark 5. The authors' willingness to identify weaknesses in their own software (DOCK6) and explore parameter space is commendable

  • Major Concerns

  • Concern ID R1-M1

  • Severity Major
  • Blocking Yes
  • Axis Methodology clarity and reproducibility
  • Claim pointer The manuscript claims to introduce "a calculation-ready set of 1,244 protein-ligand complexes" and that these are "freely available" for download
  • Evidence pointer Methods section, "SB2025 Test Set Criteria" and "File Preparation for Energy Minimization and Docking" sections; location not provided
  • Concern The description of how the SB2025 dataset was constructed is insufficiently detailed. While the authors mention criteria for inclusion (resolution, non-covalent binding, etc.), the specific workflow for how structures were selected, processed, and validated is not fully described. The claim that the dataset is "calculation-ready" requires a clear description of the exact preparation pipeline, including protonation state assignment, charge calculation methods, and any manual curation steps. Without this detail, other researchers cannot reproduce the dataset construction or fully understand potential biases in the benchmark.
  • Why it matters The value of a benchmark dataset depends entirely on its construction methodology. If the preparation pipeline is not fully specified, users cannot assess whether the dataset is appropriate for their specific applications, and the reproducibility of the benchmarking results is compromised. This is particularly important given the authors' claim that this dataset improves upon previous versions.

  • Resolution test The authors should provide a complete, step-by-step description of the dataset construction pipeline, including all software tools, parameters, and decision criteria used. Ideally, this would include a flowchart or pseudocode of the preparation process, and the exact commands or scripts used should be made available.

  • Concern ID R1-M2

  • Severity Major
  • Blocking Yes
  • Axis Statistical rigor of comparisons
  • Claim pointer The manuscript states that "Averaged PR success rate across triplicate runs for DOCK6 was slightly improved compared to Vina (followed by AD4)" and makes similar comparative claims for CD, DE, and RD
  • Evidence pointer Results sections for PR, CD, DE, and RD; location not provided
  • Concern The statistical analysis of the differences between programs appears to be limited to reporting means and standard deviations. The manuscript does not describe any formal statistical testing (e.g., paired t-tests, Wilcoxon signed-rank tests, or ANOVA) to determine whether the observed differences between programs are statistically significant. Given the relatively small differences reported (e.g., 74.6% vs 71.0% for PR), it is unclear whether these differences are meaningful or within the range of random variation. Additionally, the manuscript does not discuss the distribution of results across the different protein families or ligand types, which could reveal important interaction effects.
  • Why it matters The primary contribution of this work is the comparative benchmarking of three docking programs. Without proper statistical analysis, readers cannot determine whether the observed differences are robust or merely artifacts of the specific test set composition. This is particularly important for practical recommendations about which program to use for specific applications.

  • Resolution test The authors should perform appropriate statistical tests to compare the performance of the three programs across all benchmarks. This should include both overall comparisons and analyses stratified by protein class or ligand properties. The results of these tests should be reported with appropriate effect sizes and confidence intervals.

  • Severity Major
  • Blocking Yes
  • Axis Interpretation of reverse docking results
  • Claim pointer The manuscript claims that "Challenging RD tests using FARMA2025, which gauge the ability to correctly rank the cognate structure best, indicate that generating the correct ligand pose is necessary but not sufficient"
  • Evidence pointer Results section, "Reverse Docking (RD)" subsection; location not provided
  • Concern The interpretation of the RD results as showing that "generating the correct ligand pose is necessary but not sufficient" is not well supported by the data presented. The manuscript reports CFR rates of 28.5% (DOCK6), 20.0% (Vina), and 10.9% (AD4), and PA-CFR rates of 91.5%, 90.9%, and 77.8% respectively.
