8

Humanizing Antibodies and Nanobodies From Scratch With HuDiff.

Nan, Yang; Sun, Hongshuai; Zhang, Bo; Yang, Yue; He, Jianxin; Bai, Qifeng
Bio-protocol · 2026-09-11 · 仅摘要 · 原文

提出HuDiff，一种自适应自回归扩散方法，仅用CDR序列从头生成人源化抗体和纳米抗体，核心贡献在蛋白质序列设计（抗体人源化），方法为AI生成模型，对象为蛋白质（抗体），问题与方法高度契合。

摘要

Antibody (Ab) and nanobody (Nb) humanization is essential for reducing immunogenicity in therapeutic applications. HuDiff is an adaptive autoregressive diffusion approach that generates humanized antibodies and nanobodies from scratch using only complementarity-determining region sequences as input, eliminating the need for preexisting human templates. The method follows a two-stage training pipeline: pretraining on human antibody sequences to learn framework region patterns, followed by fine-tuning on target-species sequences. HuDiff-Ab processes paired heavy and light chains for conventional antibodies, while HuDiff-Nb can incorporate a specialized inpainting mode to preserve critical nanobody framework residues. This protocol provides a complete step-by-step guide for implementing HuDiff, covering data preparation, model training, and sequence generation. Key features * Requires only CDR sequences as input and does not require human template selection. * Uses a two-stage training strategy, with pretraining on human antibody sequences and fine-tuning on target-species sequences guided by humanness scores. * HuDiff-Ab humanizes paired heavy and light chains simultaneously, whereas HuDiff-Nb provides an inpainting mode to preserve key framework residues. * Generates multiple diverse humanized candidates for downstream experimental screening.

摘要翻译

抗体（Ab）和纳米抗体（Nb）的人源化对于减少治疗应用中的免疫原性至关重要。HuDiff是一种自适应自回归扩散方法，仅使用互补决定区序列作为输入，从头生成人源化抗体和纳米抗体，无需预先存在的人类模板。该方法遵循两阶段训练流程：先在人类抗体序列上进行预训练以学习框架区模式，再在目标物种序列上进行微调。HuDiff-Ab处理常规抗体的配对重链和轻链，而HuDiff-Nb可整合专门的修补模式以保留关键的纳米抗体框架残基。本协议提供了实施HuDiff的完整分步指南，涵盖数据准备、模型训练和序列生成。关键特性 * 仅需CDR序列作为输入，无需人类模板选择。 * 采用两阶段训练策略，在人类抗体序列上预训练，并在目标物种序列上以人源化评分指导微调。 * HuDiff-Ab同时人源化配对的重链和轻链，而HuDiff-Nb提供修补模式以保留关键框架残基。 * 生成多个多样化的人源化候选序列，供下游实验筛选使用。

02 一句话总结

HuDiff 是一个自适应自回归扩散模型，仅以 CDR 序列为输入，通过两阶段训练（人类抗体序列预训练 + 目标物种序列微调）从头生成人源化抗体和纳米抗体，无需人类模板，并支持纳米抗体 inpainting 模式以保留关键框架残基。

03 研究问题

  • 具体问题：如何在不依赖预先选定的人类模板的情况下，仅从 CDR 序列出发生成低免疫原性的人源化抗体和纳米抗体？
  • 为什么重要：抗体/纳米抗体人源化是降低治疗性蛋白免疫原性的关键步骤，传统方法依赖人类模板选择，模板质量直接影响结果，且对纳米抗体等非标准支架效果有限。
  • 现有方法不足：传统 CDR 移植和表面重塑需要人工选择模板，耗时且对非人类框架适应性差；现有生成模型（如扩散模型）多需完整序列或结构输入，未针对 CDR-only 输入和框架区保留进行优化。
  • 精确研究问题：Can an autoregressive diffusion model, pretrained on human antibody sequences and fine-tuned on target-species sequences, generate humanized antibodies and nanobodies from CDR sequences alone, without human template selection?

04 背景与发展脉络

  • 阶段一：传统人源化方法（CDR 移植、表面重塑）——优点：成熟、可解释；局限：依赖模板选择，对非人类框架适应性差，耗时。
  • 阶段二：基于序列的生成模型（如 LSTM、Transformer 用于抗体序列设计）——优点：可生成多样序列；局限：多需完整序列或结构输入，未专门针对人源化任务优化。
  • 阶段三：扩散模型在蛋白质设计中的应用——优点：生成质量高、可控性强；局限：多数方法需结构或完整序列输入，计算成本高。
  • 本文位置：提出 HuDiff，将自回归扩散模型适配到 CDR-only 输入的人源化任务，通过两阶段训练和 inpainting 模式解决框架区保留问题。

06 核心思想

  1. 表面方法：两阶段训练的自回归扩散模型，输入 CDR 序列，输出完整人源化抗体/纳米抗体序列；纳米抗体支持 inpainting 模式。
  2. 核心洞察：通过预训练学习人类框架区模式，再通过微调适应目标物种，使得模型能够从 CDR 出发「填充」框架区，无需模板；inpainting 模式允许在生成过程中固定关键框架残基。
  3. 可能的普适教训 [Analysis]：对于序列生成任务，两阶段训练（先学通用模式，再学任务特定模式）可有效平衡通用性与特异性；inpainting 是处理「关键残基保留」问题的通用策略，可迁移到其他蛋白质设计任务。

07 方法总览

  • 输入：CDR 序列（抗体为重链和轻链 CDR，纳米抗体为单链 CDR）

  • 训练：两阶段——先在人类抗体序列上预训练，再在目标物种序列上微调

  • 反馈回路：humanness scores 在微调阶段作为引导信号

14 学到什么

Agent 提炼的知识候选： 1. 两阶段训练策略：先预训练通用模式（人类抗体序列），再微调任务特定模式（目标物种），可迁移到其他蛋白质设计任务（如酶设计、抗原表位设计）。 2. CDR-only 输入设计：仅用功能关键区域（CDR）作为输入，减少输入维度，降低数据需求，可迁移到其他功能位点驱动的设计任务。 3. Inpainting 模式：在生成过程中固定关键残基，是处理「保守残基保留」问题的通用策略，可迁移到结构预测（如固定活性位点）或 MD 模拟（如固定结合口袋）。 4. Humanness scores 引导微调：用可量化的属性分数引导生成过程，可迁移到其他属性优化任务（如稳定性、溶解度、亲和力）。 5. 多候选生成：生成多个多样候选供下游筛选，是生成模型与实验验证衔接的通用范式，可迁移到结构生成（如构象采样）任务。

15 与已有知识连接

  • 相似方法：与扩散模型在蛋白质设计中的应用（如 RFdiffusion）相似，但本文聚焦序列级生成，RFdiffusion 聚焦结构级生成。
  • 组合方向：HuDiff 生成的序列可输入 AlphaFold 进行结构验证，或用于 MD 模拟评估框架区稳定性。
  • 冲突点：本文仅用序列信息，与结构感知方法（如 AlphaFold 引导的设计）存在潜在冲突，需实验验证序列-only 方法的边界。
  • 可迁移领域：inpainting 策略可迁移到构象采样（固定关键残基）、分子对接（固定结合位点）等任务。
  • 候选方向：将 HuDiff 的两阶段训练策略与结构预测结合，实现序列-结构联合优化。

  • Who would be interested in the results, and why 治疗性抗体和纳米抗体研发人员，特别是从事抗体工程、免疫原性降低和候选分子筛选的研究组；计算生物学和机器学习应用于蛋白质设计的研究者；以及关注 AI 驱动生物药物开发平台的工业界科学家。他们会对「仅需 CDR 输入即可生成人源化序列」这一简化流程感兴趣，因为它可能减少对结构数据和模板库的依赖。

  • Major strengths 1. 核心主张明确且具有实际意义：仅以 CDR 为输入、无需人源模板，直接回应了传统人源化方法依赖模板匹配的瓶颈。 2. 两阶段训练策略（人源预训练 + 目标物种微调）逻辑清晰，符合迁移学习在生物序列建模中的成熟范式。 3. 区分 HuDiff-Ab 和 HuDiff-Nb 两种模式，并针对纳米抗体引入 inpainting 机制，显示了对不同抗体格式特殊性的考虑。 4. 生成多个多样化候选的设计目标与实验筛选流程衔接合理，具有实际操作性。

  • Major Concerns

  • Concern ID R1-M1

  • Severity Major
  • Blocking Yes
  • Axis 技术可实现性
  • Claim pointer 「HuDiff is an adaptive autoregressive diffusion approach that generates humanized antibodies and nanobodies from scratch using only complementarity-determining region sequences as input」
  • Evidence pointer 摘要全文；location not provided
  • Concern 摘要未提供任何关于「adaptive autoregressive diffusion」架构的具体描述。自回归模型与扩散模型的结合方式、自适应机制的具体含义、CDR 序列如何条件化生成过程，这些核心设计决策均未说明。作为 protocol 稿件，读者需要明确的架构定义才能复现。
  • Why it matters 如果架构描述不完整，protocol 无法被独立实施。此外，「adaptive」和「from scratch」的表述在当前描述下缺乏可验证的技术内涵，可能误导读者对方法复杂度和输入要求的理解。

  • Resolution test 在完整 protocol 中提供模型架构图、输入输出张量维度、CDR 序列编码方式、自回归与扩散组件的具体交互机制，以及「adaptive」的准确定义。

  • Concern ID R1-M2

  • Severity Major
  • Blocking Yes
  • Axis 可复现性
  • Claim pointer 「pretraining on human antibody sequences to learn framework region patterns, followed by fine-tuning on target-species sequences guided by humanness scores」
  • Evidence pointer 摘要全文；location not provided
  • Concern 摘要未提供预训练和微调数据集的具体来源、规模、物种范围或序列筛选标准。humanness score 的定义、计算方法和在训练中的具体引导方式（如损失函数加权、采样约束或后处理过滤）完全未说明。两阶段训练的超参数（学习率、训练轮数、批次大小等）也未提及。
  • Why it matters 对于 protocol 类稿件，数据获取和评分标准是复现的关键路径。缺少这些信息，读者无法判断训练数据的适用性，也无法评估 humanness score 是否客观反映免疫原性风险。

  • Resolution test 在 protocol 中列出数据来源（如 OAS、IMGT 等）、版本号、序列数量、物种组成、预处理流程；提供 humanness score 的数学定义或引用原始文献，并说明其在训练流程中的具体集成方式。

  • Severity Major
  • Blocking Yes
  • Axis 性能验证
  • Claim pointer 「Generates multiple diverse humanized candidates for downstream experimental screening」
  • Evidence pointer 摘要全文；location not provided
  • Concern 摘要未提供任何生成序列的质量评估数据。没有 humanness score 的分布、与已知人源抗体的序列相似性、框架区残基保守性、CDR 结构完整性或功能活性（如抗原结合亲和力）的验证结果。也没有与现有方法（如 CDR grafting、Sapiens、BioPhi 等）的对比数据。

  • Concern ID R1-M4

  • Severity Major
  • Blocking No
  • Axis 方法适用性边界
  • Claim pointer 「HuDiff-Nb can incorporate a specialized inpainting mode to preserve critical nanobody framework residues」
  • Evidence pointer 摘要全文；location not provided
  • Concern 摘要未说明 inpainting 模式的具体触发条件、哪些残基被定义为「critical」、以及该模式与传统 CDR grafting 或结构引导设计有何本质区别。纳米抗体的人源化面临独特的框架区保守性问题，但摘要未提供针对这一挑战的解决方案细节。
  • Why it matters 纳米抗体因其小尺寸和 CDR3 长环结构而具有特殊的人源化难点。如果 inpainting 模式只是简单的残基掩码和重建，可能不足以解决框架区稳定性和 VHH 特异性残基（如 45e、47、103 等）的保留问题。

  • Resolution test 在 protocol 中明确 inpainting 模式的输入格式、掩码策略、关键残基的定义标准，并提供纳米抗体人源化的具体案例或基准测试。

  • Readability for nonspecialists 尚可。摘要语言清晰，但「adaptive autoregressive diffusion」和「inpainting mode」等术语缺乏解释，可能阻碍非计算背景读者理解。
