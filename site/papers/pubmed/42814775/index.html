GeoEPred: A multimodal structure-aware geometric deep learning framework for Gram-negative bacterial secreted effector prediction with sequence semantics.

Song, Shouzhen; Shi, Hua; Wu, Hongfeng; Liu, Dachen; Lin, Yihang; Mat Isa, Nor Ashidi; Zou, Quan; Wei, Leyi
PLoS computational biology · 2026-09-30 · 仅摘要 · 原文

该文提出GeoEPred，融合蛋白语言模型序列嵌入与ESMFold预测结构，通过几何深度学习预测细菌效应蛋白，虽对象非典型蛋白结构计算问题，但结构感知建模方法可迁移至蛋白质结构相关任务。

摘要

Accurate prediction of effector proteins secreted by Gram-negative bacteria is important for elucidating bacterial pathogenic mechanisms and developing precise anti-infective strategies. Although existing methods have benefited from the strong sequence feature extraction capacity of pretrained protein language models, reliance on linear sequence information alone often fails to fully capture the three-dimensional conformational signals required for virulence functions. Meanwhile, conventional structure-based methods are limited by the scarcity of experimentally resolved protein structures. To address these challenges, we propose GeoEPred, a multimodal deep learning framework designed for the synergistic modeling of protein sequence and structure to identify Gram-negative bacterial effector proteins. Specifically, the model integrates sequence-contextual embeddings from a pretrained protein language model with three-dimensional structural representations predicted by ESMFold. A feature projection network refines fine-grained sequence signals associated with effector functions, while geometric vector perceptrons characterize inter-residue orientations, distances, and local spatial topology to capture potential structural conformational motifs. To further enable effective cross-modal fusion, we design a cross-modal alignment and feature-tokenized self-attention module. This module enhances consistency between the sequence-semantic and structural-geometric spaces through contrastive learning and models associations between linear functional motifs and spatial conformational patterns at a fine-grained token level. Extensive evaluations on multiple benchmark datasets show that GeoEPred achieves better predictive performance than existing leading models in T3SE, T4SE, and T6SE prediction tasks, while maintaining stable performance in remote homolog recognition scenarios. Moreover, the modular and extensible architecture of GeoEPred demonstrates strong generalization ability and substantial application potential for genome-scale effector protein discovery.

摘要翻译

06 核心思想

1) 表面方法

GeoEPred 是一个多模态深度学习框架，输入为蛋白质序列，通过预训练蛋白质语言模型获得序列语义嵌入，同时通过 ESMFold 预测三维结构，再用几何向量感知器（Geometric Vector Perceptrons, GVP）编码结构几何特征，最后通过跨模态对齐与特征 token 化自注意力模块进行融合，输出效应蛋白分类预测。

2) 核心洞察

  • 预测结构可作为序列方法的补充模态：ESMFold 提供的预测结构虽非实验解析，但足以提供与功能相关的粗粒度构象信号，弥补序列信息的不足。
  • 跨模态对齐是关键：序列语义空间与结构几何空间存在本质差异，需要对比学习等机制将两者对齐，才能实现有效的信息互补而非简单拼接。
  • Token 级融合优于全局融合：在细粒度 token 水平上建模序列 motif 与结构构象模式之间的关联，能更精确地捕捉功能相关特征。

3) 可能的普适教训 [Analysis]

  • 对于蛋白质功能预测类任务，当实验结构稀缺时，预测结构（如 ESMFold/AlphaFold2 输出）可作为「免费」的结构模态引入，且无需昂贵的 MD 模拟或对接计算。
  • 多模态融合的核心挑战不是「有没有两种模态」，而是「如何对齐两种模态的特征空间」——对比学习 + token 级注意力是一种可迁移的通用方案。
  • 模块化设计（序列模块、结构模块、融合模块各自独立）有利于框架的扩展和迁移到其他任务。

07 方法总览

  • 输入：蛋白质氨基酸序列（单序列输入）
  • 输出：二分类预测（是否为效应蛋白，具体 T3SE/T4SE/T6SE 分别建模或联合建模，摘要未明确）
  • 模块： 1. 序列编码模块：预训练蛋白质语言模型（具体模型未在摘要中指定）→ 序列上下文嵌入 2. 结构预测模块：ESMFold → 预测三维结构 3. 结构编码模块：几何向量感知器（GVP）→ 残基间方向、距离、局部拓扑特征 4. 特征投影网络：精炼序列级功能相关特征 5. 跨模态融合模块：对比学习对齐 + 特征 token 化自注意力 → 融合表示 6. 分类头：全连接层 → 效应蛋白概率
  • 训练：多任务或单任务分类训练 + 对比学习辅助损失（摘要未给出具体损失权重、优化器、学习率等细节）
  • 工具：ESMFold（结构预测）、预训练蛋白质语言模型（序列嵌入）、GVP（几何编码）
  • 假设：
  • ESMFold 预测结构足以提供功能相关的构象信号；
  • 序列语义与结构几何之间存在可学习的对齐关系；
  • Token 级融合能捕捉 motif-构象关联。
  • 流程：序列 → 语言模型嵌入 + ESMFold 结构 → GVP 结构特征 → 特征投影 → 跨模态对齐与融合 → 分类输出

11 结论正确解读

  • 任务范围：仅覆盖革兰氏阴性细菌的 T3SE、T4SE、T6SE 效应蛋白预测，不涵盖其他分泌系统（如 T1SE、T2SE、T5SE）或其他细菌类型。
  • oracle/真值输入：无人工标注结构输入，结构来自 ESMFold 预测，因此结论受限于 ESMFold 预测精度。
  • 端到端状态：框架是端到端可训练的（序列 → 预测），但依赖 ESMFold 作为外部结构预测工具，非完全端到端。
  • 算力成本：摘要未提及训练/推理计算成本；ESMFold 结构预测本身有较高计算开销，基因组规模应用时需考虑。
  • 历史数据依赖：依赖训练数据中效应蛋白的标注质量与多样性；未提供训练集规模与来源。
  • 模型依赖：依赖预训练蛋白质语言模型的选择和 ESMFold 版本，不同选择可能影响结果。
  • 最难情形：远程同源识别是测试的难点场景，但摘要未给出具体性能衰减数据。
  • 群体/领域边界：结论仅适用于革兰氏阴性细菌效应蛋白，不可外推至真核生物或其他分泌机制。
  • 不确定性：未提供置信区间、误差棒或统计显著性检验信息。

有边界的复述：GeoEPred 在多个 benchmark 数据集上，针对 T3SE、T4SE、T6SE 三类革兰氏阴性细菌效应蛋白预测任务，展示了优于现有方法的性能，并在远程同源场景下保持稳定；该结论基于 ESMFold 预测结构作为结构模态输入，且未提供具体数值与统计检验。

14 学到什么

Agent 提炼的知识候选：

  1. 预测结构作为「免费」结构模态的通用策略：在蛋白质功能预测任务中，当实验结构稀缺时，可直接使用 ESMFold（或 AlphaFold2）预测结构作为结构模态输入，无需昂贵的实验或 MD 模拟。此策略可迁移至：蛋白质-蛋白质互作预测、结合位点预测、酶功能注释等任务。

  2. GVP 作为结构编码器的可迁移性：几何向量感知器（Geometric Vector Perceptrons）能够有效编码残基间方向、距离和局部拓扑，这种几何特征表示方法可迁移至分子对接 pose 评分、蛋白质-配体结合亲和力预测等任务。

  3. 跨模态对比学习对齐策略：通过对比学习将序列语义空间与结构几何空间对齐，是解决多模态特征空间不一致的通用方案。可迁移至：序列-结构-功能联合建模、蛋白质设计中的序列-结构协同优化。

  4. Token 级融合优于全局融合：在细粒度 token 水平上建模跨模态关联（而非全局向量拼接），能更精确捕捉局部功能 motif 与结构构象的对应关系。此思路可迁移至：功能位点预测、突变效应预测等需要局部精度任务。

  5. 模块化架构设计：序列模块、结构模块、融合模块各自独立的设计有利于框架扩展——可替换不同的 PLM、不同的结构编码器、不同的融合策略，便于适配新任务。

  6. 远程同源泛化测试：将远程同源识别作为额外评测场景，是检验模型是否真正学到功能相关特征（而非记忆序列相似性）的有效实验设计，值得在其他蛋白质功能预测任务中借鉴。

15 与已有知识连接

  • AlphaFold2 (Jumper et al., 2021, Nature)：AlphaFold2 开创了高精度蛋白质结构预测，本文使用的 ESMFold 是 AlphaFold2 的轻量级替代，表明预测结构已足够成熟可用于下游任务。
  • ESM 系列 (Lin et al., 2023, Science)：ESM-2 及 ESMFold 展示了蛋白质语言模型在序列表示和结构预测上的强大能力，本文直接使用 ESMFold 作为结构模态来源。
  • Geometric Vector Perceptrons (Jing et al., 2021, ICLR)：GVP 是专为蛋白质结构设计的等变神经网络层，本文将其用于结构几何特征提取，是该架构在功能预测任务中的又一应用。
  • EffectiveT3 (Eid et al., 2021) 及 DeepT3 (Xue et al., 2018)：此前 T3SE 预测的代表性方法，主要基于序列特征，本文将其作为被超越的基线（摘要中未明确列出，但属于领域常识）。
  • CLIP (Radford et al., 2021)：对比学习跨模态对齐的经典范式，本文的跨模态对齐模块在思想上与 CLIP 一致，但应用于蛋白质序列-结构双模态。
  • 候选方向（未验证）：本文的框架思路与「蛋白质语言模型 + 结构编码器」的通用范式（如 ESM-IF、GVP-Transformer）有潜在联系，但摘要中未提及，需查阅全文确认。

16 研究想法

Agent 生成的研究候选：

候选 1：GeoEPred 框架迁移至蛋白质-蛋白质互作（PPI）预测

  • 名称：GeoPPI：structure-aware multimodal PPI prediction
  • 来源局限/观察：GeoEPred 证明了序列+预测结构的多模态融合对效应蛋白预测有效；PPI 预测同样面临序列信息不足、实验结构稀缺的问题
  • 核心假设：将 GeoEPred 的跨模态对齐 + token 级融合策略应用于 PPI 预测，可超越纯序列方法
  • 初步方法：双分支编码（每条链分别用 PLM + ESMFold + GVP），跨链注意力融合，对比学习对齐
  • 验证方式：使用 Docking Benchmark 5.5 或 PPI 标准数据集，与 D-SCRIPT、PIPR 等基线对比
  • 可能的失败模式：PPI 需要双链联合建模，简单拼接可能无法捕捉界面互补性；预测结构误差在界面区域可能更大
  • 创新状态：unverified

候选 2：将 MD 模拟作为结构模态的补充或替代

  • 名称：GeoEPred-MD：incorporating conformational ensembles from MD simulations
  • 来源局限/观察：GeoEPred 使用单一静态预测结构，但蛋白质功能往往依赖构象动态；MD 模拟可提供构象系综
  • 核心假设：使用 MD 模拟生成的构象系综替代单一结构，可提升对构象敏感的功能预测（如效应蛋白分泌信号）
  • 初步方法：对 ESMFold 预测结构进行短时 MD 模拟（如 100ns），采样多个构象，用 GVP 编码后通过注意力池化聚合
  • 验证方式：在 GeoEPred 的 benchmark 上对比单结构 vs 构象系综的性能差异
  • 可能的失败模式：MD 模拟计算成本高，基因组规模应用不可行；短时 MD 可能未充分采样功能相关构象
  • 创新状态：unverified

候选 3：序列-结构-功能三模态联合建模

  • 名称：TriGeoPred：integrating sequence, structure, and functional annotation modalities
  • 来源局限/观察：GeoEPred 仅融合序列和结构两种模态；功能注释（如 GO、InterPro domain）可能提供额外信号
  • 核心假设：加入功能注释模态可进一步提升效应蛋白预测精度，尤其在远程同源场景
  • 初步方法：在 GeoEPred 基础上增加功能注释编码分支（如 GO term embedding），三模态跨模态对齐
  • 验证方式：与 GeoEPred 对比，检验增量提升是否显著
  • 可能的失败模式：功能注释本身可能依赖序列相似性，引入循环偏差；注释缺失率高的蛋白质可能无法受益
  • 创新状态：unverified

候选 4：GeoEPred 用于蛋白质设计中的序列-结构协同优化

  • 名称：GeoDesign：leveraging cross-modal alignment for sequence-structure co-design
  • 来源局限/观察：GeoEPred 的跨模态对齐模块学习了序列 token 与结构几何的对应关系，这种对应关系可用于逆向设计
  • 核心假设：GeoEPred 学到的序列-结构对齐可用于指导功能位点的序列设计
  • 初步方法：将 GeoEPred 的融合表示作为条件，使用生成模型（如扩散模型或自回归模型）生成满足特定结构约束的序列
  • 验证方式：在已知效应蛋白上做序列回复突变实验，检验生成序列是否保留功能
  • 可能的失败模式：判别模型的表示未必适合生成任务；对齐精度不足以指导残基级别的设计
  • 创新状态：unverified

候选 5：跨物种泛化与基因组规模筛选的基准测试

  • 名称：GeoEpiScan：systematic evaluation of GeoEPred for genome-scale effector discovery across bacterial species
  • 来源局限/观察：摘要声称「genome-scale effector protein discovery」的应用潜力，但未提供实际基因组规模实验数据
  • 核心假设：GeoEPred 在跨物种基因组规模筛选中优于现有方法，且计算成本可控
  • 初步方法：在多个完整细菌基因组上运行 GeoEPred，评估预测阳性率、计算时间、与已知效应蛋白的重叠
  • 验证方式：与现有基因组规模效应蛋白预测工具对比，检验 precision/recall
  • 可能的失败模式：ESMFold 在全基因组规模上的计算成本过高；跨物种泛化性能可能下降
  • 创新状态：unverified
