Trion-1: Unifying Language, Protein Sequence, and Structure with Diffusion Language Models

Tianyu Lu; Kaicheng Yang; Jiangtao Feng; Keyue Qiu; Yawen Ouyang; Yixin Wu; Xinbo Zhang; Lihao Wang; Wei-Ying Ma; Hao Zhou
arXiv 预印本 · 2026-10-22 · 全文(ar5iv) · 原文

该文提出Trion-1，一个统一序列、结构与自然语言的多模态扩散语言模型，实现折叠、逆折叠、序列/结构理解与设计等六项蛋白质结构计算能力，方法创新且直接命中蛋白质结构预测与生成核心问题。

摘要

We envision a general-purpose protein foundation model as a unified, interactive model of sequence, structure, and function, capable of understanding, generation, and cross-modal translation while retaining the instruction-following and reasoning capabilities of modern LLMs. Toward this vision, we introduce Trion-1, the first native, unified, multimodal diffusion language model (dLLM) for proteins. Trion-1 is built on two key design choices: (1) a unified discrete token space that jointly represents sequence, structure, and natural language; (2) a dLLM backbone that replaces strict left-to-right factorization with bidirectional or semi-bidirectional token interactions, enabling global residue communication and long-range contact modeling that are naturally suited to structure modeling. This formulation unifies six core capabilities: folding, inverse folding, sequence understanding, structure understanding, sequence design, and structure design, while retaining the native language capabilities of general-purpose LLMs. On established benchmarks, Trion-1 achieves broadly competitive performance. In folding, Trion-1 achieves a TM-score above 0.8 with a single sample under strict homology control, matching or exceeding the existing tri-modal model using 200 samples. For sequence understanding, Trion-1 performs on par with top-tier LLMs such as Claude Opus 4.7 (62.37%). These results support well-aligned sequence-structure-language representations and strong cross-modal generative capabilities.

摘要翻译

我们设想一个通用蛋白质基础模型，作为序列、结构和功能的统一交互模型，能够理解、生成和跨模态转换，同时保留现代LLM的指令遵循和推理能力。为实现这一愿景，我们引入了Trion-1，这是首个原生、统一的多模态蛋白质扩散语言模型（dLLM）。Trion-1基于两个关键设计选择：（1）一个统一的离散标记空间，共同表示序列、结构和自然语言；（2）一个dLLM骨干架构，用双向或半双向标记交互替代严格的从左到右分解，实现全局残基通信和长程接触建模，这些特性天然适合结构建模。该公式统一了六项核心能力：折叠、逆折叠、序列理解、结构理解、序列设计和结构设计，同时保留通用LLM的原生语言能力。在既定基准测试中，Trion-1实现了广泛竞争性的性能。在折叠方面，Trion-1在严格同源控制下，单次采样即可达到TM-score超过0.8，匹配或超过使用200个样本的现有三模态模型。在序列理解方面，Trion-1与Claude Opus 4.7（62.37%）等顶级LLM表现相当。这些结果支持了序列-结构-语言表示的紧密对齐和强大的跨模态生成能力。

02 一句话总结

本文提出 Trion-1，一个基于扩散语言模型（Diffusion Language Model）的统一多模态框架，将自然语言、蛋白质序列与蛋白质结构（3D 坐标）映射到同一离散 token 空间进行联合生成与理解，在序列-结构-语言跨模态任务上展示了统一的生成能力。

03 研究问题

  • 具体问题：如何在一个统一的生成框架中同时建模自然语言、蛋白质序列和蛋白质三维结构，使得模型能够跨模态进行条件生成（如用语言描述生成蛋白质结构、用结构生成序列、用序列生成语言描述）？
  • 为什么重要：当前蛋白质 AI 模型通常针对单一模态（序列或结构）设计，缺乏统一的跨模态生成能力。若能统一建模，可大幅提升蛋白质设计、功能注释、结构理解等任务的效率与泛化性。
  • 现有方法为何不足：
  • 序列模型（如 ESM、ProtGPT2）无法直接处理 3D 结构；
  • 结构模型（如 AlphaFold、RFdiffusion）不擅长序列-语言联合生成；
  • 多模态模型（如 Multimodal LLM）通常只做理解/嵌入，不做生成；
  • 缺乏一个统一的生成式框架同时覆盖三种模态。
  • 精确研究问题：Can a single diffusion language model jointly generate and condition across natural language, protein sequence, and protein 3D structure in a unified token space?

06 核心思想

  1. 表面方法：将自然语言、蛋白质序列、蛋白质结构（3D 坐标）统一编码为离散 token，在扩散语言模型框架下进行联合生成与条件生成。

  2. 核心洞察：扩散语言模型天然支持连续噪声注入与去噪生成，可以统一处理离散 token（语言/序列）与连续数据（结构坐标），通过将结构坐标离散化为 token 或通过连续扩散头处理，实现多模态统一。

  3. 可能的普适教训 [Analysis]：多模态统一的关键不在于模型架构本身，而在于如何设计一个共享的 token 空间或表示空间，使得不同模态的数据可以在同一生成框架下互相条件化。这一思路可迁移至其他生物分子（RNA、小分子）与语言/结构的联合建模。

14 学到什么

Agent 提炼的知识候选：

  1. 扩散语言模型作为多模态统一框架：扩散 LM 的连续噪声-去噪机制天然适合混合离散（token）与连续（坐标）数据，可迁移至 RNA/小分子+结构+语言的统一建模。
  2. 统一 token 空间设计：将不同模态映射到同一 token 空间是实现跨模态条件生成的关键，这一思路可迁移至蛋白质-配体复合物、蛋白质-蛋白质相互作用的联合生成。
  3. 结构离散化策略：虽然本文未提供细节，但结构 token 化（如通过 VQ-VAE 或几何哈希）是连接结构预测与序列生成的重要桥梁，值得在本课题中深入探索。
  4. 多任务联合训练范式：多模态联合训练（重建+条件生成）可提升模型泛化性，可迁移至蛋白质设计中的序列-结构协同优化。
