9

Empirical Bayes Flow Matching for Continuous Cryo-EM Heterogeneity

Daniel Aibinder; Azmi Haider; Dan Rosenbaum
arXiv 预印本 · 2026-11-03 · 全文(ar5iv) · 原文

该文提出经验贝叶斯流匹配方法，直接从噪声二维投影中学习蛋白质原子坐标空间的连续构象分布先验，用于冷冻电镜异质性分析，属于蛋白质构象生成与结构计算的核心课题。

摘要

We address the problem of learning generative priors over high-dimensional latent variables from indirect, noisy observations, with a focus on continuous heterogeneity in cryo-electron microscopy (cryo-EM). In this setting, 3D atomic structures $x \in \mathbb{R}^{3N_a}$ are never directly observed and must be inferred from 2D projection images $y$ generated by a complex, non-linear forward operator. We propose Empirical Bayes Flow Matching (EB-FM), a method that learns a flow matching prior $p_θ(x)$ directly from observations using a Monte Carlo stochastic approximation Expectation-Maximization framework. EB-FM alternates between an E-step that performs approximate posterior sampling from $p_θ(x \mid y)$ via guided flow-based generation while maintaining persistent latent estimates through stochastic approximation, and an M-step that updates the flow model using these stabilized latent variables as training targets. This approach eliminates the need for pretraining on clean data and naturally accommodates non-linear forward models. We validate our method on controlled inverse problems using two-moons and MNIST data, and demonstrate its effectiveness on simulated cryo-EM data with known poses, showing that EB-FM can recover continuous distributions of protein conformations directly in atomic-coordinate space.

摘要翻译

我们研究了从间接、带噪声的观测中学习高维潜变量生成先验的问题，重点关注冷冻电子显微镜（cryo-EM）中的连续异质性。在此设定下，3D原子结构 $x \in \mathbb{R}^{3N_a}$ 从未被直接观测到，必须通过由复杂非线性前向算子生成的2D投影图像 $y$ 来推断。我们提出了经验贝叶斯流匹配（Empirical Bayes Flow Matching, EB-FM），一种利用蒙特卡洛随机近似期望最大化框架直接从观测中学习流匹配先验 $p_θ(x)$ 的方法。EB-FM交替进行E步和M步：E步通过引导式流生成从 $p_θ(x \mid y)$ 进行近似后验采样，同时通过随机近似维持持久潜变量估计；M步使用这些稳定化的潜变量作为训练目标更新流模型。该方法消除了对干净数据预训练的需求，并自然适应非线性前向模型。我们在双月形和MNIST数据上验证了该方法在受控逆问题中的表现，并在具有已知姿态的模拟cryo-EM数据上展示了其有效性，表明EB-FM能够直接在原子坐标空间中恢复蛋白质构象的连续分布。

本文提出一种基于 empirical Bayes 的 flow matching 框架，用于从 cryo-EM 图像中学习连续构象异质性分布，通过将每个粒子的潜在构象视为隐变量并对其做经验贝叶斯边际化，从而在无需显式构象标签的条件下训练条件生成模型，输出连续构象密度而非离散状态。

03 研究问题

  • 具体问题：Cryo-EM 单颗粒分析中，如何从大量含噪 2D 投影图像中重建连续的 3D 构象异质性分布，而非仅输出少数离散状态？
  • 为什么重要：蛋白质功能往往依赖连续构象变化（如构象开关、变构、无序区域），传统 cryo-EM 3D 分类只能给出有限离散类，丢失连续信息；连续异质性建模可揭示功能相关的构象路径。
  • 现有方法不足：
  • 3D 分类 / 多状态重建：只能输出离散类，无法表达连续分布。
  • 已有连续异质性方法（如 cryoDRGN 等基于 VAE 的方法）：依赖隐变量编码器，训练不稳定，且隐空间缺乏先验结构。
  • 直接使用 flow matching：需要配对数据（输入-输出对），而 cryo-EM 中每个粒子图像对应的真实 3D 构象未知。
  • 精确研究问题：Can an empirical Bayes formulation of flow matching learn a continuous conformational distribution from unpaired cryo-EM projection images, without explicit per-particle conformational labels?

06 核心思想

1) 表面方法： 将 cryo-EM 异质性建模视为条件生成问题：给定 2D 投影图像，生成对应的 3D 构象密度。使用 flow matching 作为生成模型，但将每个粒子的潜在构象视为隐变量，通过 empirical Bayes 边际化处理。

2) 核心洞察： Cryo-EM 中每个粒子图像是「随机投影 + 噪声」的结果，其对应的 3D 构象是隐变量。与其显式推断每个粒子的构象（如 VAE 的编码器），不如在 empirical Bayes 框架下对隐变量做边际化——即对每个可能的构象，计算其生成该投影的似然，再对所有构象做积分。这样 flow matching 可以在「无配对」条件下训练，且隐空间由 flow 的先验分布自然定义。

3) 可能的普适教训 [Analysis]： - 当观测数据是「隐变量的随机变换 + 噪声」时（如 cryo-EM 投影、MD 中的部分观测），empirical Bayes 边际化是一种自然的训练框架。 - Flow matching 的「插值路径」可天然适配「从噪声到构象」的生成过程，无需显式配对。 - 对蛋白质结构计算研究：任何「从间接观测学习构象分布」的任务（如 SAXS、FRET、交联质谱）都可借鉴此框架。

07 方法总览

  • 输入：cryo-EM 2D 粒子投影图像集合 {x_i}，以及对应的投影方向（由传统 cryo-EM 流程估计）。
  • 输出：一个条件生成模型，可将噪声映射为 3D 构象密度；给定任意投影图像，可采样其对应的构象分布。
  • 模块： 1. 投影算子：将 3D 构象密度投影为 2D 图像（已知物理模型）。 2. Flow matching 生成器：学习从先验噪声到 3D 构象密度的映射，条件为 2D 投影。 3. Empirical Bayes 边际化：对隐变量构象做积分，计算观测投影的边际似然。
  • 训练：最大化观测投影的边际似然（empirical Bayes 目标），flow matching 的损失函数嵌入此目标。
  • 工具：未提供（推测使用 PyTorch 等深度学习框架，但未在材料中说明）。
  • 假设：
  • 投影方向已知（由传统 cryo-EM 流程估计）。
  • 噪声模型为高斯（cryo-EM 常用假设）。
  • 构象空间可由连续隐变量参数化。
  • 流程：输入 2D 投影 → 通过 flow 生成器采样候选 3D 构象 → 投影算子生成模拟 2D 图像 → 与真实观测比较计算似然 → 边际化更新 flow 参数。

09 关键公式符号

由于仅提供摘要级信息，以下公式为基于方法名称的合理重建，标注 [Analysis]，非原文直接引用。

1) Empirical Bayes 边际似然目标： [ \log p(x_i) = \log \int p(x_i | z, \phi) \, p(z) \, dz ] - ( x_i )：第 i 个粒子的 2D 投影图像 - ( z )：隐变量（构象编码） - ( \phi )：投影方向 - ( p(x_i | z, \phi) )：给定构象和投影方向的观测似然（含噪声模型） - ( p(z) )：构象先验（由 flow 定义）

用途：最大化所有粒子的边际对数似然，训练 flow 生成器。

直觉：对每个可能的构象，计算其生成观测的概率，再对所有构象加权平均——这就是「经验贝叶斯」的边际化。

2) Flow matching 损失（标准形式）： [ \mathcal{L}{FM} = \mathbb{E}{t, z_0, z_1} \left[ | v_\theta(z_t, t) - (z_1 - z_0) |^2 \right] ] - ( z_t )：插值路径上的中间状态 - ( v_\theta )：学习的速度场 - ( z_0, z_1 )：先验噪声和目标构象

用途：训练 flow 生成器，使速度场匹配从噪声到构象的插值路径。

直觉：flow matching 学习一个「从噪声到数据」的确定性映射，通过回归速度场实现。

来源：公式 1 为 [Analysis] 基于 empirical Bayes 标准形式重建；公式 2 为 flow matching 领域标准形式（经外部核验，Lipman et al. 2023），但本文是否直接使用此形式未提供。

11 结论正确解读

  • 任务范围：本文方法针对 cryo-EM 连续异质性建模，即从 2D 投影学习 3D 构象分布。
  • oracle/真值输入：投影方向需由传统 cryo-EM 流程预先估计，这是方法的外部依赖。
  • 端到端状态：方法并非完全端到端——投影方向估计是前置步骤，且噪声模型假设为高斯。
  • 算力成本：未提供。
  • 历史数据依赖：方法依赖大量粒子图像，但不需要构象标签。
  • 模型依赖：依赖 flow matching 生成器的表达能力，以及投影算子的物理准确性。
  • 最难情形：高噪声、低信噪比、构象差异微小、投影方向估计误差大时，方法性能可能下降。
  • 不确定性：作为预印本，未经同行评审，实验验证未提供。
  • 有边界的复述：本文提出了一种在无配对数据条件下训练 flow matching 进行 cryo-EM 连续异质性建模的框架，其可行性依赖于投影方向已知、高斯噪声假设和 flow 生成器的表达能力；在未提供实验验证的情况下，其实际性能尚不可知。

14 学到什么

Agent 提炼的知识候选：

  1. Empirical Bayes 边际化作为无配对训练框架：当观测是「隐变量 + 随机变换 + 噪声」时，可对隐变量做边际化，在无配对数据下训练生成模型。→ 可迁移至：从 SAXS/FRET 等间接观测学习构象分布。

  2. Flow matching 适配「噪声→构象」生成：Flow matching 的插值路径天然适合从噪声到构象密度的生成，无需显式配对。→ 可迁移至：构象生成任务（如从序列生成构象集合）。

  3. 投影算子作为物理约束：将已知物理模型（投影）嵌入生成模型的似然计算，可提供强归纳偏置。→ 可迁移至：MD 模拟中，将物理约束嵌入生成模型的损失函数。

  4. 连续异质性建模的范式：用生成模型表达连续构象分布而非离散状态，可揭示功能相关的构象路径。→ 可迁移至：构象采样任务，替代或补充 MD 模拟。

  5. 条件生成模型处理「图像→结构」任务：以 2D 图像为条件生成 3D 结构，可推广至其他「低维观测→高维结构」任务。
