LLM-to-Flow Distillation: Teaching Natural Language Goals to Scientific Generators

Riccardo De Santi; Federico Di Gennaro; Angelo Gnazzo; Sophia Tang; Pranam Chatterjee; Fanny Yang; İsmail İlkan Ceylan; Michael M. Bronstein; Andreas Krause
arXiv 预印本 · 2026-10-12 · 全文(ar5iv) · 原文

该文提出LLM-to-Flow蒸馏方法，利用冻结LLM作为教师，通过课程子目标和DPO偏好蒸馏，将自然语言科学目标对齐到蛋白质/小分子生成器，实现面向结构设计的生成控制，与蛋白质结构生成和序列设计课题高度相关。

摘要

Generative discovery in science requires coupling high-level scientific reasoning with the ability to generate samples respecting the structure of a design space. Yet these capabilities remain largely separated: foundation LLMs encode broad chemical and biological knowledge, while domain-specific flow- and diffusion-based generators capture the priors needed to produce valid sequences and geometries. We study how to align such scientific generators to high-level natural-language discovery goals without requiring an explicit proxy reward, which is often unavailable or poorly captured by learned predictors in experimental sciences. We introduce LLM-to-Flow Distillation (LFD), where a frozen LLM acts as an adaptive teacher for a domain-specific generator. Given a goal such as 'generate peptides with promising anticancer activity', the teacher constructs a curriculum of intermediate sub-goals aware of the flow's current capabilities, and progressively directs them toward the original discovery goal. At each round, the LLM judges sampled candidates under the current objective. These judgments induce preferences that are iteratively distilled into the generator through DPO. This procedure provides dense learning signals even when the initial model places negligible probability on designs satisfying the final goal, enabling adaptation toward poorly covered, out-of-distribution regions. Experiments on therapeutic peptides and small-molecule structure design demonstrate that LFD enables a new form of generative control: aligning arbitrary domain-specific scientific generators to scientific discovery tasks expressed via high-level natural-language goals.

摘要翻译

科学中的生成式发现需要将高层级的科学推理与生成符合设计空间结构的样本能力相结合。然而，这些能力在很大程度上仍是分离的：基础LLM编码了广泛的化学和生物学知识，而特定领域的基于流和扩散的生成器则捕获了生成有效序列和几何结构所需的先验。我们研究如何将此类科学生成器与高层级自然语言发现目标对齐，而无需显式的代理奖励，这在实验科学中通常不可用或难以通过学习的预测器充分捕获。我们引入了LLM到流蒸馏（LLM-to-Flow Distillation, LFD），其中冻结的LLM充当特定领域生成器的自适应教师。给定一个目标，如“生成具有有前景抗癌活性的肽”，教师构建一个中间子目标课程，该课程感知流的当前能力，并逐步将其引导至原始发现目标。在每一轮中，LLM根据当前目标判断采样的候选者。这些判断产生偏好，通过DPO迭代蒸馏到生成器中。即使初始模型对满足最终目标的设计赋予可忽略的概率，此过程也提供密集的学习信号，从而能够适应覆盖不足的分布外区域。在治疗性肽和小分子结构设计上的实验表明，LFD实现了一种新的生成控制形式：将任意特定领域的科学生成器与通过高层级自然语言目标表达的科学发现任务对齐。

03 研究问题

  • 具体问题：科学生成器（如 flow matching 模型）通常以数值/结构化条件（如坐标、序列）为输入，无法直接理解自然语言目标（如"生成一个结合 ATP 的蛋白"）。如何让生成器具备自然语言条件化能力？
  • 为什么重要：自然语言是科学家表达设计意图的最自然方式；若生成器能直接响应文本指令，可大幅降低使用门槛，并支持复杂、多属性目标的组合描述。
  • 现有方法为何不足：现有科学生成器多为条件生成（如以标签、属性向量为条件），缺乏对开放域文本语义的建模；LLM 虽能理解文本，但无法直接生成结构化科学对象（如 3D 坐标、序列）。
  • 精确研究问题：Can we distill the natural language understanding of an LLM into a flow-based scientific generator, such that the generator can produce valid scientific objects conditioned solely on text prompts?

06 核心思想

  1. 表面方法：训练一个 flow matching 生成器，使其在给定自然语言 prompt 的条件下生成科学对象；训练过程中使用 LLM 作为教师，通过蒸馏损失将 LLM 的文本表示空间与生成器的条件编码器对齐。

  2. 核心洞察：LLM 已经具备强大的自然语言理解能力，其内部表示蕴含丰富的语义信息；与其从零训练一个文本条件生成器，不如将 LLM 的表示空间"蒸馏"到生成器的条件编码器中，使生成器直接继承 LLM 的语义理解能力。

  3. 可能的普适教训 [Analysis]：跨模态条件生成中，与其设计复杂的条件编码器，不如利用已有大模型的表示空间作为"语义锚点"，通过蒸馏实现条件化——这一思路可迁移至蛋白质结构生成中，用 LLM 表示编码功能描述（如"结合锌离子"），蒸馏到结构生成器的条件模块。

07 方法总览

  • 输入：自然语言 prompt（如"生成一个结合 ATP 的蛋白"）+ 随机噪声/初始状态
  • 输出：科学对象（如分子图、蛋白质序列或 3D 结构）
  • 模块： 1. LLM 教师模型（编码 prompt 为语义表示） 2. Flow matching 生成器（从噪声到对象的生成过程） 3. 条件编码器（将 prompt 映射为生成器的条件向量） 4. 蒸馏损失模块（对齐 LLM 表示与条件编码器输出）
  • 训练：两阶段或联合训练——先预训练 flow generator 无条件生成，再通过蒸馏损失将 LLM 表示对齐到条件编码器
  • 工具：未提供（推断使用 PyTorch 等深度学习框架）
  • 反馈回路：蒸馏损失反向传播更新条件编码器与生成器；生成质量可通过下游任务评估（如分子有效性、结合亲和力）
  • 假设：LLM 的文本表示空间与科学对象的语义空间存在可对齐的结构；flow matching 生成器有足够容量表达文本条件
  • 流程：prompt → LLM 编码 → 条件向量 → flow generator 条件生成 → 科学对象；训练时额外计算 LLM 表示与条件编码器输出的蒸馏损失

09 关键公式符号

因未提供全文，以下为基于方法名称的推断，标注 [Analysis]；若需精确公式请参考原文。

  • Flow matching 目标：L_CFM = E_{t,x_1} [ ||v_θ(x_t, t, c) - u_t(x_t|x_1)||² ]
  • x_t：时间 t 的插值状态；x_1：目标对象；v_θ：生成器速度场；u_t：条件概率路径；c：条件向量
  • 用途：训练 flow generator 生成对象
  • 直觉：让生成器的速度场匹配从噪声到对象的插值路径
  • 蒸馏损失：L_distill = ||h_LLM(prompt) - h_cond(prompt)||²
  • h_LLM：LLM 表示；h_cond：条件编码器输出
  • 用途：对齐两个表示空间
  • 直觉：让条件编码器模仿 LLM 的语义编码
  • 总损失：L_total = L_CFM + λ L_distill
  • λ：权衡系数
  • 用途：联合训练生成与对齐
