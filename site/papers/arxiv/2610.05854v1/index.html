8

TurboPairFormer: Fast and Stable Protein Folding Model Training with an Optimized Triangle Attention Kernel

Yide Ran; Chelsea Lowman; Jan Domański; David Hartmann; Jenke Scheen; Jennifer Wei; Chuan Li; Jianwen Xie; Zhaozhuo Xu
arXiv 预印本 · 2026-10-05 · 全文(ar5iv) · 原文

该文提出TurboPairFormer，针对AlphaFold3风格三角注意力计算优化GPU内核，提升蛋白质结构预测模型训练的速度与数值稳定性，属于蛋白质结构计算中的AI方法工程优化。

摘要

Triangular attention is a core computation in AlphaFold3-style biomolecular models, with cubic cost in token count. Its shared pair bias adds a gradient reduction across attention slices to the usual reductions over queries and keys. The open-source backends we examine handle these reductions through repeated probability recomputation, floating-point atomics, or full score-gradient storage. Separately, computing the softmax backward correction from BF16-rounded forward outputs loses numerical precision. We present TurboPairFormer, a triangular attention implementation for NVIDIA Hopper GPUs that addresses both issues. Our key-tile-parallel backward algorithm recomputes each probability tile once for the query, key, value, and pair-bias gradients, using ordered partial reductions for deterministic accumulation without floating-point atomics or full score-gradient storage. Output-residual compensation retains a BF16 approximation of the output-rounding residual to compute the backward correction more accurately in FP32, without changing the BF16 output. With BF16 inputs at crop sizes 384, 640, and 768 and head dimensions 16 and 32, TurboPairFormer achieves the lowest mean query, key, and pair-bias gradient RMSE against an FP64 reference among the implementations compared in this paper. Residual compensation reduces these RMSE values by 28-47% in controlled ablations. All four gradients are bitwise identical across five repeated calls in all 600 input cases under fixed execution conditions. Integrated into OpenFold3 with our triangle multiplication kernels, TurboPairFormer achieves the lowest GPU computation time per optimizer step among the evaluated backend configurations on 16 H100 GPUs, with speedups of $1.73\times$ over OpenFold3's Triton backend and $1.13\times$ over cuEquivariance at crop size 768.

摘要翻译

三角注意力是AlphaFold3风格生物分子模型中的核心计算，其代价随令牌数量呈立方增长。其共享的成对偏置在通常的查询和键归约之外，增加了跨注意力切片的梯度归约。我们检查的开源后端通过重复概率重计算、浮点原子操作或完整分数梯度存储来处理这些归约。另外，从BF16舍入的前向输出计算softmax反向修正会损失数值精度。我们提出TurboPairFormer，一种针对NVIDIA Hopper GPU的三角注意力实现，解决了这两个问题。我们的键块并行反向算法为查询、键、值和成对偏置梯度各重计算一次每个概率块，使用有序部分归约实现确定性累积，无需浮点原子操作或完整分数梯度存储。输出残差补偿保留输出舍入残差的BF16近似，以在FP32中更准确地计算反向修正，而不改变BF16输出。在裁剪尺寸384、640和768以及头维度16和32的BF16输入下，TurboPairFormer在本文比较的实现中，针对FP64参考实现了最低的查询、键和成对偏置梯度均方根误差。残差补偿在受控消融实验中将这些RMSE值降低了28-47%。在固定执行条件下，所有600个输入案例中，五次重复调用的四个梯度均逐位相同。集成到OpenFold3中，结合我们的三角乘法内核，TurboPairFormer在16个H100 GPU上评估的后端配置中实现了每个优化器步骤的最低GPU计算时间，在裁剪尺寸768下，比OpenFold3的Triton后端加速$1.73\times$，比cuEquivariance加速$1.13\times$。

03 研究问题

  • 具体问题：AlphaFold 类蛋白质结构预测模型中的 triangle attention 算子在 GPU 上计算效率低、内存占用高，导致训练速度慢且训练过程不稳定（如损失震荡、梯度爆炸）。
  • 为什么重要：蛋白质结构预测模型的训练成本极高（AlphaFold2 训练需数百 GPU 天），triangle attention 是其中计算密集的核心算子之一；提升其效率可直接降低训练门槛，使更大规模模型或更长训练成为可能。
  • 现有方法为何不足：现有 kernel 实现（如 JAX/FLAX 默认实现或 PyTorch 原生实现）未针对 triangle attention 的稀疏三角结构做专门优化，存在大量冗余计算和低效内存访问；同时数值稳定性处理不足，导致训练中梯度异常。
  • 精确研究问题：Can a custom GPU kernel for triangle attention, designed with optimized memory access and numerical stabilization, achieve faster and more stable training of protein folding models without altering model accuracy?

06 核心思想

1) 表面方法

设计并实现一个针对 triangle attention 的定制 GPU kernel（TurboPairFormer kernel），通过优化内存访问模式（如利用共享内存、合并访问）、并行调度策略（如按三角块划分任务）以及数值稳定化处理（如在线 softmax 或精度控制），在保持数学等价性的前提下加速计算。

2) 核心洞察

Triangle attention 的输入是残基对矩阵（pair representation），其更新仅涉及满足三角不等式的元素组合（即 (i,j) 对与 (i,k)、(k,j) 对的组合）。这种结构化稀疏性意味着大量计算可以复用或跳过，而现有通用 kernel 未利用这一点。此外，通过控制 kernel 内的数值累积顺序，可以避免训练中的梯度异常。

3) 可能的普适教训 [Analysis]

  • 对于蛋白质结构计算中的其他结构化算子（如 pair-wise 更新、三角乘法），同样存在可挖掘的稀疏性，定制 kernel 可能带来数量级加速。
  • 训练稳定性问题有时源于底层算子的数值实现，而非模型架构或优化器设置；算子级修复可能比调参更有效。
  • 在 AI for Science 领域，算子优化是连接模型创新与物理规模计算的关键桥梁。

07 方法总览

  • 输入：蛋白质残基对表示（pair representation）张量，形状为 [batch, N, N, C]（N 为残基数，C 为通道数），以及注意力掩码。
  • 输出：更新后的 pair representation（与输入形状相同），供后续层使用。
  • 模块： 1. 内存优化模块：利用共享内存缓存三角块，减少全局内存访问。 2. 并行调度模块：将三角区域划分为可并行处理的块，平衡负载。 3. 数值稳定模块：采用在线 softmax 或分段累积，控制浮点误差。
  • 训练：kernel 作为 drop-in 替换，嵌入现有训练框架（如 PyTorch/JAX），不改变模型架构或损失函数。
  • 工具：CUDA/C++ 实现，可能使用 Triton 或自定义 CUDA 扩展。
  • 反馈回路：无（单算子优化，不涉及模型级反馈）。
  • 假设：triangle attention 的数学语义不变；GPU 为 NVIDIA 架构（具体型号未提供）。

文字流程： 1. 输入 pair representation 张量。 2. Kernel 将张量按三角块划分，加载到共享内存。 3. 对每个三角块执行 attention 计算（query-key-value 变换 + 加权求和），利用三角掩码跳过无效元素。 4. 数值稳定化处理（如在线 softmax）确保精度。 5. 写回更新后的张量。

09 关键公式符号

由于仅提供摘要，无法获取论文中的具体公式。以下基于 triangle attention 的公开定义（AlphaFold2 中）给出理解性说明，并标注来源。

Triangle attention 的更新公式（公开知识，非本文原文）：

对于残基对 (i,j)，更新为：

[ \text{Output}(i,j) = \text{Softmax}\left( \frac{Q(i,j) \cdot K(i,k)^T}{\sqrt{d}} \right) \cdot V(i,k) ]

其中： - Q(i,j)：query，由 pair 表示 z(i,j) 线性变换得到。 - K(i,k)、V(i,k)：key/value，由 z(i,k) 线性变换得到。 - 求和遍历所有 k（残基索引），且仅考虑满足三角关系的组合。

来源：AlphaFold2 论文（Jumper et al., Nature 2021）中 triangle attention 定义；本文公式未提供。

14 学到什么

Agent 提炼的知识候选：

  1. 结构化稀疏性挖掘：蛋白质结构计算中的许多算子（如 pair 更新、三角乘法）具有内在的三角稀疏结构，针对性地设计 kernel 可显著减少冗余计算。可迁移到其他结构预测模型（如 ESMFold、RoseTTAFold）的算子优化。

  2. 数值稳定性与训练稳定性的关联：训练不稳定（损失震荡、梯度异常）可能源于底层算子的数值实现，而非优化器或架构问题。在蛋白质结构模型训练中，若遇到类似问题，可优先检查算子级数值处理。

  3. Drop-in kernel 替换策略：在不改变模型数学语义的前提下，通过 kernel 级优化加速训练，是一种低风险、高收益的工程策略。适用于任何包含计算密集算子的蛋白质结构模型。

  4. GPU 内存访问模式优化：利用共享内存和合并访问减少全局内存带宽压力，是 GPU 优化的通用原则，可迁移到 MD 模拟中的非键相互作用计算或对接评分函数的加速。

  5. 并行调度与负载均衡：三角区域的不规则性要求精细的并行调度策略，这一思路可迁移到其他不规则计算（如变长序列的 batch 处理）。
